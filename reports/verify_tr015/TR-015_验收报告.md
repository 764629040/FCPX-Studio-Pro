# TR-015 验收报告｜dmg 重建脚本 `$DO_REPLACE` unbound variable 阻断

- 等级：致命 / 交付阻断

## 1. 根因

`tools/s4_rebuild_dmg.sh` 使用 `set -euo pipefail`（`:46`）。原 `:189` 有：

```bash
if [ "$DO_REPLACE" -eq 1 ] && [ ! -f "$OLD_DMG" ]; then
    die "--replace 需要旧镜像存在才能备份，当前未找到: $OLD_DMG"
fi
```

`DO_REPLACE` 全脚本**无任何赋值** —— `--replace` 已在参数解析处（`:94`）直接 `die`，这个判断块是禁用 `--replace` 后没清干净的残留。`set -u` 下展开未定义变量必退出，故「R2 退出后执行 `--version v1.1`」100% 失败，且失败发生在前置闸门阶段、早于任何写操作。

## 2. 修法

按问题单给的第一个方案：**删除残留判断块**，不做 `DO_REPLACE=0` 兜底（保留一个永假的开关没有意义）。删除后在该位置留 3 行注释，说明为何删除、以及 `--replace` 已在何处 die。

- 改动文件：`tools/s4_rebuild_dmg.sh`（仅此一处）
- `bash -n` → `SYNTAX_OK`
- 参数解析、只读闸门、hdiutil create、挂载校验、内盘落地逻辑**全部未动**
