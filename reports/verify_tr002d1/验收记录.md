## 0. 报告必须回答的三件事

**① 哪些层被判不可写？**
按层判，不按模板判：`positionChain != "zh"` 的层一律不可写。
- 564 层英文链模板：**全部 564 层**不可写（`editable_layers=0`），L0 / L3 实测被拒。
- 8 层中文链样本：8 层全部可写（`editable_layers=8`），五值写回照旧 `readback=5`。
- 自建混链样本（1 层英文链 + 7 层中文链）：只有那 1 层不可写（`editable_layers=7`）；
  同文件 L0 拒、L1 存 —— 证明不是整模板一刀切。
- 判据粒度是「当前选中层 / 每条 edit 的 layer index」，不是文件级。

**② 判据是什么？**
`MotiDocumentParser.parseLayer` 侧已检测的位置参数链形态 `positionChain`：
- `"zh"`（属性(1)/变换(100) 链存在）→ 可写；
- `"en"`（Properties(1)/Transform(100)）与 `""`（两种都不是）→ 不可写，X/Y 亦不可写（沿用 4D-1）。
本单新增两个纯查询入口（不改任何既有解析行为）：
- `MotiDocumentParser.swift:71` `isPositionChainWritable`（快照层可写性输出）；
- `MotiEditSession.swift:47` `layerWritable(index:)`、`:55` `firstUnwritableEditLayer()`、`:63` `editableLayerCount`。
保存拦截的判据 = `edits()` 里任意一条 edit 的 `layerWritable(index) == false`。
（`edits()` 语义一行未动；它只输出「相对写前快照确实变了」的字段。）

**③ 拦截发生在写盘前哪一步？**
`MainWindowController.confirmAndSaveMotiEdits()` 中，**算备份路径之前**：
```
edits = session.edits() → count>0 检查
→ firstUnwritableEditLayer() 命中 → print SAVE_REJECT + return
   （此刻尚未调用 MotiWriteBack.apply、未算/未建备份、未写盘）
→ 之后的 writable 检查、备份路径、performMotiSave 全部不执行
```
证据：`MainWindowController.swift:718`（`[TR-002D1] SAVE_REJECT error=图层不可写：参数链非本工具格式 (L<n>)`）。
实测 stdout 均只有 `edit_moti_open` + `SAVE_REJECT` 两行，无 `confirm_auto`、无 `SAVE_OK`、无 `SAVE_FAIL`；
文件 sha 不变、备份目录计数不变（逐用例记账见 `不可写层拦截留证.txt`）。

## 4. 披露（如实，不含包装）

1. **包内二进制未动**：`FCPX Studio Pro R2.app` 不在本单允许改动清单内，仍为 `7755783f… / 4179744 B`。
   本单修复在源码层，下一次封版自然带入；本单不重封 v1.6、不封 v1.7。
2. **表格按钮置灰的实现方式**：`InspectorView.swift` 禁改，单元格又由原逻辑按行重建，
   因此置灰走「可视行补挂 + 滚动通知补挂」。滚动瞬间新行可能先以原样式出现一帧，
   下一次补挂即灰；**最终硬保证是保存前置拦截**——按钮层即便被绕过，磁盘一个字节也不会变（A2/A3/C1/D2 实测）。
3. **保存按钮按选中层判**：混链模板里若先在 L1 改了内容、再选中 L0（不可写层），按钮会显示禁用；
   回到可写层即恢复。这是「当前这一层不能写」的诚实表达；写盘拦截则按 edits 内容判，
   两者叠加后不存在「按钮亮着、点了才发现不能存」的路径。
4. **备份计数**：开工 17，收尾 21。新增 4 个全部来自四次真实 `SAVE_OK`（zh8 预跑、mixed8 预跑、B2、C2b），
   拒绝路径 0 新增（A2/A3/C1/D2 前后计数相同）。未删除任何历史备份。
5. **旋转字段的 `0.0°`**：这是既有的只读角度显示，与位置 X/Y 无关；4D-1 判据「X/Y 不出现假 0.0」按
   X/Y 框判（显示「—」），截图 01/02 可核。
6. **混链样本是合成件**：仓库没有现成混链模板，按问题单 §4 自行构造（只改一层参数链的两个 name 属性，
   其余字节不动，脚本与断言见 `混链样本构造器.py`），只用于证明按层判。
7. **未做的事**：英文链读写支持、文本英文链落点、写回算法/错误文案体系、4D-4 的 120pt 调整、
