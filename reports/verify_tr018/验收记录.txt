二、为什么不能「纯删」
----------------------------------------------------------------
删除除 ndimage/interpolate/_lib/.dylibs 外全部子包后：

  ModuleNotFoundError: No module named 'scipy.special'

链路：ndimage/_interpolation.py 顶层 from scipy import special；
interpolate/__init__.py 为 eager import，连锁拉 linalg / sparse /
special / optimize / spatial。于是
  psd_tools.composite._compat 里 from scipy import interpolate 失败
  → HAS_SCIPY=False
  → composite/effects.py 抛 ImportError("Stroke effects require: scipy")
  → core/psd_layer_fallback.py::render_layer_to_png_bytes 掉到
    pil_topil_fallback
  → wedding_with_decorations_23.psd L003「箭头」PNG sha 从
    785e0597 变成 8053f51d（1 张降级，违反「禁降级」）。

三、最终采用的裁剪方案
----------------------------------------------------------------
A. 目录层：只保留 ndimage / interpolate / _lib / .dylibs（slim_scipy.sh）。
B. 保留区内补丁（patch_slim.py，每处带精确断言，源码不符即失败）：
   - scipy/__init__.py submodules 收敛为 ['interpolate','ndimage']
   - ndimage/_interpolation.py 去掉顶层 special，rotate() 内按需加载 +
     math.cos/sin(radians) 等价兜底
   - interpolate/__init__.py 改 PEP 562 lazy 命名空间（63 个公开符号
     访问时才加载真实实现），使 from scipy import interpolate 立即成功
   - _interpolate.py / _polyint.py / _bsplines.py / _cubic.py / _rgi.py /
     _ndbspline.py / _rbf.py / _rbfinterp.py / _ndgriddata.py / _pade.py：
     跨包顶层 import 改可降级加载；确需已删子包的 API 在调用时抛明确
     ImportError（诚实失败，绝不返回占位值、绝不静默降级）
   - CubicSpline 需要的 solve_banded((1,1),...) 用 numpy Thomas 算法
     等价实现；保留输入 dtype（float32 → LAPACK sgbsv 同精度）
C. C 级依赖（alias_capi.py）：_ppoly.so cimport scipy.linalg.cython_lapack、
   _interpnd.so cimport scipy.spatial._qhull。把原版真实 .so 复制进
   _lib/_tr018_capi/ 并在 scipy/__init__.py 注册 sys.modules 别名，
   不新增任何 scipy 子包目录，不是 stub。
