## 二、口径定稿（用户拍板 · 口径 2）

| 项 | 口径 2 落地方式 |
|---|---|
| P1 边缘延展填色 | **保留**。实体背景上被前景压住的洞，用边缘最近邻外推填掉，背景不露洞（不踩立项 §3 / §7.3 / 退回 2）。 |
| P2 邻域内容感知（patch 匹配） | **不做**。不在背景里找相似块补洞，不新增搜索窗 / 相似度匹配代码。 |
| 无依据的洞 | 周围一圈全透明、没有可参考的纯色 / 渐变 / 纹理时，**不硬填**；留透明并标 `low_confidence`，交面板手动合并/拆分。硬填等于凭空编背景，违反「不许假装分准」。 |

### 与立项单的关系

立项单 §3 BACKGROUND 禁止「缺口不补直接交付」、§7.3 要求挪走主体后背景无可见空洞、§10 退回 2「背景有明显空洞就交付判不合格」。口径 2 没有推翻这条：**实体底上的洞仍由 P1 延展补住**；只有「周围确实没有可参考背景」的洞才留透明——这种位置底下本来就是空的，留透明不算露洞。

判据（写死，不靠手感）：看洞块外扩一圈的环带里有没有实体背景像素（alpha 高、非近透明）。有 → 可补；没有 → 留透明 + 低置信。

## 三、现状代码自洽核对（只读实证）

### 1. 输入模式二分（`tools/pngp1/png_split_p1.py`）

- `foreground_mask`（约 264–271 行）：不透明像素占比 `< 98%` 判 `alpha`（自带透明底），否则判 `color`（实体底）。
- **alpha 模式**背景洞（约 1085–1093 行）：`transparent_keep`，洞区域 alpha 置 0，不延展填色。✅ 符合「无依据留透明」。
- **color 模式**背景洞（约 1094–1099 行）：`fill_holes_by_extension` 边缘延展。实体底源图全不透明，洞环带必然是实体像素，延展有依据。✅ 符合「有依据才补」。
- OBJECT 内部被文字/内装饰压出的洞（约 1029–1039 行）：取**本层自身**最近邻像素延展，属于主体自补，保留不动。

### 2. check 契约已按模式分支（约 1317–1327 行）

- `alpha` 模式跳过「背景补洞后无透明像素」断言（透明底本身就是半透明像素本体）。
- 非 `alpha` 模式才要求背景层全不透明。✅ 与口径 2 一致，无需放宽。
