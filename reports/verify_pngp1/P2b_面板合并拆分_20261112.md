## 一、背景 note 措辞：不再写死结论

**问题**：`core/png_layer_io.py:_layer_note` 对 BACKGROUND 无条件插一句「背景底图：已按延展填色补洞」。透明底样本根本没做延展，界面会同时出现「已按延展补洞」和清单自带的「源图透明底，洞保持透明」，自相矛盾。

**改法**：清单自带 notes 优先，只有清单没写才补一句中性「背景底图」。补洞方式本来就在 `background_fill.method` 字段里，不在 note 里重复下结论。

同时 `png_split_p1.py:class_legend["BACKGROUND"]` 从「去掉以上三类后的底图，已按延展填色补洞」改为「去掉以上三类后的底图；洞的处理方式见 background_fill.method」。

## 四、面板手动合并 / 拆分

### 为什么需要

P1 是按像素规则拆的，必然有拆错：一件东西被切成两三层，或者一层里躺了几件不相连的东西。用户要能在设计器里手动纠错，而不是回到命令行重跑。

### core 层（`core/png_layer_io.py`）

**像素工具（只管像素，不做业务判定）**

- `merge_layer_pngs(paths, bboxes, canvas, out_path)`：按叠放顺序（底→顶）alpha over 合成一张。层图无论是全画幅还是 bbox 裁剪尺寸，都按 bbox 对齐贴回，不靠猜。
- `split_layer_png(path, bbox, canvas, out_dir)`：按 8 连通块拆，碎块并进末块。
  阈值**随层自身像素自适应**：取「画布 0.08%（对齐 P1 碎渣口径）」与「本层像素 1/8」的较小者。原因：固定 0.08% 画布对本身只有 1600px 的碎渣层等于永远拆不动（实测第一版就是 0 块）。

**业务入口**

- `merge_layer_models(parsed, split_dir, indexes)` → `(新层表, 提示语)` 或 `(None, 拒绝原因)`
- `split_layer_model(parsed, split_dir, index)` 同上

两条入口共同的重建逻辑走 `_relayer`：重排 1-based index、重算居中位移 `motion_pos`、按类别恢复发布通道（TEXT 的文本/字体/大小/字距/对齐五通道保持不发布）、重生成缩略图。

**边界（写死在 core 里，不靠界面兜）**

| 情况 | 处理 |
|---|---|
| 非 PNG 分层链路 | 拒绝（PSD 的层来自源文件，改了跟源对不上）|
| 选中含背景层 | 拒绝合并（背景的洞是分层语义基础）|
| 背景层拆分 | 拒绝 |
| 合并选中 < 2 层 | 拒绝 |
| 拆不出第二块（本层连成一片） | 如实拒绝，不硬编 |

编辑产物一律写输出目录下 `_edit/`，**不覆盖**原 `layers/*.png`；改动只在本次导出生效，源分层文件不动（右键菜单里写明这句）。

### GUI 层

- `inspector_panel`：层树 `SingleSelection` → `ExtendedSelection`；右键菜单按选中数量给不同项（≥2 层「合并所选 N 层」，单选「按连通块拆分这层」）；新增 `layers_merge_requested(list)` / `layer_split_requested(int)` 两个信号。多选时参数面板跟随最后点中的层（`currentItem`），不再是列表里排最前的。
- `main_window`：接信号 → 调 core → 整表替换 `current_parsed_psd["layers"]` → 重刷画布与面板 → 同步层数标签与低置信度清单。失败弹原因，成功靠层数变化体现（不弹窗，少打扰）。

## 五、顺带修掉的既有问题（不修就没法验收）

本轮要交付"用户能看见的界面"，用离屏真实窗口截图时撞出四个既有问题：

1. **画板尺寸从不跟随文档** —— `_on_psd_selected` 载入后没调 `set_artboard_resolution`，竖版 1080×1920 文档按 1920×1080 画板摆放，整幅错位溢出。补一行同步。
2. **画布重刷崩溃** —— `InfiniteCanvasView.load_layers` 先 `removeItem` 再 `clear`；`removeItem` 同步触发 `selectionChanged`，回调遍历 `items_map` 与 `_expanded_item` 时撞上已删除图元，报 `wrapped C/C++ object of type ConvertedLayerGraphicItem has been deleted`。改为先清索引与展开态、再删图元，并给 `_reconcile_badge_expansion` 加 `sip.isdeleted` 防护。（这条不稳定，以前只在载入新文件时刷一次，碰不到；本轮引入"同一文档反复刷"才暴露。）
3. **层树列错位** —— 说明文字写进「锁定」列(3)，而该列同时放了锁定勾选框，「字体/预览」列(4) 永远空。改回列 4。
4. **层名被挤没** —— `fallback_png` 没在徽章映射里，层名前缀被撑成 `[fallback_png]`，图层名只剩几个字。补 `[位图]` 徽章；关掉表头「最后一列占满剩余」（`setStretchLastSection(False)`）；第 4 列固定 84px；右栏 360 → 400。
