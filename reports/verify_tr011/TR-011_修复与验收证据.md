### 3. 重签与验签（含一个环境坑）

```bash
codesign --force --deep --sign - "FCPX Studio Pro R2.app"     # SIGN_EXIT=0
codesign --verify --deep --strict "FCPX Studio Pro R2.app"    # 期望零输出
```

**坑**：首次重签后 `verify` 报 `a sealed resource is missing or invalid`，verbose 定位到
`file missing: .../Contents/MacOS/FCPXStudio.cstemp`。`codesign` 在本外置卷上签名时创建 `*.cstemp` 临时文件并把它扫进 `CodeResources`，签完删除 → 封存条目缺失。这与交接文档记录的「本盘 unlink 有毛病」同源。

**固化流程（可复现）**：
1. `find "$APP" \( -name "*.cstemp" -o -name "._*" -o -name ".DS_Store" \) -delete`
2. `xattr -cr "$APP"`
3. `codesign --force --deep --sign - "$APP"` —— **只签一次**
4. `codesign --verify --deep --strict "$APP"` → `exit=0`，输出 0 字节

注意：**签完后不要再重签**。本轮曾因验收脚本里多签了一次把好签名覆盖并复发同一错误，按上述流程重做后恢复。最终 `CodeResources` 976308 B，`grep -c cstemp` = 0。

原始输出：`03_verify.txt` / `03_verify.png`
