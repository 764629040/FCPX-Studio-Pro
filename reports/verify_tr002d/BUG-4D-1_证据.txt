TR-002-D｜BUG-4D-1 证据：英文参数链 X/Y 假 0.0 收口
==========================================================

问题单 §2 BUG-4D-1。严重等级：严重。
一句话：英文参数链模板 X/Y 显示假 0.0，改值后被自检回填且没有任何解释。

----------------------------------------------------------
1. 根因（复核结论一致）
----------------------------------------------------------
MotiDocumentParser.parseLayer 只按中文链取值：
  属性(1) / 变换(100) / 位置(101) / X(1) | Y(2)
564 层模板用的是英文链 Properties(1) / Transform(100) / Position(101)，
解析器取不到 → posX / posY 恒 0.0（假数）。
写回侧 MotiWriteBack 双语链都能写 → 写入成功；
写后 readback 用解析器（中文链）仍读 0.0 → 判不一致 → 安全回填。
用户只看到「写后读回不一致，已回填」，不知道是链格式不支持。

----------------------------------------------------------
2. 修复方式（按问题单期望：置灰 + 固定文案，不是支持英文链写回）
----------------------------------------------------------
a) MotiDocumentParser.swift
   · MotiLayerSnapshot 新增只读字段 positionChain（"zh" / "en" / ""），
     默认 "zh"，仅 parseLayer 显式赋值，其余构造点行为零变化。
   · 新增 positionChainKind(of:)：只检测链存在与否，不读英文链的值。
   · parseLayer 把检测结果写进快照。
b) InspectorView+MotiEdit.swift
   · 当前层 positionChain != "zh" 时：
       - X / Y 输入框 isEnabled = false（置灰只读）
       - 值显示「—」（不是 0.0，也不是空字符串）
       - tooltip 与横幅使用固定文案：
         该模板参数链非本工具格式（Properties/Transform/Position），X/Y 不可写
       - 横幅由单行 26pt 临时改两行 42pt（文案一字不改），避免省略号截断
   · 中文链层完全走原路径：X/Y 可写、横幅仍是「编辑态：仅 文本 / X / Y / 可见 / 锁定 写回 .moti」。
   · 退出编辑态恢复单行横幅与 X/Y tooltip。
c) MainWindowController.swift（applyAutomationPreset 内）
   · 非中文链层跳过 --edit-moti-x / --edit-moti-y 的预置，X/Y 不进 ops；
     stdout 打 [TR-002D] preset_skip_xy layer=… chain=en …。
   · 该函数整段已被 BUG-4D-3 的 #if TR002C_AUTOMATION 包住，交付包内不参与编译。
