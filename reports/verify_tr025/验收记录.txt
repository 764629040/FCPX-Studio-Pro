二、B. X/Y 数值框鼠标拖动
───────────────────────────────────────────────────────────────────────────

  posXField / posYField 换成该子类（声明仍是 NSTextField!），
  rotationField / scaleField 保持原生 NSTextField。

  B1 死区与点击编辑
    mouseDown 自跑 NSWindow.nextEvent(matching: [.leftMouseDragged,.leftMouseUp],
    until: +8s, inMode: .eventTracking, dequeue: true) 循环；拖动期间不调
    super.mouseDown → 不产生 field editor / 无蓝色选中。
    按下不动 → selectText(self)，currentEditor() != nil = true（原点击编辑保留）。
    +2pt 事件未触发回调；首个回调 delta=9.0（12-3 死区，阈值 3pt）。
    拖动三步期间「进编辑态=false」×3。→ PASS

  B2 步长（纯函数 dragValue(current:delta:flags:) 逐档断言）
    1pt=1px → 1.0；10pt=10px → 10.0；Shift×10 → 10.0；
    Option×0.1（10pt→1.0）→ 1.0；1 位小数 → 15.3；Option 3pt → 0.3。
    → PASS（全部期望==实际）

  B3 实时跟手（不是松手才刷新）
    onDragStep 每帧写 field.stringValue 并调 onPosFieldChanged()（复用原入口，
    写 model + onLayerModified 重绘画布），onDragNeedsDisplay 调
    window?.displayIfNeeded()。确定性 NSEvent 序列探针在 mouseUp **之前**
    逐帧采样 layer.posX：
      delta 9.0  → posX 9.0   stringValue 9.0
      delta 28.0 → posX 37.0  stringValue 37.0
      delta 210.0→ posX 247.0 stringValue 247.0
    松手前 247.0 == 松手后 247.0（相等 = 没有补一次刷新）。→ PASS

  B4 悬停光标：resetCursorRects() 用 addCursorRect(bounds, cursor: .resizeLeftRight)；
    拖动越过阈值 push(.resizeLeftRight)，松手 pop。
    字节级旁证：resizeLeftRight 字符串旧包 0 → 新包 1。

  B5 拖出控件外 / 松手后键入
    最后一步覆盖 +250pt（远超控件边界），仍逐帧跟手；
    松手后键入 77.7 + 回车 → layer.posX = 77.7。→ PASS

  B6 只改 X/Y：posX/posY 是可拖动子类 true/true；
    rotation/scale 仍是原生 true/true；MainWindowController 里
    onLayerModified = { canvasView.needsDisplay = true } 未改。→ PASS
