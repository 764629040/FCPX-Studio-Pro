## 三、口径偏差（必须先披露，不偷偷改口径）

1. **`enabled` / `locked` 在样本里根本不存在**：8 个 `<layer>` 开标签全是 `<layer name="…" id="…">`，
   全文 `enabled` / `locked` 字面出现 **0 次**。任务书 §1.2 说它们是「布尔属性」、§3 说「只替换属性值区间」，
   与样本不符。`MotiDocumentParser.boolAttribute(_:default:)`（663–679 行）因此全部走默认值
   `enabled=true` / `locked=false`。处理：**属性已存在→替换引号内区间；属性缺失→在 `>` 前单点插入**
   ` enabled="…"` / ` locked="…"`（同一插入点合并为一个 op，顺序固定），仍属单点字节替换，
   不重排任何已有属性、不动其它字节。这样才能让 `parse` 回读到改动值（任务书 §6.3 的硬判据）。
2. **`id="1"` 全文出现 16 次**（8 层 × 位置链 X + 缩放链 X）。所以 X/Y 一律按
   `属性(1)/变换(100)/位置(101)` 祖先链尾段匹配，绝不全局搜。缩放链 `缩放(105)` 下的 `X/Y` 值 `1.0` 不碰。
3. **文本节点含真实 LF**（如第 0 层 `领\n衔\n呈\n现`）。写回只替换 `<text>` 内容区间，
   XML 转义 `&` `<` `>`，换行原样保留；行数不变，diff 才能只命中目标行。
4. **`@default` 保留**：数值只改 `@value`，`default="0"` 一字不动（任务书 §1.2）。
