三、每个属性一句判定规则（报告里也有全文）
--------------------------------------------------------------------------------
字体名  该 layer 子树里文档顺序第一个 style 的 parameter[name=字体|Font] → <font> 节点文本，
        去空白后非空即命中（不是 @value，是节点文本）。
字号    该 layer 子树里第一个 parameter[name=大小|Size]，取值链 @value → 子 <curve>@value，
        不退回 @default；解析成 Double 且 > 0 即命中。

  $ cd /tmp/wt_tr023b1 && python3 - <<'PY'
  import os, xml.etree.ElementTree as ET
  root = os.path.expanduser('~/Movies/Motion Templates.localized/Titles.localized')
  A, B, detail = set(), set(), {}
  def walk(e, inlayer, rel, path):
      for c in e:
          p = path + "/" + c.tag + (f"[name={c.get('name')}]" if c.get('name') else "")
          il = inlayer or (c.tag == "layer")
          if c.tag == "style":
              for face in c:
                  if face.get("name") != "面": continue
                  for col in face:
                      if col.get("name") != "颜色": continue
                      if any(g.get("value") is not None for g in col.iter()
                             if g.tag == "parameter" and g.get("name") in ("红","绿","蓝")):
                          (A if inlayer else B).add(rel)
                          if not inlayer: detail.setdefault(rel, p)
          walk(c, il, rel, p)
  for dp,_,fs in os.walk(root):
      for f in fs:
          if not f.endswith(".moti"): continue
          fp = os.path.join(dp,f)
          try: t = ET.parse(fp)
          except Exception: continue
          walk(t.getroot(), False, os.path.relpath(fp, root), "")
  print("layer 内 =", len(A), "并集 =", len(A|B), "只由 layer 外贡献 =", len(B-A))
  for rel in sorted(B-A): print("  ", rel, "|", detail[rel])
  PY

  实测输出：layer 内 = 160　并集 = 163　只由 layer 外贡献 = 3
  3 个模板名与上面的 Swift 侧结果逐字相同 —— 两套独立实现（Swift 全库统计 / Python
  一次性复算）给出同一个数、同一批模板名。
