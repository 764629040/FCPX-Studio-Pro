■ 判定规则（每属性一句）
------------------------------------------------------------------------
【统一前提】
  · 候选集 = MotiDocumentParser 从 <ozml>/<scene> 起深度优先展开的全部
    <layer> 节点（前序，含任意嵌套层；本库 12324 个）。
  · 「该 layer 的子树」= 这个 <layer> 元素的全部后代节点，包含它内部再嵌的
    <layer>（解析器的 allStyleElements 就是这么走的，继承是既有行为，未改）。
  · 命中判据 = 该 layer 的 snapshot 里该字段非空/大于 0；空串与 0 一律算没取到。

字体名：取该 layer 子树里按文档顺序第一个 <style> 下 parameter[name=字体|Font]
        的 <font> 子元素文本（非 @value，是节点文本），去空白后非空即命中。
字号：  取该 layer 子树里按文档顺序第一个 parameter[name=大小|Size] 的值，
        取值链 = 参数自身 @value → 子 <curve>@value（不退回 @default），
        解析为 Double 且 > 0 即命中；大小写与 @default 都不算。
对齐：  先取该 layer 子树里第一个 <paragraphStyle> 的 parameter[name=对齐|Alignment]，
        无则退该 layer 子树里第一个带 @value 或 <curve> 的同名 parameter；
        取值链同上（@value → <curve>@value，不退回 @default），
        数值 0/1/2 分别映射 left/right/center（AppKit NSTextAlignment）即命中；
        其它数值（两端对齐等）不在三档内 → 空串 → 不命中。
颜色：  该 layer 内按固定优先级命中即停：
          ① Face/Color ② 面/颜色 ③ 表面/颜色 ④ 渐变首色标；
        每一族要凑齐 RGB 三通道（@value → <curve>@value → 该通道 @default 补齐），
        至少一个通道有值才成色，成色即命中；
        明确不用 物质/颜色、Object/Basic/Substance/Color、轮廓/Outline。

为什么在本表口径下不计入 面/颜色：这些 <style> 没有任何 <layer> 祖先，
MotiDocumentParser 只从 <scene> 起展开 <layer>，走不到它们，因此这份颜色
在 UI 里根本不会出现；把它算成「模板命中」会让分子（UI 真能显示颜色的模板）
与分母（1241 个模板）不同源。阶段 1 python 按样式扫全文档，
所以它数到 163，本表按 layer 数到 160。

一句话交代：160 与 163 差在「候选集边界」——163 把没有 layer 祖先的
<style> 也算成模板命中，160 只认 UI 真正能显示的那部分；
layer 级层数两种数法一致：面/颜色 = 250 层。
