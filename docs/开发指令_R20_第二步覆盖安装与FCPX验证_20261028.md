## 一、前置判断（硬门槛，逐项留痕）

> 以下四项是方案 A 的硬前置。**任一项不满足，禁止执行覆盖安装**。所有判定必须附原始命令输出，不接受「应该是」「大概是」。

### P-1 · 已装 `1`/`23` 是真实目录还是符号链接

```
ls -ld "$HOME/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕/1" \
       "$HOME/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕/23"
```

- 判定：首字符为 `d` → 真实目录，方案 A 可直接执行；首字符为 `l` → 符号链接，**必须先改造 `build_template_atomic` 对 `os.path.islink(output_dir)` 分支处理**，否则 `os.rename` 只移动链接本身、`os.replace` 会建出真实目录，链接架构被静默破坏。
- 证据要求：**原始 `ls -ld` 输出全文**存入 `docs/r20_evidence/`，不得只写结论。

### P-3 · 组目录 `PSD婚礼字幕` 本身是否为符号链接

```
ls -ld "$HOME/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕"
```

- 判定：若为链接，需确认备份与替换发生在**外部真实目录**内（`os.rename` 跨文件系统抛 `EXDEV`）。

### P-2 · 备份落点须在模板扫描树之外

- 扫描树根：`~/Movies/Motion Templates.localized/`
- 备份落点：`~/Movies/_psd_subtitle_backups/`（必须在扫描树之外）
- 判定：`find ~/Movies/Motion Templates.localized/ -maxdepth 4 -name '*_bak_*' -o -name '*_tmp_build_*'` 必须 0 命中。

### P-4 · 逐模板串行（先 T01 后 T23）

- 禁止批量；任一失败时保留另一个不动，回滚面最小。
- 证据：安装器输出中须体现两次独立调用，各自带退出码。

## 二、命名裁决（条件性批准，双分支写死）

### 2.1 裁决

**条件性批准**：将模板命名为 **`T01_领衔呈现_竖版` / `T23_含装饰_横版`**，直接复用 `build_staging/` 已复核产物，**不重建**。

### 2.2 走此分支的前提条件（必须全部满足）

开发方须补做**外置盘 + Movies 精准扫描**，确认**无任何 FCPX 工程引用旧 `1`/`23`**。扫描至少覆盖：

1. `~/Movies/` 下全部 `.fcpxml` / `.fcpbundle` / 资源库；
2. 外置卷 `/Volumes/摄影师工具箱128GB/` 下全部 `.fcpxml`；
3. `~/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕/` 内旧 `1`/`23` 的实际引用。

三条命令（示例，开发方可扩充但不得缩减）：

```
find ~/Movies -iname '*.fcpxml' 2>/dev/null | head -200
find /Volumes/摄影师工具箱128GB -iname '*.fcpxml' 2>/dev/null | head -200
grep -rl "PSD婚礼字幕/1\|PSD婚礼字幕/23" ~/Movies /Volumes/摄影师工具箱128GB 2>/dev/null | head -50
```

**判定树**：

| 扫描结果 | 走哪条分支 | 动作 |
|---|---|---|
| **未发现任何引用** | 分支 A（命名 `T01`/`T23`） | 直接复用 staging 产物安装，不重建 |
| **发现任一引用** | 分支 B（保持 `1`/`23`） | 自动改走保持 `1`/`23` 命名，**重新构建**（`template_name="1"`/`"23"`），并**重核五项数据**（comp 尺寸/层数/缩略图比例/纵向跨度/横向跨度） |

**关键**：两条分支都已写死，开发方**不需要再来问**，按扫描结果自行走。扫描证据（命令 + 输出）存入 `docs/r20_evidence/`。

### 2.3 为什么复用 staging 而不是重建

- `.moti` 文件名必须与模板目录名一致（`_validate_template_bundle` 第 681 行强制）；
- staging 产物已被第十九轮独立审核逐项复核（五项数据 + Media 实物尺寸）；
- 重建会引入「未经复核的新变量」，是审核角度最忌的。

## 五、异常分支与处置

| 异常 | 触发条件 | 处置 |
|---|---|---|
| E-1 | P-1 发现 `1`/`23` 为符号链接 | **停止**。先改造 `build_template_atomic` 对 `os.path.islink(output_dir)` 分支处理，再重走 §一 |
| E-2 | P-3 组目录为符号链接且跨卷 | 备份与替换必须在外部真实目录内进行，避免 `EXDEV` |
| E-3 | P-2 扫描树内发现 `_bak_/_tmp_build_` 残留 | 先清理残留，再执行安装；残留即视为 A-36 未处置 |
| E-4 | §二 扫描发现任一 FCPX 工程引用旧 `1`/`23` | 自动走分支 B：保持 `1`/`23` 命名，重新构建，重核五项数据，重新提交审核 |
| E-5 | J-1 退出码非 0 | 立即回滚：`os.rename` 备份 → 还原，保留失败现场日志 |
| E-6 | J-2 A-25 尺寸不符 | 停止，核对 staging 源与 PSD，禁止「先装了再说」 |
| E-7 | J-4 sha256 不一致 | 停止，说明 staging 被改动或未复用，要求重做 |
| E-8 | 安装中途失败 | 保留另一个模板不动，回滚面最小，写异常报告 |

**回滚机制**：旧版已 `os.rename` 至 `~/Movies/_psd_subtitle_backups/<timestamp>/{1,23}`，未删除，可随时还原。
