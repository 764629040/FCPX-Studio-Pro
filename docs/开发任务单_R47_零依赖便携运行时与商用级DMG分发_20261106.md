## 一、详细技术规格与模块设计

### 1. 便携式运行时打包器 (`tools/bundle_standalone_runtime.sh`)
- 自动提取当前运行环境中的核心 Python 运行时与纯 Python 依赖（`psd-tools`、`Pillow` 等）；
- 安全嵌入至 `FCPX Studio Pro.app/Contents/Resources/python_bundle`；
- 剥离无用的 `.pyc` 缓存、测试用例与开发头文件，体积精简优化；
- `AppConfig.swift` 四级级联探测链最高优先级直接命中内置便携包；
- 确保执行 `FCPX Studio Pro.app` 时不需要用户机器配置任何环境变量或预装 Homebrew。

### 2. 标准 DMG 商业镜像打包器 (`tools/package_dmg.sh`)
- 采用 macOS 原生 `hdiutil` 自动化压制只读压缩镜像 `FCPX_Studio_Pro_v1.0.dmg`；
- 镜像根目录包含：
  - `FCPX Studio Pro.app`（已代码签名并通过 Gatekeeper 校验）；
  - `/Applications` 软链接快捷替身；
  - `使用说明与快速上手.txt`。

### 3. 原生 App 编译、代码签名与直证
- 执行全量 Release 编译；
- 对嵌入后的完整 App Bundle 执行递归深度代码签名：
  `codesign --deep --force --verify --verbose --sign - "FCPX Studio Pro.app"`；
- 编写 `tools/r47_harness.swift` 自动化断言便携运行时探测路径、DMG 镜像完整性与启动零依赖可用性。
