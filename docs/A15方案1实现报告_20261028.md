## 2. 关键实现（回应审核 6.2 节的更正）

审核更正了第八轮的根因表述：

> 根因是**徽章固定尺寸（最小 110 宽 / 18 厚）与竖版 11–14 单位列间距不匹配**，
> 横向与纵向同时失配，横向失配量级更大（110 vs 11–14，约 8 倍）。
> 且 `rotation = 90°` 的图元经 `setRotation(90)` 后，徽章厚度落在**水平**方向。

**这直接决定实现方案**：锚点不能用 `rect.left()`（旋转后位置全错），
必须用图元本地原点（`setRect(-w/2, -h/2, w, h)` 的 (0,0) 即 bbox 中心），
经 `setRotation` 后色点自然随图元旋转。

```python
def _dot_rect(self) -> QRectF:
    """折叠态色点：以 bbox 中心为锚点（本地原点），随图元旋转"""
    half = self.DOT_SIZE / 2.0
    return QRectF(-half, -half, self.DOT_SIZE, self.DOT_SIZE)

def _hit_rect(self) -> QRectF:
    """命中区不小于 8×8（视觉色点 4×4，命中区外扩）"""
    half = max(self.HIT_MIN, self.DOT_SIZE) / 2.0
    return QRectF(-half, -half, half * 2.0, half * 2.0)
```

参数：

| 常量 | 值 | 说明 |
|---|---|---|
| `DOT_SIZE` | 4.0 | 折叠态色点边长 |
| `BADGE_MIN_WIDTH` | 110.0 | 展开态最小宽（保持原值） |
| `BADGE_HEIGHT` | 18.0 | 展开态厚（保持原值） |
| `BADGE_GAP` | 4.0 | 胶囊与 bbox 间距 |
| `HIT_MIN` | 8.0 | 命中区下限 |

展开条件：`isSelected() or _hovered or _badge_expanded`。

### 4.1 一处测试自纠（如实记录）

首轮无 AppKit 跑出 **1 failed**：

```
AssertionError: 四态夹具状态过少: {'unverifiable': '#ffd60a'}
assert 1 >= 3
```

**是我的断言写错**，不是代码缺陷：无 AppKit 环境下全部图层必然是 `unverifiable`，
只有 1 种状态是**正确行为**。已改为按环境分支：

```python
if has_appkit:
    assert len(seen) >= 3        # macOS：三态并存
else:
    assert set(seen) == {"unverifiable"}   # 无 AppKit：统一单态
```

这与 A-10 修复确立的契约一致——不得把平台能力差异当成缺陷。
