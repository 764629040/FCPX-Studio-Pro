## 2. 各条目执行结果

### 2.1 A-40 模板唯一化（P1）

新增 `core/template_dedup.py`：
- `derive_template_aliases(name)`：同源别名推导，已修正裸数字映射（T01↔1、T23↔23），
  避免漏匹配历史命名。
- `scan_homologous_siblings` / `dedup_before_install`：安装前扫描同源兄弟目录，
  移入隐藏回收 `.{name}_trash_<ts>`（保留=移入回收站，不 `rmtree`、不静默共存）。
- `verify_unique_after_install`：安装后校验——目标内恰 1 个 `.moti` 且 sha256 与构建产物一致、
  Media 数符合、parent 无同源残留；任一不满足抛 `TemplateUniquenessError`，不得返回成功。

`core/motion_builder.build_template_atomic` 接入：步骤 6a 调用 `dedup_before_install`，
步骤 7b 调用 `verify_unique_after_install`，返回含 `dedup_report`。


**A-40 三检查直接演示**（见 `docs/r22_evidence/a40_demo.txt`）：
- ① 去重：扫描到同源兄弟 `01_领衔呈现`（sha 与构建产物一致），移入隐藏回收；
