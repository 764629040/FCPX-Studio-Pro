## 一、详细技术规格与模块设计

### 1. 批量导出异步并发调度器与进度面板 (`BatchExportProgressSheet.swift`)
- **存放路径**：`FCPXStudioNative/Sources/FCPXStudio/Views/BatchExportProgressSheet.swift`；
- **交互与视觉**：
  - 采用 macOS Pro 磨砂毛玻璃 Sheet 窗口（以当前主窗口为宿主附着弹出）；
  - 进度指示器：平滑 `NSProgressIndicator`，显示百分比（如 `42% (21/50)`）；
  - 实时状态文本：展示当前正在转换的 PSD 文件名（如 `正在生成: 镇雄.psd -> Motion XML...`）；
  - 结果清单小列表：实时滚动呈现成功（🟢）、警告（🟡）、失败（🔴）流水明细；
  - 底部操作栏：【取消批处理】按钮，全部完成后变为【在 Finder 中查看】与【完成】按钮。
- **后台异步调度 (`MainWindowController.swift`)**：
  - 将 `batchExportAllTemplates()` 完全移至后台全局高优先级队列（`DispatchQueue.global(qos: .userInitiated)`）；
  - 避免任何主线程阻塞与旋转彩球；
  - 每完成一个模板，通过 `DispatchQueue.main.async` 刷新进度条；
  - 任务支持中途安全取消（`isCancelled = true`），退出时清理未完成的临时暂存文件。

### 2. 导出路径自适应与无外置盘智能降级 (`AppConfig.swift` & `MainWindowController.swift`)
- **规则规范**：
  - 检测首选外置存储目录（`defaultExternalAssetsDir`）；
  - 若外置盘未挂载或不可写，**严禁直接弹出模态错误阻断用户**！
  - 自动无缝降级到本地标准路径：`~/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕`（必要时自动创建目录与 `.localized` 字典）；
  - 如果检测到外置盘重新插入，则恢复软链接模式；
  - 提供目标路径选择器（【保存到外置盘】/【保存到本地系统盘】/【自定义导出目录】）。

### 3. 字体拖拽一键补齐与系统安装助手 (`FontInstaller.swift`)
- **存放路径**：`FCPXStudioNative/Sources/FCPXStudio/Models/FontInstaller.swift`；
- **核心功能**：
  - 支持将 `.ttf` / `.otf` / `.ttc` 字体文件直接拖拽到诊断面板或主窗口；
  - 基于 macOS 原生 `CTFontManagerRegisterFontsForURL(url, .user, &error)` 瞬间静默注册字体为用户级全系统可用字体；
  - 注册成功后自动通知 `NSFontManager` 刷新字体缓存，并触发当前 PSD 重新校验，使原本缺字警告即刻变绿（`detection_status: "detected"`，字形覆盖率 100%）。
