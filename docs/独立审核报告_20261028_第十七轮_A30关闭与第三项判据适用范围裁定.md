## 3. 关键验证：逐层贴图有没有引入新失真

这是本轮我花最多力气的一项。因为你承认「差异不属于纯暗噪声」，我必须自己证明**逐层侧没有变脏**。

逐层贴图的**覆盖范围与 `composite()` 完全一致**，无缺块、无溢边。

### 3.2 逐层侧是否引入了 composite 没有的亮噪声

| 指标 | 实测 |
|---|---|
| 差异像素总数（旧夹具） | 84847（4.0918%） |
| 其中**逐层比 composite 更亮 > 20** 的像素 | **10707** |
| 　└ 落在**文字层并集内** | **10707（100%）** |
| 　└ 落在**文字层并集外** | **0** |

**这一行是决定性的：逐层贴图多出来的 10707 个亮像素，100% 落在 8 个文字层的 bbox 并集内，文字层外一个都没有。**

对照视觉证据 `round17_evidence/A30_r17_textband_compare.png`（文字带 y 370–690，全宽 1080）：

- **上（`composite()`）**：红绿横向条纹铺满，文字**完全不可读**；
- **下（`composite_layers_manually()`）**：8 层文字清晰——「领衔呈现／LEAD THE PRESENTATION／新娘 THE BRIDE／朱永宏／新郎 THE GROOM／陈晗／镇雄／CITY」。

**所以那 10707 个更亮的像素，是被彩条淹没后恢复出来的文字，不是新噪声。**

### 3.3 你提到的 2646 / 712 暗噪声

| 指标 | 你的值 | 我实测 | 判定 |
|---|---|---|---|
| composite 暗噪声 `(mx>0 & mx<=20)` | 2646 | **2646** | **完全一致** |
| 逐层暗噪声 | 712 | **712** | **完全一致** |

**你的数字是准的。** 但用它概括整体差异会低估严重程度：

- 旧夹具总差异 **84847 像素（4.09%）**，不是 2646；
- 构成是：**被消除的彩条（42329）+ 被恢复的文字（约 24201，文字区差异占 12.80%）+ 暗区噪声（约 2646）**。

**建议表述改为「差异 = 消除彩条 + 恢复文字 + 少量暗区噪声」，而不是「差异是暗噪声」。** 这不是造假，是表述会让人误判量级。

## 4. A-32 成因已定位（重要技术发现）

我在新沙箱按你的依赖装 **psd-tools 1.9.24**，结果：

```
tests/data/vertical_wedding_9_16.psd -> Invalid RLE compression
```

**1.9.24 直接抛异常，根本解不开旧夹具；换 1.26.0 后正常解码。**

这解释了你我之间 84/40 vs 28852/13477 的量级差——**不是谁算错，是解码路径不同**：低版本对同一 RLE 数据解出的像素完全不同，甚至直接失败。

**因此 A-32 的性质要升级**：不只是「报告没标注版本」，而是**存在一个会直接失败的解码版本区间**。建议：

1. 在 `requirements.txt` / 报告里**写明最低版本**（建议 `psd-tools>=1.26.0`），不是只写「当前版本」；
2. 彩条计数统一用**全像素扫描**（你的 step=20 采样会漏掉 99.99%：旧夹具全像素 42329，采样只命中极少）；
3. 断言保持 `red > 0 or green > 0` 即可，**不必锁具体数值**——跨版本数值本就不稳定，锁数值会造成假失败。
