## 一、 核心功能实现细节

### 1.1 `LayerModel.swift` 扩展与数据流闭环
- **属性扩充**：在 `LayerModel` 中增加 `public var isLocked: Bool`，初始化参数默认赋 `false`，确保旧有调用端 100% 向后兼容；
- **状态深拷贝与同步**：
  - `public func copyModel() -> LayerModel`：创建图层完整深拷贝，包括所有文本属性、变换参数、缺字风险标识与锁定状态；
  - `public func sync(from other: LayerModel)`：支持将外部修改状态平滑无损同步回原模型对象；
- **解析套接字支持**：在 `PSDParserSocket.swift` 中统一读取 `item["is_locked"] as? Bool ?? item["locked"] as? Bool ?? false`，解析时建立初始锁定态。

### 1.2 `InfiniteCanvasView.swift` 画布锁定交互与视觉系统
- **防误触穿透算法（Penetration Hit-Testing）**：
  - 画布中的图层在 PSD 数组中为“顶 $\to$ 底”排序；
  - 在 `hitTestLayer(at:)` 中判定 `guard !layer.isLocked else { continue }`；
  - 若鼠标落点下方有多个图层，顶部图层锁定时会自动跳过，穿透选中下方的未锁定图层；若下层图层亦全部锁定，则安全返回 `-1`，彻底杜绝误触底板或定稿元素。
- **拖拽绝对阻断（Drag Blocker）**：
  - `mouseDown` 阶段：若命中的图层 `isLocked == true`，强行设置 `isDraggingLayer = false`；
  - `mouseDragged` 阶段：增加前置守护 `guard !layer.isLocked else { isDraggingLayer = false; return }`，彻底防止拖动画布误改坐标。
- **锁定专属视觉高光（Lock Visual Badge）**：
  - 选中普通图层：渲染高亮科技蓝边框（`lengths: [4/zoomScale, 4/zoomScale]`）；
  - 选中锁定图层：渲染经典灰色细点虚线边框（`NSColor.systemGray`, `lengths: [2.5/zoomScale, 2.5/zoomScale]`），并在右上角动态绘制自适应缩放的深色圆角胶囊徽标，徽标内居中绘制醒目的 `🔒 LOCKED` 铭牌，层次分明。

### 1.3 `InspectorView.swift` 检查器置灰与快捷键联动
- **图层表格新增「锁定」与「显示」列**：
  - 增加 `lock` 列，点击直接切换当前行的锁定状态，图标即时在 🔒 与 🔓 之间流转；
  - `vis` 列由复选框升级为直观的 👁 / 🚫 切换，隐藏图层呈现灰色置灰视觉；
- **属性控件智能置灰（Smart Read-Only State）**：
  - 实现 `updateControlStates(isLocked:)` 集中管理控制器：
    - `textEditor?.isEditable = !isLocked`，锁定状态下字体颜色降级为半透明灰色；
    - `toggleOrientationButton`、`rotationSlider`、`scaleSlider`、`posXField`、`posYField`、`publishTextCheck` 等全部控件置为 `isEnabled = false`；
  - 在属性区域上方增设警示提示横幅 `lockBannerBox`，文字内容：“🔒 图层已锁定，解锁后可修改属性”；选中锁定图层时自动展出，解锁后无缝淡出隐藏；
- **快捷键联动系统（⌘L / ⌘H）**：
  - 绑定 `⌘L` 切换当前选中图层的 `isLocked`，联动通知画布与检查器刷新；
  - 绑定 `⌘H` 切换当前选中图层的 `visible`，画布即时隐藏对应渲染；
  - 主菜单栏挂载「图层」原生菜单项，支持全局菜单调用与快捷键触发。
