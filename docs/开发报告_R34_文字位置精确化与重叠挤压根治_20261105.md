## 一、 根因定位与三段修复链路实施

### 1.1 链路①：`core/psd_parser.py` 段落对齐与真实行距提取
- **改动位置**：
  - `PSDLayerInfo.__init__`：增加 `alignment: str = "center"`，`self.alignment = alignment`；
  - `PSDLayerInfo.to_dict()`：增加 `"alignment": self.alignment`；
  - `parse_psd_file`（文本图层解析分支）：
    - 从 `layer.engine_dict["ParagraphRun"]["RunArray"][0]["ParagraphSheet"]["Properties"]` 提取 `Justification`：
      - `0` -> `"left"`
      - `1` -> `"right"`
      - `2` -> `"center"`
      - 其他/异常 -> `"left"`
    - 从 `layer.engine_dict["StyleRun"]["RunArray"][0]["StyleSheet"]["StyleSheetData"]` 提取 `Leading`：若 `AutoLeading` 为 False 且 `Leading` 存在，存为真实浮点数；否则默认 `round(fontSize * 1.2, 5)`；
    - 记录至 `PSDLayerInfo.line_spacing` 与 `PSDLayerInfo.alignment`，并序列化到桥接 JSON。
- **实测验证**：`01.psd`（`vertical_wedding_9_16.psd`）中 4 个中文层 `alignment == 'center'`, `leading == 46.5`；4 个英文层 `alignment == 'left'`, `leading == 20.83333`，提取准确率 100%。

### 1.2 链路②：`core/motion_builder.py` 写入对齐参数与锚点坐标补偿
- **改动位置**：
  - 更新 `parameter id="401"`（段落对齐）：
    - `"left"` -> 写入 value=`"1"`
    - `"center"` -> 写入 value=`"2"`
    - `"right"` -> 写入 value=`"3"`
    - 对所有 `layer_elem.findall(".//parameter[@id='401']")` 批量同步赋值；若图层（如 Text 02）未包含现有 401 节点，则在 `paragraphStyle` 节点中安全补充注入；
  - **非居中锚点坐标补偿**：
    - 在 Motion 中，左对齐图层将 `parameter 101` 作为行首基线，而 PSD 提取的 `motion_pos`（`mx, my`）为包围盒几何中心；若直接填入，会导致左对齐图层向右平移半个身位（`line_len / 2`）；
    - 本轮在写出 `parameter 101` 时执行向量补偿：
      ```python
      half_len = line_len / 2.0
      dx = half_len * math.cos(rot_rad)
      dy = half_len * math.sin(rot_rad)
      if align_str == "left":
          comp_x = mx - dx
          comp_y = my - dy
      elif align_str == "right":
          comp_x = mx + dx
          comp_y = my + dy
      ```
    - 补偿后，Motion 左对齐行首基线与 PSD 真实包围盒完全对齐（例如 `THE BRIDE` 在 Motion 中的基线 Y 坐标精准落在 456.0，与 PSD 物理包围盒底部 504 笛卡尔映射 960-504=456 完全吻合）。
- **实测验证**：导出的 `.moti` 文件各图层 `parameter 401` 与 PSD 提取属性完全一致，深层结构 ID 未做变动，保持架构完整性。

### 1.3 链路③：`InfiniteCanvasView.swift` & `LayerModel.swift` 物理包围盒与对齐绘制
- **改动位置**：
  - `LayerModel.swift`：增加 `public var alignment: String`（默认 `"center"`）与 `public var lineSpacing: Double`（默认 `0.0`）；
  - `PSDParserSocket.swift`：解析桥接 JSON 中的 `alignment` 与 `line_spacing` 并注入 `LayerModel`；
  - `InfiniteCanvasView.swift`：
    - 彻底废除 `maxLineLen * fontSize * 1.1` 伪假公式；
    - 采用真实 `psdBBox`（`bw = b[2]-b[0], bh = b[3]-b[1]`）；当文本旋转 90°/270° 时，屏幕上的视觉高度对应局部宽度，视觉宽度对应局部高度（`totalW = bh, totalH = bw`），使旋转后的屏幕外接矩形严格等于真实物理宽高 `(bw, bh)`；
    - 绘制属性设置真实的 `style.alignment`（`.left` / `.center` / `.right`），并应用真实行距 `style.lineSpacing`；
    - `hitTestLayer` 同步采用真实 `psdBBox` 半径，杜绝虚假大方块拦截鼠标。
