## 二、 详细设计与实现要求

### 2.1 FCPX 资源库深度安全瘦身清理引擎（`LibraryCleaner.swift` & `CleanerDashboardView.swift`）

1. **资源库智能探测与拖拽扫描**：
   - 自动扫描用户本机常见路径（如 `~/Movies/`、外置剪辑盘中的 `.fcpbundle` 资源库包）；
   - 支持剪辑师随手将任意 `.fcpbundle` 资源库拖入清理面板；
2. **深度包结构穿透与安全分类**：
   - 穿透 `.fcpbundle` 目录树，精确分类并统计各项非破坏性缓存的体积：
     - `Render Files`（高画质渲染缓存、光流 Optical Flow 分析、防抖稳定缓存）；
     - `Proxy Media`（剪辑代理媒体，非原始素材）；
     - `Thumbnail Media`（音视频波形与缩略图缓存）；
     - `Shared Items`（历史导出分享渲染残留）；
3. **极度审慎保守瘦身安全红线（最高安全等级）**：
   - **绝对红线**：`Original Media`（原始拍摄素材）与项目元数据数据库（`CurrentVersion.fcpevent` / `CurrentVersion.flexolibrary`）**绝对受保护，严禁触碰**；
   - **安全移入废纸篓**：清理动作一律通过 `FileManager.default.trashItem` 或 `NSWorkspace.shared.recycle` 安全移入 macOS 废纸篓（Trash），**绝对禁止 `rm -rf` 盲目硬抹除**，确保用户资产 100% 可找回；
   - 提供直观的体积清单，支持单项选择或一键安全瘦身（`Safe Clean All`）；
   - 清理完成后即时重新计算释放空间并展示释放报表。

### 2.2 多语言本地化友好中文重命名引擎（`TemplateRenameManager.swift`）

1. **中文别名直观设定**：
   - 用户在模板列表/卡片中，支持一键点击【重命名 / 设置中文别名】（对标嘉星 `TemplateRenameManager`）；
   - 允许为模板指定友好中文名（如将 `Modern_Title_01` 命名为 `中式婚礼优雅字幕`）；
2. **`.strings` 字典安全写入机制**：
   - 深入模板包及所属分类的 `.localized/zh_CN.strings` 或 `zh-Hans.strings` 字典文件；
   - 使用标准 UTF-16 / UTF-8 编码安全追加或更新键值映射对：`"Modern_Title_01" = "中式婚礼优雅字幕";`；
   - 若 `.localized` 目录或 `.strings` 字典不存在，自动规范创建；
   - **断链防护**：保持底层文件夹原始物理名称或 Motion 模板工程内部 ID 引用不变，仅在 Final Cut Pro 界面层显示亲切中文名，彻底杜绝 FCPX 红色感叹号破损断链！

### 2.3 `AssetHubView` 四大超级业务中心完整布局

1. 顶层主 Tab 升级完善：
