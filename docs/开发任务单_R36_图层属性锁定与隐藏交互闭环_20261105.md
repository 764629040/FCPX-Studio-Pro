## 一、 任务背景与目标

目前画布拖拽编辑与智能对齐磁吸已在 R35 交付（D-73）。在复杂排版设计中，用户极易误触底板、背景文字或已定稿图层。
本轮旨在全量落地总清单 **D 域第 74 项：「图层隐藏状态与属性锁定的完整交互」**：
1. 为图层数据模型注入 `isLocked` 属性；
2. 在原生画布（`InfiniteCanvasView`）实现锁定图层的防误触穿透与锁定视觉标识；
3. 在检查器（`InspectorView`）实现锁定按钮、属性只读置灰与快捷键联动（⌘L / ⌘H）；
4. 保持全量回归测试与原生架构一致。

---

## 二、 详细设计与实现要求

### 2.1 `LayerModel.swift` 扩展
1. 增加属性：`public var isLocked: Bool = false`；
2. 在 `PSDParserSocket.swift` 解析时默认赋 `false`（或读取已有状态）；
3. 提供深拷贝与状态同步方法。

### 2.2 `InfiniteCanvasView.swift` 原生画布交互锁定
1. **拾取穿透保护**：
   - 在 `hitTestLayer` 中，若 `layer.isLocked == true`，跳过该图层，优先拾取其下方的未锁定图层，防止误点；
2. **选中态与锁定标识绘制**：
   - 若通过列表选中的图层处于锁定状态，在画布上绘制专属的锁定风格高光边框（例如 `NSColor.systemGray` 配合细点虚线），并在其右上角或左上角绘制精美的小锁图标 🔒 或 `LOCKED` 徽标；
3. **拖拽阻断**：
   - `isDraggingLayer` 在选中的图层 `isLocked == true` 时**绝对不启动**，杜绝误拖动。

### 2.3 `InspectorView.swift` 检查器与列表交互
1. **图层列表增加「锁」列**：
   - 在图层表格中增加 `lock` 列，支持点击切换锁定/解锁（🔒 激活 / 🔓 未激活）；
2. **属性控件智能只读置灰**：
   - 当选中的图层处于锁定状态时，右侧检查器中的文本框、字体下拉框、字号滑动条、坐标输入框、旋转控制等**自动禁用（`isEnabled = false`）**；
   - 属性区域顶部显式显示黄色/灰色提示横幅：“🔒 图层已锁定，解锁后可修改属性”；
   - 解锁后立即恢复可编辑状态。
3. **可见性（眼睛 👁）优化**：
   - 图层隐藏时（`visible == false`），画布上即时不渲染该图层（除底板预览在设置中特殊要求外），列表眼睛图标切换为闭眼/置灰状态；
4. **快捷键支持**：
   - 绑定 `⌘L` 切换当前选中图层的锁定状态；
   - 绑定 `⌘H` 切换当前选中图层的显示/隐藏状态。

### 2.4 验证与回归
1. 编写直证 Harness（如 `tools/r36_lock_harness.swift`），针对锁定穿透、属性置灰、快捷键、可见性切换进行 100% 自动化断言；
2. 保持 Python 全量回归 `pytest tests/` 305 项全部通过（Exit Code 0）；
3. 重新编译并签名 `FCPX Studio Pro.app`，更新指纹 `docs/audit_inventory_native_r36.json`。
