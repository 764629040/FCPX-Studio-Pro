## 1. 实现：逐层贴图合成

### 1.1 核心函数

`core/thumbnail.py` 新增 `composite_layers_manually(psd_obj, edge_fill=True)`：

1. **递归收集叶子层**（组内子层也要展开）
2. 逐层 `layer.composite()`，按真实 bbox 与画布**求交后裁切**
3. `alpha_composite` 贴入
4. 覆盖率 < 99% 时做**边缘延伸填充**

### 1.2 三个踩坑（如实记录）

实现过程中遇到三个真实缺陷，全部靠实测发现：

| # | 缺陷 | 症状 | 修复 |
|---|---|---|---|
| 1 | 对 `descendants()` 做 `reversed()` | 叠放顺序错，**0.57% 像素差异** | 改用顶层迭代（已按自下而上） |
| 2 | `getattr(node, "is_group", False)` 恒真 | `is_group` 是**方法**不是属性，所有层被当组递归 → 合成**全透明** | 先 `callable` 判断再调用 |
| 3 | 无条件边缘填充 | 正常夹具透明区被涂色，**0.57% 差异** | 覆盖率 < 99% 才填充 |

### 1.3 边缘填充的作用边界

实测数据：

| 夹具 | 无填充非透明率 | 有填充非透明率 |
|---|---|---|
| 重建夹具（完整背景） | **100%** | 100%（不触发） |
| 旧夹具（背景仅覆盖上半） | **56.25%** | **100%** |

填充只在覆盖率不足时生效，正常夹具零影响。

## 3. 第三项指标的问题（需要您裁定）

### 3.1 现象

「新夹具逐像素回归 == 0」这条，在**重建夹具**上成立（0 像素），
但在**四态/旧夹具**上是 4.09%。

### 3.2 差异的性质

我做了逐通道分析：

| 检查 | 结果 |
|---|---|
| Alpha 通道差异 | **0 像素** |
| RGB 差异位置 | y 220..1734，纯黑区域 |
| 差异样本 | 我 `(0,0,0)` vs composite `(17,0,0)` |

**composite 在纯黑区域产生了暗红噪声 `(17,0,0)`**，我的输出是干净的纯黑。

进一步统计「暗噪声伪影像素」（`0 < max(RGB) <= 20`）：

| 夹具 | composite 暗噪声 | 逐层贴图暗噪声 |
|---|---|---|
| 四态 | **2646** | **712** |
| 旧夹具 | 2646 | 712 |
| 重建夹具 | 0 | 0 |
| 横版 | 0 | 0 |

### 3.3 我的判断

**「逐像素与 composite 一致」这条标准，是拿有伪影的结果当基准。**

逐层贴图在四态/旧夹具上比 composite **更干净**（712 vs 2646 暗噪声）。
如果要求与 composite 完全一致，反而要**主动复现它的伪影**——这与 A-30 的目标（消除伪影）冲突。

### 3.4 请您裁定

| 选项 | 含义 |
|---|---|
| A | 维持「== composite」，则我需要主动复现伪影（技术上可行，但与目标冲突） |
| B | 改为「与 composite 差异仅限暗噪声区域，且暗噪声数 ≤ composite」（推荐） |
| C | 改为「重建夹具 == 0；其余夹具彩条 0/0 + 非透明 100% 即可」 |

我倾向 **B 或 C**，但这属于验收标准定义，由您定。
