## 3. 崩溃判定标准

按优先级判，任一命中即记「崩溃 = 是」并写明主体：

1. **R2.app 崩溃**：点击确认后进程退出 / Dock 图标消失 / 出现 macOS「意外退出」对话框 / `~/Library/Logs/DiagnosticReports/` 新增 `FCPX Studio Pro*.ips`（或 `.crash`）。
2. **FCPX 崩溃 / 卡死**：FCPX 意外退出、 beachball 持续、弹「资源库已损坏 / 文件丢失 / 无法打开资源库」、渲染文件缺失告警。
3. **App 内错误**：看板 `cleanResultLabel` 的 `errors` 计数 > 0（假库基线是 0），或 Console 里 `trashItem` 相关 error。
4. **静默破坏**：`Original Media` 消失、`.fcpbundle` 结构被改动、Render Files 子项数不是预期的 3（多了说明误伤，少了说明漏清）。
5. **无崩溃**：以上全否，且看板仍可交互 → 记「崩溃 = 否」。

> 「FCPX 运行态特有风险」（清理后 FCPX 是否重新生成缓存、是否触发重新渲染）**只能由人在口径 C 下观察**，S2 不预设结论。
