## 一、 核心功能实现细节

### 1.1 `TemplateInstaller.swift` 一键安装与分类智能感知引擎
- **扩展名映射与枚举**：
  - 定义 `MotionCategory` 枚举，映射四大分类的 `.localized` 目录名称与中文友好名；
  - `MotionCategory.fromExtension` 消除大小写与前导点干扰，精准识别四大类。
- **递归模板发现与子分类推导**：
  - `discoverTemplates(inDirectory:defaultSubcategory:)` 使用 `FileManager.enumerator` 深度探测包内所有 Motion 专有工程文件；
  - 向上回溯两级目录提取主题/子分类名称（Theme / Subcategory），若无可提取则智能回落为压缩包名或默认分类。
- **原子解压与冲突备份**：
  - 在 `install(paths:targetTierRoot:defaultSubcategory:)` 中，临时解压在独立 UUID 沙箱内；
  - 若目标目录已存在模板，调用原子移动将旧版本备份至 `installer_conflicts` 隔离目录，再行写入新版本。
- **模板状态启停操作**：
  - `toggleTemplate(item:)` 与 `setTemplateEnabled(item:enabled:)`：
  - 检查内置只读保护（`TierWritePolicy.isBuiltinWritable`）；
  - 原子重命名 `item.path` $\leftrightarrow$ `item.path.disabled`；
  - 返回干净的显示名称（剥离 `.disabled`），同时保持 `path` 与磁盘实际路径一致。

### 1.2 `TemplateTier.swift` 模型与扫描器增强
- **`TemplateItem` 属性扩展**：
  - 增加 `public var isEnabled: Bool = true`，初始化方法保留默认参数 `isEnabled: Bool = true`，确保历史模块 100% 源码级兼容。
- **`TemplateTierScanner.scan` 逻辑增强**：
  - 扫描各层级目录时，自动检测 `entry.hasSuffix(".disabled")`；
  - 若命中后缀，标记 `isEnabled = false`，显示名称剥离后缀；若未命中，标记 `isEnabled = true`；
  - 无论是启用还是休眠状态，体积统计与磁盘形态均能完整准确计算。

### 1.3 `AssetHubView.swift` 交互体验全面对标嘉星
- **四大分类下拉选择与一键切换**：
  - 接入 `selectCategory(_ category: String)` 与 `onCategoryChanged`；
  - 支持 `Titles.localized`、`Effects.localized`、`Transitions.localized`、`Generators.localized` 切换即时重载全量数据。
- **表格新增「状态」列**：
  - 列标识 `status`，标题「状态」，宽度 95pt；
  - 单元格渲染交互按钮：`p.isEnabled ? "🟢 已启用" : "⚪️ 已休眠"`；
  - 绑定 `onToggleStatusClicked`，用户点击直接触发底层重命名并刷新列表；
  - 针对内置级只读模板，点击弹出弹窗：“系统内置模板受保护，需先复制到用户库后再调整”。
- **拖拽半透明安装引导遮罩（Drop Overlay）**：
  - 创建 `dropOverlayView`，采用高质感深蓝半透明遮罩与浅蓝边框，居中展示大号 📦 引导文案；
  - 实现 `NSDraggingDestination` 协议：`draggingEntered` 自动调用 `TemplateInstaller.acceptsDrop`，命中模板或 zip 时淡入展示，移出或释放时自动恢复；
  - 释放后异步调用 `TemplateInstaller.installTemplates`，并在主线程完成刷新与成功统计汇总。
- **顶部资产健康统计条**：
  - 结合三级分布与当前分类状态，格式化输出：“当前分类（\(catDisplayName)）：共 N 套 · 🟢 已启用 M · ⚪️ 已休眠 K | 🟡 内置 X · 🟢 用户 Y · 🟣 系统 Z”。
