## 一、详细技术规格与模块重构

### 1. 中间无限画布磨砂半透明质感统一 (`MainWindowController.swift`, `InfiniteCanvasView.swift`)
- **根因分析**：
  - `MainWindowController.swift` 中 `canvasView` 直接以不透明视图贴在窗口上；
  - `InfiniteCanvasView.swift` 的 `layer?.backgroundColor` 及 `draw` 方法硬编码填充了不透明纯黑色 (`#0D0E12`)，切断了桌面和窗口底层的毛玻璃背板，形成视觉“黑洞”。
- **重构要求**：
  - 在 `MainWindowController.swift` 中为 `canvasView` 配置 `NSVisualEffectView` 背板（`material = .underWindowBackground`, `blendingMode = .behindWindow`, `appearance = NSAppearance(named: .darkAqua)`）；
  - `InfiniteCanvasView` 设置为半透明石墨调底色（`alpha: 0.35 ~ 0.45`），允许底层磨砂玻璃质感自然穿透；
  - 点阵网格（Dot Grid）保留并精细化，与毛玻璃形成高科技专业工作台质感；
  - 中间 1920x1080 画板（Artboard）保持扎实的工作区底色，配备细腻深邃的悬浮投影（`shadowBlur = 32, offset = (0, -12), opacity = 0.6`）与 Pro 边框（`borderWidth = 1.0, color = white 16%`），与左右毛玻璃侧栏完美呼应。

### 2. 素材库万级性能虚拟分块渲染与缩略图内存缓存 (`AssetHubView.swift`, `ResourceCardView.swift`)
- **根因分析**：
  - 当前 `AssetHubView.reloadCardGrid()` 在载入 1,294 款模板时，一次性将 1,294 个 `ResourceCardView`（包含 12,000+ 个子视图）全部 `addSubview` 到容器中，瞬间阻塞主线程布局引擎；
  - 同时触发 1,294 个次级线程并发进行磁盘文件 I/O 探测与 PNG 解码，且缺乏内存缓存，导致严重卡顿、掉帧与彩虹圈。
- **重构要求**：
  - **缩略图内存高速缓存 (`ResourceCardView.swift`)**：
    - 引入 `static let thumbnailCache = NSCache<NSString, NSImage>()`；
    - 读取图片前先命中内存缓存，命中率高且 0ms 瞬间显示；
    - 后台解码完成后写入缓存，避免重复磁盘 I/O。
  - **虚拟分页分块加载 (`AssetHubView.swift`)**：
    - 首次仅渲染前 48 款卡片（瞬间加载，耗时 < 15ms，60fps 丝滑无感）；
    - 底部提供优雅的「加载更多 / 查看全部（已展示 X / Total 项）」按钮及滚动触底智能懒加载；
    - 切换分类（如从全部 1294 切到综艺动漫 280）时秒级响应，彻底消灭切换卡顿感。

### 3. 模板安全删除（移入废纸篓）完整闭环 (`AssetHubView.swift`, `ResourceCardView.swift`)
- **业务需求**：支持用户在素材库中对不需要的发生器、标题、特效、转场直接执行安全删除。
- **重构要求**：
  - **安全策略**：系统内置模板（`.builtin`）默认受保护，弹窗告知“系统内置模板受 macOS 保护，不可直接删除”；用户自定义及外置模板可自由删除；
  - **交互入口**：
    - 卡片右下角「⋯」更多操作菜单新增「🗑️ 移入废纸篓 (Delete)」项；
    - 卡片与表格右键上下文菜单（Context Menu）同步支持「移入废纸篓」；
  - **无损可逆删除**：
    - 调用原生 `FileManager.default.trashItem(at: url, resultingItemURL: nil)`，确保文件安全移动至 macOS 废纸篓，用户随时可“放回原处”，杜绝硬性物理擦除风险；
  - **内存与 UI 联动**：
    - 删除成功后，即时从 `allItems`、`plugins` 内存列表中移除，并同步更新 `AssetCacheManager` 缓存；
    - 平滑移除对应卡片视图，即时刷新顶部子分类徽章计数（如 `全部 (1293)`），界面无需全量重启。

### 4. 外置存储搬家中心与检视器 UI 全面精致化 (`StorageMigrationDashboardView.swift`, `InspectorView.swift`)
- **根因分析**：
  - `StorageMigrationDashboardView.swift` 表格操作列使用了 `bezelStyle = .inline` 的 `NSButton`，导致按钮强制拉伸为整行等宽等高的巨大胶囊，排版极其臃肿粗糙；
  - 界面仍残留大量 Emoji 图标（`🚀`, `↩️`, `📁`, `🟢`, `⚡️`, `💾`），与原生 macOS Pro 风格格格不入。
- **重构要求**：
  - **单项操作按钮精致化**：
    - 单元格居中放置紧凑型 Pro 按钮（宽 96pt，高 24pt）；
    - 采用 SF Symbols 矢量图标：`arrow.up.forward.app`（搬到外置）与 `arrow.uturn.backward`（迁回内置）；
    - 按钮使用暗色石墨微光边框与圆角，字体 11pt medium，悬停高亮；
  - **指标卡片与顶栏图标重塑**：
    - 顶栏按钮：「刷新」(`arrow.clockwise`)、「一键搬家至外置卷」(`arrow.up.forward.app.fill`)、「还原至内置盘」(`arrow.uturn.backward`)；
    - 指标卡片图标全部升级为 SF Symbols：`internaldrive`、`externaldrive.badge.checkmark`、`bolt.circle.fill`、`externaldrive`；
    - 卡片背景升级为半透明石墨质感，边框采用 1px 微光线条；
  - **检视器与全局控件对齐**：
    - 右侧检视器底部操作按钮（保存、导出）高度标准化（28pt），与全站磨砂玻璃规范严格一致。

### 5. macOS 原生官方高清应用图标系统 (`AppIcon.icns`) 封装与发布
- **根因分析**：
  - 之前版本打包仅复制了可执行二进制与 Python 环境，未包含 `AppIcon.icns`，`Info.plist` 中也未声明 `CFBundleIconFile`；
  - 导致在桌面、访达（Finder）、访达侧边栏、程序坞（Dock）以及 DMG 安装包中均呈现 macOS 默认白底空网格占位符，严重破坏了专业 Pro 应用的工业设计完整性。
- **重构要求**：
  - **设计标准**：严格遵循 Apple macOS Human Interface Guidelines (HIG) Big Sur+ 超椭圆圆角（Continuous Curvature Squircle，1024×1024 Retina 高清母版）；
  - **视觉元素**：
    - 深邃钛金黑至暗夜曜石渐变底座，辅以 1px 环形微光金属倒角边框与半透明磨砂质感；
    - 中心图案：Apple Final Cut Pro / Motion 标志性霓虹动感胶片光轨 + 金曜石核心「✦ Studio」专业星标；
  - **生成全套多分辨率图标集 (`AppIcon.iconset`)**：
    - 包含 16x16, 16x16@2x, 32x32, 32x32@2x, 128x128, 128x128@2x, 256x256, 256x256@2x, 512x512, 512x512@2x (1024x1024)；
    - 使用 macOS 原生 `iconutil -c icns` 编译生成工业标准 `AppIcon.icns`；
  - **系统级集成**：
    - 置入 `FCPX Studio Pro.app/Contents/Resources/AppIcon.icns`；
    - 更新 `Info.plist` 注入 `<key>CFBundleIconFile</key><string>AppIcon</string>`；
    - 更新 `tools/package_dmg.sh`，重新生成包含官方高质感图标的 DMG 镜像。
