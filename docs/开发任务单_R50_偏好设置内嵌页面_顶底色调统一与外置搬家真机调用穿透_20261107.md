## 一、详细技术规格与模块重构

### 1. 偏好设置从独立弹窗彻底重构为内嵌页面 (`AssetHubView.swift`, `SettingsWindow.swift`)
- **根因分析**：
  - 点击侧边栏「偏好设置」时，之前调用了 `SettingsWindowController.shared.showWindow(nil)` 弹出一个独立的 macOS 模态窗口，割裂了单窗口 Pro 工作流体验。
- **重构要求**：
  - 在 `AssetHubView.swift` 的主内容区域中新增专属的「偏好设置与自检工作台」内嵌视图（Tab 8 `settingsContainer`）；
  - 将 `SettingsWindow.swift` 中的核心设置功能（内置级只读/可写安全策略 Toggle、环境依赖便携化就绪状态、Metal 硬件加速自检、Python 便携环境状态等）完整迁移为自适应 AutoLayout 的内嵌面板；
  - 侧边栏点击「偏好设置」（Tag 11）时，平滑切换至 Tab 8，彻底废除浮动弹窗。

### 2. 顶栏与素材管理中心视觉质感一体化与色调协调 (`AssetHubView.swift`, `MainWindowController.swift`)
- **根因分析**：
  - 顶栏 `topBar` 采用了 `NSVisualEffectView`（`.sidebar` 材质 + `behindWindow` 混合），而下方的 `AssetHubView` 及其侧边栏直接填充了硬编码的不透明深黑色（`#111417` / `#14171c`），使得上下交界处产生明显的色块割裂感。
- **重构要求**：
  - `AssetHubView` 整体外壳重构为 `NSVisualEffectView`（`material = .underWindowBackground`, `blendingMode = .behindWindow`, `appearance = NSAppearance(named: .darkAqua)`）；
  - `sidebarView` 左侧边栏重构为 `NSVisualEffectView`（`material = .sidebar`, `blendingMode = .behindWindow`）；
  - 顶栏与内容面板背景颜色梯度、微光边框（`NSColor(white: 1.0, alpha: 0.10)`）与呼吸留白完全对齐，呈现天衣无缝的 macOS 现代暗色玻璃质感。

### 3. 多工作区情境（全量、婚礼、商业、短视频）功能强化与状态直观呈现 (`WorkspaceProfileDashboardView.swift`, `WorkspaceProfileManager.swift`)
- **技术阐述与验证**：
  - 明确“情境隔离（.disabled）”的底层技术：物理文件原封不动保存在磁盘，通过向无用插件包或目录添加 `.disabled` 后缀，使得 FCPX 在启动扫描时完全跳过该目录；
  - 结果：插件不进 FCPX 内存，不出现在 FCPX 菜单中，FCPX 启动提速 5~10 倍；再次开启时去除后缀，瞬间恢复连接；
  - 在 `WorkspaceProfileDashboardView` 中增加实时的「当前已隔离插件数量」及「已节省 FCPX 扫描开销」动态指示卡片，让用户对“关闭/开启”的生效机制一目了然。

### 4. 外置移动存储真实迁移与 FCPX 穿透调用实测直证 (`StorageMigrationManager.swift`, `SymlinkSocket.swift`)
- **核心逻辑与技术直证**：
  - 深度核验 macOS 文件系统级透明软链接（Symbolic Link）：
    - 物理文件移动至外置高速卷（如 `/Volumes/摄影师工具箱128GB/...` 或测试外置卷）；
    - 在系统盘 `~/Movies/Motion Templates.localized/` 原生位置创建指向外置目录的透明软链；
    - 对 FCPX 与 macOS 系统而言，访问路径与原生完全一致，FCPX 底层无缝穿透并保持完整的 GPU 加速与实时渲染；
  - 编写自动化实操脚本与端到端 Harness，真实模拟从系统盘移动大体积模板到外置存储、创建软链接、并在软链接下调用 Motion 解析渲染引擎，验证成图完全一致并截图留证；
  - 解释为什么厂商默认装在“影片”位置（第三方安装包为通用性采用傻瓜式脚本硬编码系统路径）。
