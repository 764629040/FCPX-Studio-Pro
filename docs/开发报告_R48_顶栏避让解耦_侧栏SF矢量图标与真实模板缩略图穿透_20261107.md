## 一、工程背景与攻坚使命

在 R47 完成便携式 Python 运行时与商用级 DMG 分发镜像压制后，真机用户在 macOS 原生使用中反馈了三个关键的视觉质感与素材真实性问题：
1. **顶部红圈挤压与标题穿透碰撞**：启用 `.fullSizeContentView` 且 `titlebarAppearsTransparent = true` 后，系统默认窗口标题文本未隐藏，顶栏 `segmentedControl` 从 X=16 铺满，直接与 macOS 交通灯（红黄绿 🔴🟡🟢）及系统标题 `FCPX Studio Pro (macOS 原生旗舰版)` 发生图层穿透与物理挤压碰撞；
2. **左侧侧边栏残留彩色手机 Emoji**：`AssetHubView.swift` 侧边栏按钮硬编码了移动端 Emoji（`💬`, `✨`, `📼`, `⚡️`, `🎨`, `🎵`, `🧹`, `🩺`, `💾`, `🗂️`, `🚀`, `⚙️`），视觉粗糙刺眼，与 macOS Pro 旗舰软件调性严重不符；
3. **模板展示虚假 Emoji 与假分类**：`TemplateTierScanner.scan` 原先仅做一层单级遍历，把 `03综艺动漫` 这样的分类文件夹直接当作单个模板，而分类文件夹根目录根本没有 `large.png`；导致 `ResourceCardView` 找不到图片退化为彩色 Emoji 占位符，用户看到的全部是假图标。对标《嘉星插件管理 2.app》，必须 100% 递归穿透读取磁盘中的 1,200+ 套真实模板与真实 `large.png` 缩略图！

## 二、核心技术实现与源码重构

### 1. 顶栏避让解耦与窗口标题栏重构 (`MainWindowController.swift`)
- **根除穿透碰撞**：设置 `win.titleVisibility = .hidden`，彻底隐去系统窗口标题文本，严禁任何文字穿透重叠；
- **交通灯安全避让边距**：设置 `trafficLightPadding = 84pt`，顶栏引擎切换胶囊 `[ 🪄 设计器 (PSD → Motion) ] [ 🗄️ 素材库与管理中心 ]` 从 X=84pt 起排，为红黄绿交通灯留足呼吸空间；
- **现代 Pro 统一工具栏布局**：
  - 引擎切换胶囊宽度调整为 390pt；
  - 右侧工作区情境胶囊（`profileBadgeButton`，宽 160pt）与直观对比模式切换控件（`comparisonSegmentedControl`，宽 300pt）靠右自然对齐；
  - 中间留出 220pt+ 呼吸空间，各控件垂直居中，彻底消除任何文字重叠与挤压。

### 2. 左侧菜单栏全面升级 Apple 原生 SF Symbols (`AssetHubView.swift`)
- **彻底清除所有 12 项侧边栏 Emoji**：
  - 改造 `addSidebarButton(id:icon:title:to:)`，采用 `NSImage(systemSymbolName:...)` + `btn.imagePosition = .imageLeading` + `btn.imageScaling = .scaleProportionallyDown`；
  - 12 大功能项全面映射至 Apple 原生 SF Symbols 矢量图标体系：
    1. 标题字幕 (id: 0): `character.textbox`
    2. 视频特效 (id: 1): `wand.and.stars`
    3. 视频转场 (id: 2): `rectangle.2.swap`
    4. 视频发生器 (id: 3): `film.stack`
    5. 3D LUT 调色 (id: 4): `slider.horizontal.3`
    6. 影视音效库 (id: 5): `waveform`
    7. 资源库瘦身医生 (id: 6): `trash.circle`
    8. 幽灵插件医生 (id: 7): `stethoscope`
    9. 存储与搬家 (id: 8): `externaldrive`
    10. 工作区情境 (id: 9): `macwindow.on.rectangle`
    11. 团队分发 (id: 10): `paperplane`
    12. 偏好设置 (id: 11): `gearshape`
- **Pro 灰阶与选中高亮**：选中项背景为高质感深海军蓝 `#19243c`，图标与文字联动高亮，对标 Finder 与 Final Cut Pro 原生侧栏；
- **主分类标题消除 Emoji**：`categoryTitleLabel` 去除 Emoji 前缀，显示为优雅纯净的 `标题字幕 (Titles)`。

### 3. 模板深度递归扫描与真实 `large.png` 缩略图穿透 (`TemplateTier.swift` & `ResourceCardView.swift` & `AssetHubView.swift`)
- **深度递归模板探针 (`TemplateTier.swift`)**：
  - `TemplateItem` 扩展 `subCategory: String = ""` 字段，保留旧初始化签名，确保 100% 源码与二进制向后兼容；
  - 重构 `TemplateTierScanner.scan`：深入递归分类目录下的各级子文件夹，精准识别内部直接包含 `.moti`（字幕）、`.moef`（效果）、`.motr`（转场）、`.motn`（发生器）的真实模板目录；
  - 提取：`name`（真实模板名，如 `图标 01`）、`subCategory`（所属子分类，如 `03综艺动漫`）、`targetPath`（真实模板物理目录）；
  - 兼顾叶子测试 Mock 目录（如 `Same/same.bin`），保证历史自动化测试零回归。
- **100% 真实加载 FCPX 缩略图 (`ResourceCardView.swift`)**：
  - 彻底删除 `categoryIconLabel.stringValue = "💬"` 占位符；
  - 优先读取模板物理目录内的 `large.png`（FCPX 标准大图）、`small.png`、`thumbnail.png`、`preview.png`；
  - 若无图片，优雅降级为 SF Symbol `film` 矢量图标，杜绝假 Emoji；
  - 卡片 16:9 视口高保真渲染真实缩略图，左下角悬浮展示半透明子分类胶囊标签（`subCategoryBadgeLabel`，如 `03综艺动漫`），副标题联动展示所属子分类。
- **子分类快速筛选栏 (`AssetHubView.swift`)**：
  - 在网格视图顶部增设横向滚动的【子分类快速筛选栏】（`subCategoryScrollView` 与 `subCategoryStackView`）；
  - 自动从扫描结果中聚合提取所有子分类并按模板数降序排列：`全部 (1294)`, `03综艺动漫 (280)`, `易安装 - 137个体育新闻风格字幕条 (137)`, `MS标题字幕S5 (50)`, `PSD婚礼字幕 (53)`...；
  - 点击子分类胶囊即刻过滤卡片列表并高亮胶囊，完全还原 Final Cut Pro 原生素材浏览体验。
