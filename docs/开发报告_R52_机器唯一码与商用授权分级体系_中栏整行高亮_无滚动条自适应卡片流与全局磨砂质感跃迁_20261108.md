### 1. 硬件特征码与防伪授权核心 (`LicenseManager.swift` & `tools/generate_license.py`)
- **硬件特征码提取**：
  - 基于 IOKit 读取 `IOPlatformExpertDevice` 的 `IOPlatformUUID`；
  - 读取 primary 网卡（`en0`）物理 MAC 地址；
  - 组合哈希后生成格式化代码：`MAC-XXXX-XXXX-XXXX`（100% 确定性、防伪造、唯一性）；
- **商用防伪签名与离线校验**：
  - 管理后台工具 `tools/generate_license.py`：基于主密钥盐计算 HMAC-SHA256，生成许可证代码 `FCPX-LIC-XXXX-XXXX-XXXX`；
  - 端侧 `LicenseManager.swift`：对机器码执行端侧数学验签，校验通过后持久化写入本地配置；同时内置开发者测试免密代码（`DEV-TEST-PASS-2026`）用于离线与 Harness 自动化验证；
- **分级权限拦截网关 (Feature Gate)**：
  - `isProLicensed: Bool`
  - 体验版：浏览与实时预览 ✅ 开放；删除模板与分组 ❌ 拦截；批量渲染导出 ❌ 拦截；外置一键搬家 ❌ 拦截；情境隔离切换 ❌ 拦截；P2P团队直传与克隆 ❌ 拦截；
  - 商业版：全量功能无缝解锁。
- **左上角品牌卡片 `LicenseStatusCardView`**：
  - 磨砂半透明质感背景（`NSColor(0.10, 0.12, 0.16, 0.50)` + `0.8pt` 微光边框）；
  - 包含机器码展示、一键复制到剪贴板按钮（点击反馈 `已复制 ✓`）；
  - 授权状态徽章：`🟡 试用体验版` / `🟢 永久商用授权`；
  - `[🔑 激活]` 按钮支持就地展开内嵌轻量输入抽屉，输入后即刻激活，并支持已授权状态下的注销管理。

### 2. 中栏 TableView 整行高亮与多列文字联动变色 (`GroupTableRowView`)
- **自定义 RowView 绘制**：
  - 实现 `GroupTableRowView: NSTableRowView`；
  - 重写 `drawSelection(in dirtyRect: NSRect)`，使用 `NSBezierPath(roundedRect:..., xRadius: 6, yRadius: 6)` 绘制深邃高透蓝光晕背景（`NSColor(0.18, 0.48, 0.95, 0.32)`），并叠加 `0.5pt` 细微光轮廓描边；
  - 重写 `drawBackground` 保持完全透明，使底层的毛玻璃质感自然穿透；
- **多列单元格文字联动**：
  - `groupName`：加粗纯白（`.white`，weight: `.bold`）；
  - `groupCount`：高光天青蓝（`#61D2FF`，weight: `.bold`）；
  - `groupSize`：高亮银白（`#F7F7F7`，weight: `.semibold`）；
  - `groupTier`：醒目指示箭头「▶」+ 高光蓝，未选行不显示箭头；
  - `tableViewSelectionDidChange` 触发全表重绘，整行视觉变色完全同步。

### 3. 右栏自适应弹性卡片流与零滚动条平滑滚动 (`InvisibleScroller`)
- **零滚动条平滑滚动 (`InvisibleScroller`)**：
  - 继承 `NSScroller`，将 `draw(_:)`、`drawKnob()`、`drawKnobSlot(in:highlight:)` 重写为空实现；
  - `isCompatibleWithOverlayScrollers = true`；
  - 将 `groupScrollView.verticalScroller` 与 `cardGridScrollView.verticalScroller` 均设为 `InvisibleScroller`；
  - 彻底隐藏所有原生滑块与滑道，但鼠标滚轮与触控板双指滑动原生顺畅无阻。
- **自适应弹性流式布局 (Adaptive Fluid Grid)**：
  - 重构 `reloadCardGrid`：不再使用写死的 220pt 宽度与固定列数；
  - 依据 `cardGridScrollView.contentView.bounds.width` 动态计算：
    - 列数 `cols = max(2, min(4, Int((availableW - 32 + 14) / (210 + 14))))`；
    - 卡片宽度 `cardW = floor((availableW - margin * 2 - (cols - 1) * spacing) / cols)`；
    - 严格预留 `>= 16pt` 呼吸安全边距；
  - 重写 `resizeSubviews(withOldSize:)`，窗口拉伸或缩小时卡片网格即时流式重排，彻底消除第 3 列卡片被窗口边缘截断的问题。

### 4. 全局磨砂玻璃质感、椭圆胶囊与配色深度统一
- **左下角外置挂载胶囊**：
  - 重构为精致的 **Pill shape 椭圆胶囊**（`layer.cornerRadius = 22`，高度严格 44pt）；
  - 磨砂半透明背景（`NSColor(0.12, 0.14, 0.18, 0.45)`）+ `0.8pt` 亚光微光融合边框；
  - Apple 原生 SF Symbol `externaldrive.fill` 图标 + 绿色动态发光呼吸灯指示点；
- **消除全界面死黑硬块**：
  - 将中栏背景、分类胶囊条、中栏工具栏、右栏背景、面包屑条、批量工具栏的硬编码不透明纯黑背景（`alpha 0.90` / `1.0`）全部替换为半透明磨砂深色质感（`alpha 0.35 ~ 0.45`）；
  - 底层添加 `NSVisualEffectView`（`.darkAqua`），实现整个界面的透光与深色一体化。
