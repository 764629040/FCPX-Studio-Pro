## 1. A-18：我方判断有误，撤回

### 1.1 审核指出的错误

我先把同一个数值分别传给 `setPointSize(34)` 和 `setPixelSize(34)` 直接比较，
得出"偏差 31%"。但**这不是生产链路**。

### 1.2 真实生产链路实测

链路：`font_size(px) → text_render_font_size() → ×0.75 → QFont(pt) → Qt 按 96DPI 换算回 px`

| PSD px | ×0.75 后 | QFont(pt) 实际 px | 偏差 |
|---|---|---|---|
| 12 | 9 | 17 | **+0.0%** |
| 16 | 12 | 22 | **+0.0%** |
| 24 | 18 | 33 | **+0.0%** |
| 32 | 24 | 45 | **+0.0%** |
| 48 | 36 | 67 | **+0.0%** |
| 64 | 48 | 90 | **+0.0%** |
| 90 | 68 | 127 | +0.8% |
| 100 | 75 | 140 | **+0.0%** |
| 120 | 90 | 168 | **+0.0%** |

结果与审核完全一致：**偏差 0.0%～+0.8%**，24/48/100px 处为 0.0%，随字号增大收敛。

**×0.75 换算与 Qt 的 DPI 换算相互抵消，是正确的。改掉它才会在 Retina 等高 DPI 环境引入真实偏差。**

### 1.3 处置

- **A-18 撤回**，不成立，不修改任何代码；
- A-3 已过审约定保持不变；
- 我在上一轮"不越权改已过审约定、先送审"的做法是对的，但**判断依据（31% 的测量方法）是错的**，特此更正。

### 3.2 问题二：写入守卫改用白名单

**审核发现**：原实现硬编码单个卷名黑名单，新增只读挂载点即失效。

**修复**：

```python
def _guard_write(path: str):
    """
    白名单为主，黑名单为辅。
    主防线：写入必须落在项目根目录内，默认拒绝一切外部路径。
    辅防线：保留原只读卷名单作为防御性冗余。
    """
    resolved = os.path.realpath(os.path.abspath(path))
    root = os.path.realpath(os.path.abspath(PROJECT_ROOT))

    for forbidden in FORBIDDEN_ROOTS:          # 辅
        if resolved.startswith(os.path.realpath(os.path.abspath(forbidden))):
            raise SystemExit(...)

    if resolved != root and not resolved.startswith(root + os.sep):   # 主
        raise SystemExit(...)
```
