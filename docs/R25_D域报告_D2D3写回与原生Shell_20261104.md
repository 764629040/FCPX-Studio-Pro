## 原生 Shell（FCPXStudioNative）—— 构建通过（附环境说明）

- 结构：不是纯 62 行骨架。`main.swift` 62 行为 AppKit 入口，全 target 共 10 个文件
  1729 行：MainWindowController（原生三栏 UI + 双引擎切换）、InfiniteCanvasView、
  InspectorView、AssetHubView、LayerModel、AppConfig、三个 Socket 桥
  （PSDParserSocket / MotionBuilderSocket / SymlinkSocket —— 以 subprocess 调
  `core/cli_bridge.py`，JSON 协议，parse/build 两命令）。
- 构建结果（2026-11-04 实测）：
  - `swift build --disable-sandbox --scratch-path .build` → **Build complete!**（17.7s，debug）
  - `swift build --disable-sandbox -c release` → **Build complete!**（13.6s）
  - 产物：`.build/debug/FCPXStudio`（632,992 B）与 `.build/release/FCPXStudio`
    （392,792 B，Mach-O arm64，链接 AppKit/CoreGraphics/Foundation）。
  - 裸 `swift build`（不带 --disable-sandbox）在本机会失败：SwiftPM 内部用
    `sandbox-exec` 给 manifest 编译加沙箱，被外层会话沙箱拒绝
    （`sandbox-exec: sandbox_apply: Operation not permitted`）。这是**环境限制，
    不是代码缺陷**——在普通终端裸跑 `swift build` 应正常。
- 桥接实测：`python3 core/cli_bridge.py parse tests/data/complex_layers.psd` →
  `{"status": "ok", "layers": 5, "canvas": 1920x1080}`。
- 已知限制（诚实声明）：
  - 本机偶发 swiftc 子进程 SIGTRAP(133) 空输出（沙箱 shim 干扰），重试即恢复；
    上述 Build complete 均为真实完成（产物 mtime = 构建时刻，Mach-O 校验通过）。
  - AppConfig 硬编码 python 候选路径（homebrew → /usr/bin）；若用户机器 python
    未装 psd_tools，parse 会返回 empty——属运行时环境依赖，需人工在真机确认。
  - GUI 交互（拖拽/锁定/参考线视觉）本环境无 PyQt6 且不能弹原生窗口，
    **必须由人工在真机验证**；自动化仅覆盖纯逻辑与静态接线断言。
