## 1. A-41 代码改动（`core/template_dedup.py`）

### 1.1 移除裸编号别名

`derive_template_aliases(name)` 不再派生裸编号。以 `T01_领衔呈现_竖版` 为例：

| 版本 | 派生的别名集合 |
|------|----------------|
| R22（错误） | `领衔呈现`, `01_领衔呈现`, `1_领衔呈现`, **`1`** ← 裸编号，危险 |
| R23（正确） | `领衔呈现`, `01_领衔呈现`, `1_领衔呈现`（带余名，区别于裸编号独立目录） |

理由：用户 `~/Movies/.../PSD婚礼字幕/` 下存在以裸编号命名的独立模板目录（`2`..`50`，共 48 个，见 §4）。裸编号映射 `T01↔1 / T23↔23` 缺乏可靠依据，且与用户既有目录直接冲突，若参与 dedup 会静默移走用户认为正常的独立模板。

### 1.2 新增内容级判据 `_confirm_homology`

```python
def _confirm_homology(sib_dir, target_moti_sha, target_moti_path) -> (bool, str):
    # 判定优先级：
    # 1. 兄弟无有效 .moti → 空壳/损坏，触碰闪退嫌疑 → 可移出（隔离）
    # 2. .moti sha256 与本次构建产物一致 → 重复版本 → 可移出
    # 3. 结构同源（层名 / reference_base 集合一致，容忍少量层更名/增删）→ 可移出
    # 4. 以上均不满足 → 无法确认同源 → 默认不移动，仅警告交人工/用户复核
```

辅助：`_structure_signature`（解析 `.moti` 抽元素 tag + name/id/description + reference_base 文本，得 frozenset）、`_same_template_structure`（签名相等或交集 ≥ 0.8×min 判同源）。

### 1.3 `dedup_before_install` 走 `kept` 默认保留

仅当 `_confirm_homology` 返回"可移出"时才移入隐藏回收站 `.{name}_trash_<ts>`；否则进入 `kept`（仅记录警告，不移动、不删除）。报告结构：

```python
{
  "scanned": int,
  "moved": [{path, size, sha256, mtime, reason, moved_to}],
  "kept":  [{path, size, sha256, mtime, reason}]   # 无法确认同源，默认不移动
}
```

### 1.4 `verify_unique_after_install` 同步内容级判据（一致性必要修改）

原实现：对**任何名称别名兄弟**都抛 `TemplateUniquenessError`。
问题：R23 要求"名称别名命中但内容不同→默认不移动（kept）"。若 verify 仍对 kept 兄弟报错，则这类目录永远无法安装成功，与"默认不移动"自相矛盾。

修改：verify 仅对**内容确认同源**（sha 一致 / 结构同源 / 空壳）的兄弟才判为违反唯一性；名称别名但内容独立的模板不误报。这**不削弱** A-40 对"真·重复模板"的拦截：
- 同 sha 兄弟 → 仍报错（重复版本）
- 同结构不同 sha（旧构建）→ 仍报错（旧版同模板）
- 空壳兄弟 → 仍报错（闪退嫌疑）
- 名称别名但内容明显不同 → 不误报（独立模板）

## 6. "空 Media 何时属于正常" 判据（A-42 实证 ③）

**.moti 是 ozml XML；`Media/` 目录存放该模板引用的外部媒体（图片/视频/贴图）。** 判据如下：

| 条件 | 空 Media 是否正常 | 判据 |
|------|------------------|------|
| `.moti` **不含**任何外部媒体引用（无 `<reference>` / `reference_base` / `Media/` 路径引用） | ✅ **正常** | 纯文本/形状/生成式标题，本就无媒体文件。例：T01、`2`..`50` 等 52 个目录（refMedia=no）。 |
| `.moti` **含**媒体引用（文字描边/贴图/视频层），但对应 `Media/` 缺失或为空 | ❌ **异常（闪退风险）** | FCPX 打开时尝试装载缺失媒体失败 → 崩溃。这正是 R20 坏构建 `14fa354d` 的失效模式。 |

判定方法（脚本化）：
```python
def refs_media(moti):
    txt = open(moti, encoding="utf-8", errors="ignore").read()
    return bool(re.search(r"reference_base|Media/|<reference", txt))
# 正常：media_count==0 且 not refs_media(moti)
# 异常：media_count==0 且 refs_media(moti)
```

现状：`~/Movies` 中**无任何"引用媒体却空 Media"的目录**（唯一引用媒体的 T23 其 Media=2 已填充）。故当前无空 Media 导致的闪退风险。
