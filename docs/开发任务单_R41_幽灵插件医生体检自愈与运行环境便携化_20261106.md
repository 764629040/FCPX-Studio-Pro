## 一、 任务背景与目标

用户在剪辑实战中，频繁拔插雷雳/USB 移动硬盘、迁移工程、或解压不规范模板，经常导致 Final Cut Pro 出现“红色感叹号断链”、“模板破损卡死”或“启动极慢”。
为了彻底解决这一痛点，并完成白皮书规划的创新功能壁垒，本轮聚焦：
1. **幽灵插件体检与断链自愈医生（GhostPluginDoctor.swift）**：
   - 快速诊断全盘悬空软链接（Dangling Symlink）、破损 XML 模板、丢失 Media 资源的病症；
   - 提供**一键智能重定向重连（Relink）**与**一键安全隔离（Quarantine）**，彻底消除 FCPX 红屏感叹号；
2. **多源级联便携环境探测器（AppConfig / PythonBridge）**：
   - 规范环境探测逻辑，优先检测便携式打包环境与内置依赖，消除对开发机绝对路径的硬编码依赖。

## 二、 详细设计与实现要求

### 2.1 幽灵插件智能体检引擎（`GhostPluginDoctor.swift`）

1. **三大病症深度扫描**：
   - 遍历系统与用户级 `Motion Templates.localized` 全部分类：
     - **病症 A：悬空断链（Dangling Symlink）**：检测到符号链接指向的目标路径不存在；
     - **病症 B：破损 XML 模板（Corrupted XML）**：`.moti` / `.moef` / `.motr` / `.motn` 尺寸为 0 字节、或 XML 解析语法错误、或缺少根节点；
     - **病症 C：媒体贴图断链（Missing Media）**：Motion 模板内部存在 `footage` 引用但在 `Media/` 目录下文件缺失；
2. **智能自愈与重连算法（Self-Healing Relink）**：
   - 若悬空软链接指向的盘符发生变更（如 `/Volumes/SSD` 变为 `/Volumes/SSD 1`），自动在当前已挂载的所有卷中按相同相对路径或模板名称模糊匹配探测；
   - 探测成功后，支持【一键重连修复（Relink All）】，重新生成有效的 POSIX 软链接，秒级自愈；
3. **安全隔离区（Safe Quarantine）**：
   - 对无法修复的破损模板，支持【一键安全隔离（Quarantine）】；
   - 将其移动至 `~/Movies/Motion Templates.localized/_Quarantine/`，使其从 FCPX 扫描树中隐去，杜绝 FCPX 启动卡死或红屏感叹号；
   - 隔离记录完全保留，支持【一键还原（Restore）】。

### 2.2 医生可视化控制台（`PluginDoctorDashboardView.swift`）

1. 挂载至左侧边栏【系统工具】->【🩺 幽灵插件医生】；
2. 呈现健康体检仪表盘：
   - 健康评分（如 100 分健康，或扣分告警）；
   - 三大病症统计卡片（断链数、破损数、缺图数）；
   - 详细故障列表（故障路径、病症类型、建议修复方案）；
   - 顶部快捷操作栏：【🩺 全面体检】、【⚡ 一键智能自愈】、【🛡️ 一键隔离破损】。

### 2.3 便携环境探测机制优化（D-82）

1. 优化 `AppConfig.swift` 与 `cli_bridge` 探测：
   - 级联探测链：优先内置 Frameworks/Resources -> 环境变量 -> 虚拟环境 -> 系统 Python 3；
   - 检查 psd-tools 与核心依赖完整性，并在设置中提供健康状态显示。
