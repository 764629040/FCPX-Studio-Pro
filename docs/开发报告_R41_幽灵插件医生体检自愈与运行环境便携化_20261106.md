## 一、 幽灵插件智能体检引擎实现细节

### 1.1 三大病症深度诊断算法
- **悬空断链（Dangling Symlink）**：
  - 使用 `FileManager.attributesOfItem` 检测 `typeSymbolicLink`；
  - 解析 `destinationOfSymbolicLink` 并标准化为绝对目标路径；
  - 校验 `FileManager.fileExists(atPath: resolved)`。若目标丢失，立即标记为断链病症并触发自愈候选探测。
- **破损 XML（Corrupted XML）**：
  - 针对 `.moti`、`.moef`、`.motr`、`.motn` 文件；
  - 排除目录自身（仅针对真实 XML 模板文件）；
  - 尺寸为 0 字节直接判为破损；
  - 使用 `XMLDocument(data:options:)` 解析，若解析异常或 `rootElement()` 为空或缺失，判定为语法損毁。
- **缺失媒体（Missing Media）**：
  - 正则检索 `<fileURL>(.*?)</fileURL>` 与 `<footage src="...">`；
  - 解析 `file://` 与相对路径（如 `Media/Texture.png`）；
  - 探测模板目录、`Media/` 目录以及绝对位置；若素材不存在或媒体目录内文件尺寸为 0 字节，判定为媒体缺失。

### 1.2 模糊探测与秒级重连（Self-Healing Relink）
- **路径回溯算法**：
  - 提取悬空软链接原路径的卷后相对路径（例如原指向 `/Volumes/OldSSD/Motion/Titles/Pack1`，提取 `Motion/Titles/Pack1`）；
  - 遍历当前系统所有挂载卷（`/Volumes/*`）以及额外搜索根；
  - 探测在各卷下是否存在相同相对路径或同名模板包；
  - 命中后标记 `canAutoRelink = true` 并记录 `relinkCandidatePath`。
- **原子重连机制**：
  - `relink(issue:)` 校验候选目标真实存在后，安全移除失效软链接；
  - `createSymbolicLink(atPath:withDestinationPath:)` 重建 POSIX 符号链接，耗时仅数毫秒。

### 1.3 安全隔离区与账本持久化（Safe Quarantine）
- 隔离目录：`~/Movies/Motion Templates.localized/_Quarantine/`；
- 隔离动作：`quarantine(issue:)` 将破损模板包原子化移至隔离区，并重命名附带时间戳；
- 隔离账本：在隔离区根目录保存 `quarantine_ledger.json`，完整记录原始分类路径、模板名、病症类型及隔离时间；
- 一键还原：`restore(recordId:)` 自动检查并重建原始父目录，原路移回文件，从账本中注销，实现 100% 零风险可逆。
