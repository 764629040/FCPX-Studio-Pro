## 三、工作区情境卡顿根治与响应优化

1. **排除无效二进制资源**：
   在 `TemplateTierScanner` 和 `WorkspaceProfileManager` 中加入严格过滤规则，全面排除 `.framework`、`.app`、`.pluginkit`、`.bundle`、`.lproj`、`.dylib`、`_CodeSignature`、`Contents`、`Versions`、`Resources`。只对真实包含 `.moti`、`.moef`、`.motr`、`.motn` 的工程或真实模板目录进行启停操作，杜绝文件不存在报错与 USB 外置卷主线程阻塞。
2. **整卡可点击即激活**：
   在 `WorkspaceProfileCardView` 重写 `mouseDown(with:)`，用户点击卡片任意区域均直接激活该情境，并同步触发矩阵选择。
3. **微型加载器与平滑状态回调**：
   卡片内嵌微型 `spinner`，点击即刻切换为 `⚡️ 切换中…`，激活按钮进入防重复锁定；操作通过 GCD 异步并发完成后，在主线程平滑刷新卡片徽章与顶部指标，杜绝任何假死卡顿。

## 四、macOS 官方 Dock 图标强制生效

1. **Info.plist 双键值完备**：
   ```xml
   <key>CFBundleIconFile</key>
   <string>AppIcon</string>
   <key>CFBundleIconName</key>
   <string>AppIcon</string>
   ```
2. **运行时显式注入**：
   在 `main.swift` 与 `MainWindowController.swift` 初始化首行主动执行：
   ```swift
   if let iconPath = Bundle.main.path(forResource: "AppIcon", ofType: "icns"),
      let iconImg = NSImage(contentsOfFile: iconPath) {
       NSApplication.shared.applicationIconImage = iconImg
   }
   ```
3. **LaunchServices 缓存强制刷新**：
   在构建流水线中执行：
   ```zsh
   /System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f "FCPX Studio Pro.app"
   ```
   桌面、访达、程序坞（Dock）与 DMG 安装卷 100% 点亮官方设计图标，彻底告别空白网格。
