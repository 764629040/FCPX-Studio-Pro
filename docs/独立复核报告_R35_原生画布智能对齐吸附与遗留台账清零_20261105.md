   - 点击顶部菜单【文件】→【打开 PSD 文件…】（快捷键 `⌘O`）；
   - 任意选取一个单张 `.psd` 文件，确认无阻断弹窗，并立即进入主界面解析图层。
4. **资源库归属列与操作列点验（A-66）**：
   - 切换到【资产库 (Asset Hub)】选项卡；
   - 检查「归属」列宽度充足，能清晰看到模板所在路径；
   - 检查「操作」列不再是一整列重复的下拉框：内置模板显示黄色的 `🔒 只读`，其他模板显示小巧的 `⋯` 按钮；
   - 右键点击任意模板行，核对弹出包含【移动到…】、【在 Finder 中显示】等完整功能的上下文菜单。
