4. 关键裁定：文字分布——纵向可验，横向零覆盖

4.1 你提的问题

「新夹具的 8 层文字是我用像素层占位生成的……它能验证画布尺寸、背景不越界、文字分布、缩略图比例这些几何与管道问题，但不能验证文字内容提取。」

你的自我限定方向对、但漏了一项更要紧的：你漏报的不是「文字内容」，而是「横向分布」。

4.3 两个维度的可验性裁定

维度实测可验性
纵向8 个互不相同的中心 y（321 → 1598），跨度 1277 = 画布高 66.51%可验：能检出「纵向挤成一团」或「纵向溢出」
横向8 块中心 x 恒为 540.0，跨度 0.0 = 画布宽 0.00%；尺寸组合唯一 {(520, 120)}不可验：横向零变化，任何横向压缩/拉伸/错位都检不出

4.4 为什么这是关键缺口

Round 14 定性的 A-24，其错误维度正是横向：源 PSD 竖版 1080 宽，被塞进 1920 宽的横版 comp，8 组文字被横向拉伸、挤在画布宽的 16%–37%。

而新夹具的横向跨度是 0.00%。 也就是说：

  • 如果 comp 宽度再次写错（例如又变回 1920），8 块全在 x=540 的占位图仍然通过——因为它们的横向跨度本来就是 0，写错也看不出来；
  • 你用它「验证文字分布」，实际只验证了纵向一个维度；
  • 而纵向恰恰是 A-24 当初没出错的那个维度。

一句话：用只在一个维度有分布的样本，去验证一个在另一维度出错的缺陷，逻辑上覆盖不到。

4.5 测试断言的覆盖核验

tests/test_a28_a29_thumbnail_and_fixture.py 共 12 条测试：

类别条数内容
test_28_*（缩略图）6比例保持、偏差为零、不拉伸、与源比例一致、端到端非 640×360、横版回归
test_29_*（夹具）6夹具存在、背景不越界、文字层纵向居中、无颜色噪声、旧夹具缺陷已文档化、元数据可用

6 条 A-29 测试中，没有任何一条断言横向分布。 唯一涉及分布的 test_29_text_layers_vertically_centered，从函数名到断言内容都只管纵向。

结论：当前测试套件结构性地无法捕获横向分布错误。这不是执行不力，是覆盖面缺口。

5. A-30（新，P2）：越界图层无防护，只换样本未修根因

5.1 事实

检查项实测
core/psd_parser.py 指纹未变更（本轮 2 个内容变更中不含它）
core/thumbnail.py 是否含 bbox 越界防护无（只改了缩放逻辑，未加合成前裁剪/逐层贴图）
真实畸形 PSD（背景层越界）行为仍走 psd.composite()，仍产彩条乱码

5.2 定性

A-29 的处置是更换健康样本，而非让产品能应对不健康样本：

  • 旧夹具的越界缺陷在真实用户 PSD 上依然会发生——任何人给一个背景层尺寸与画布不符的 PSD，预览图仍是乱码；
  • Round 14 §5 已用「同一层两种合成方式对照实验」证实 psd-tools 在 bbox 越界时读错像素；
  • 本轮未在合成前裁剪越界区域、也未改为逐层贴图，该缺陷对终端用户完全未消除。

A-30（P2）：合成路径缺少 bbox 越界防护，真实畸形 PSD 仍产生可见损坏的预览图。
建议：合成前将各层 bbox 与 canvas 求交后裁剪，或对越界层改用逐层 paste 并显式裁到画布内。

5.3 为什么定为 P2 而非 P1

  • 不构成闪退、不构成报错，核心链路（导入、构建、写盘）不受影响；
  • 只在源 PSD 本身畸形时触发，规范 PSD 不受影响；
  • 表现为预览图可见损坏，属交付质量 / 健壮性问题，不阻断主流程。

7. 是否需要换夹具构造方式？——需要，但理由要改

7.1 你的问法

「如果您的版式验收要求文字内容也参与，我需要换一种夹具构造方式（例如基于旧夹具重建背景层而非重建文字层），请告知。」

7.2 裁定

需要换，采纳你提的「基于旧夹具重建背景层」方案。但换的理由不是「文字内容」，是「横向分布」。

你的理由审核方裁定
为了覆盖「文字内容提取」不是必须。文字内容提取已由旧夹具的 type 层覆盖，且旧夹具缺陷已文档化，可继续承担该职责
未提到的理由：横向分布这才是必须换的原因。旧夹具 8 层文字横向中心分布在 16%–37% 区间（有真实横向分布），重建背景层后可保留这份横向几何；新夹具横向跨度为 0，永远验不出横向错误

7.3 具体方案（采纳你的思路，补齐验收口径）

基于旧夹具 vertical_wedding_9_16.psd 重建背景层：

  1. 保留原有 8 个真实 type 层（含真实文字内容、真实 bbox、真实横向分布）；
  2. 仅替换背景层为 1080×1920 纯色，bbox == (0,0,1080,1920)；
  3. 由此得到一份同时满足的夹具：背景不越界 + 真实 type 层 + 真实横向分布。

验收口径：

项断言
背景bg.bbox == (0,0,1080,1920)，仅背景层 composite 唯一色 = 1
纵向文字层中心 y 跨度 ≥ 画布高 60%
横向文字层中心 x 跨度 > 0，且与源 PSD 中心 x 跨度一致（±0.5 单位）
层类型至少 1 层为 type 层（保证文字提取路径被覆盖）
