### 1. 局域网 P2P 自发现与 TCP 套接字直传引擎 (`TeamP2PSyncManager.swift`)

## 一、 P2P 自发现协议与传输引擎设计

### 1.1 数据包协议规格与包头结构
```
+----------------+---------------+-------------------+--------------------+----------------------+
| Magic (6 bytes)| Version (4 B) | ManifestLen (4 B) | Manifest JSON (N B)| Payload Data (M B)   |
|   "FCPXPK"     | UInt32 (BE)   | UInt32 (BE)       | UTF-8 JSON         | Raw Archive Payload  |
+----------------+---------------+-------------------+--------------------+----------------------+
```

### 1.2 清单结构 (`P2PManifest`)
```swift
public struct P2PManifest: Codable {
    public var version: Int
    public var templateName: String
    public var category: String
    public var subcategory: String
    public var sha256: String
    public var payloadSize: Int
    public var senderName: String
    public var timestamp: String
    public var isPackage: Bool
}
```

### 1.3 传输安全性与 SHA-256 校验
当接收端 TCP 套接字读取完包头与 Payload 后，使用 Apple `CryptoKit` 硬件引擎计算接收数据的哈希值：
```swift
let actualHash = TeamP2PSyncManager.sha256(data: payloadData)
guard actualHash.lowercased() == manifest.sha256.lowercased() else {
    sendResponse(fd: clientFd, text: "ERR:SHA256_MISMATCH\n")
    return
}
```
校验通过后，接收端自动调用 `TemplateInstaller.installTemplates` 或 `EnvironmentCloner.importPackage` 完成无缝物理落盘，并刷新内存缓存。

## 二、 生产环境一键克隆打包器 (`EnvironmentCloner.swift`)

### 2.1 归档包目录规范 (`.fcpxpack`)
解包沙箱结构如下：
```text
ProductionEnv.fcpxpack (ZIP)
├── manifest.json                  # 全局元数据、版本、SHA-256 指纹
├── Templates/                     # 分类模板目录
│   ├── Titles.localized/...
│   ├── Effects.localized/...
│   ├── Transitions.localized/...
│   └── Generators.localized/...
├── LUTs/                          # 3D LUT 调色库 (.cube)
└── Profiles/                      # 工作区情境与预设配置
    ├── workspace_profiles.json
    └── active_profile_id.txt
```

### 2.2 冲突处理策略 (`ConflictPolicy`)
- `.overwrite`：覆盖现有模板与配置；
- `.skip`：若目标端已存在重名项则跳过，保留本地已有版本；
- `.keepBoth`：目标端重命名追加 `(副本)` 后缀保存，实现双版本共存。
