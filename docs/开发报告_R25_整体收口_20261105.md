- composite 抛错 → PIL `topil()` 回退（诚实标注 `render_method='pil_topil_fallback'`）→ 双失败返回两级原因错误

- 失败时诊断 `severity='error'`、`media_error="Media 资产生成失败: <确切原因>"`
- 机器可核查计数器 `missing_media_refs`（>0 强制 risk_assessment 高风险）

**P2-3 缺字标记只在 JSON**：`marked_text` 升为 `PSDLayerInfo` 一等字段 + `missing_glyph_layers` 计数器（与逐层 `missing_glyph_visible_marker` 严格相等）。**如实披露**：`.moti` 仍写原始 text 属 motion_builder 红线域；GUI 徽章/高亮接线归后续轮次，本轮只闭合数据层（`docs/psd_support_matrix_R25.md` 已披露）。
