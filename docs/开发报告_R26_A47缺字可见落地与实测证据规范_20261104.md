### 1.1 代码改动（`core/motion_builder.py` 文本内容段）

```diff
--- motion_builder.py@R25
+++ motion_builder.py@R26
                 # 文本内容
+                # R26-A47：缺字可见标记接进 .moti 输出层。
+                # （注释略——完整 diff 见 docs/r26_evidence/motion_builder_r26_diff_proof.txt）
+                out_text = getattr(info, "marked_text", "") or info.text
                 text_elem = layer_elem.find(".//parameter[@id=\"369\"]/text")
                 if text_elem is not None:
-                    text_elem.text = info.text
+                    text_elem.text = out_text
                 # styleRun length 同步改为按实际写出文本计算
```
