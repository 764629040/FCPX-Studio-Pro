### 1.2 五类目标值的落点（`MotiDocumentParser.parseLayer` 290–356 行已实证）

- 位置链：`属性(id=1)` → `变换(id=100)` → `位置(id=101)` → `X(id=1)` / `Y(id=2)`
- 真实节点长相（样本原文，注意是自闭合标签、`value` 在属性里）：

      <parameter name="X" id="1" flags="12901679120" default="0" value="-213.0" />
      （样本原文；自闭合标签，数值在 value 属性里）

- 数值规则：`numericValue`（623–640 行）读 `@value`，缺失才退回 `@default`。**写回只改 `@value`，不许删 `@default`。**
- 文本：`<parameter name="文本" id="369" …` 内部有 `<text>` 子节点，换行原样保留（`textContent` 642 行）。
- 可见性 / 锁定：`layer@enabled` / `layer@locked` 布尔属性。

## 3. 写回方式（硬口径，不许自选）

**单点字节替换。** 定位可以用 `XMLDocument` 走祖先链，但落笔必须回到原始字节上：

- 数值：只替换目标 `parameter` 的 `value="…"` 属性值区间
- 文本：只替换 `<text>` 的文本节点内容，并做 XML 转义（`&`、`<`、`>`）
- 布尔：只替换 `layer` 上 `enabled="…"` / `locked="…"` 属性值区间

**禁止** `XMLDocument` 整树 `xmlData` 重写后再落盘：它会重排属性顺序、丢注释、改缩进与引号风格，Motion 有可能拒载。

**必须逐项保持**：注释、`<!DOCTYPE ozxmlscene>`、tab 缩进、属性顺序、`@default` 属性、LF 换行、无 BOM、`<?xml …?>` 声明原样。

## 5. 安全口径

- 备份目录：`~/Library/Application Support/FCPXStudioPro/moti_backups/<原名>.<YYYYMMDDHHMMSS>.moti.bak`
  **不许放模板目录**——FCPX 会把 `.moti` 扩展名当模板扫进去。
- 备份先写完并 fsync，且**备份 sha256 必须等于写前 sha256**；不等就中止，不写回。
- 写入：同卷临时文件 → `FileHandle` 写 → fsync → `rename` 原子替换，保留原权限位与属主。
- 只读卷 / 无写权限：保存按钮直接禁用并给明确文案，不许写到一半。
- 写后自检：`MotiDocumentParser.parse` 重解析，五值逐项比对。任一不一致 → 从备份回填，**原文件 sha256 必须回到写前值**，并明确报错。
