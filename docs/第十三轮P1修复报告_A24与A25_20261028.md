### 1.2 修复

**`core/motion_builder.py`**

```python
def build_moti(self, layers_info, output_file_path,
               template_title="Title",
               canvas_size: Optional[Tuple[int, int]] = None) -> str:
    ...
    # A-24：写入真实画布尺寸，覆盖基准模板的硬编码值
    if canvas_size:
        cw, ch = int(canvas_size[0]), int(canvas_size[1])
        settings = new_scene.find("sceneSettings")
        if settings is None:
            settings = ET.SubElement(new_scene, "sceneSettings")
        for tag, val in (("width", cw), ("height", ch)):
            node = settings.find(tag)
            if node is None:
                node = ET.SubElement(settings, tag)
            node.text = str(val)
```

**`build_template_atomic`** 增加 `canvas_size` 参数并透传。

**`gui/main_window.py`** 两处调用链（单模板导出、批处理）均传入
`(parsed["width"], parsed["height"])`。

## 4. 关于「6 组 vs 8 层」：我先前判断错误

审核指出：**8 层才是正确的**，图层面板每组「Text NN + Title」占两行共 16 行，
面板只容得下 12 行，因此显示到 `Text 06` 就截断。

**我接受这个结论并撤回「模板滞后」的判断。** 我的错误在于：
把 UI 面板的**可见行数**当成了模板的**实际层数**，
没有交叉核对源 PSD 的 8 个文字层与画布上的对象数。

层数核对结果（复核）：

| 来源 | 文字层数 |
|---|---|
| 源 PSD `vertical_wedding_9_16.psd` | **8** |
| 画布可见对象 | **8** |
| 图层面板可见行 | 12 行 = 6 组（**截断**） |
