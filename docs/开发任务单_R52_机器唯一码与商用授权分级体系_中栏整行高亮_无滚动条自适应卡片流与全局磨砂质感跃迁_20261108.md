## 一、用户需求与现实缺陷定位

根据用户最新指令与反馈截图标注（图 1：`media_1794064875157_bc02844a.png`），当前版本存在以下 4 处亟待解决的关键问题：

1. **标注 1：机器码与商用授权体系（后台生成与端侧分级管控）**
   - 原状态卡片显示简陋硬编码，用户要求每台机器拥有独一无二的机器码，且明确授权方案（别人用此程序必须获得所有者授权）；
   - **未授权体验版**：仅允许在素材管理中心浏览与查看模板，**禁止删除**，且关闭所有高级功能；
   - **已授权旗舰版**：输入后台针对该机器码签发的唯一授权代码后，一键解锁全量高级功能（物理删除、批量导出、外置一键搬家、情境隔离、P2P 团队分发）；
   - 界面需升级为高质感磨砂设备卡片，支持一键复制机器码与即时激活，消除死黑框。
2. **标注 2：中栏分组 TableView 整行选中高亮联动变色**
   - 用户反馈：鼠标选中某一行（如“-PVFX 便签字幕”）时，仅有数量数字变色，前面的插件名称、大小等文字均无变化，缺乏整体选中感；
   - 根因：NSTableView 未实现自定义整行高亮绘制 `GroupTableRowView`，且 cellView 内各列文字未在选中态统一切换为高对比度高亮文本色（亮白/高光天青蓝）。
3. **标注 3：右栏卡片流边缘截断与彻底隐藏滚动条**
   - 用户反馈：默认窗口宽度下，右侧第三列卡片被窗口边缘生硬截断，必须拉大窗口才能看见完整卡片；且用户反感原生滚动条出现在界面上；
   - 需求：右栏卡片流网格必须实现**自适应弹性流式布局（Adaptive Fluid Grid）**，确保任意窗口宽度下卡片均完整呈现、无裁切；
   - **零滚动条平滑滚动（No Visible Scrollbars）**：在中栏和右栏彻底隐藏滑块与滑轨（使用无绘制 Scroller），但保持鼠标滚轮与触控板双指滑动 100% 顺畅。
4. **全局 UI 质感、配色与磨砂玻璃深度统一**
   - 用户反馈：中栏（界面 2）、右栏（界面 3）以及左下角“外置剪辑盘已挂载”状态框存在大面积不透明死黑硬块；
   - 需求：左下角挂载指示重构为**椭圆胶囊（Pill shape, cornerRadius = height / 2）**、半透明微光磨砂边框与渐变发光呼吸灯；中栏与右栏移除所有硬编码纯黑背景，改为统一的半透明暗色磨砂玻璃（`NSVisualEffectView`, darkAqua），与顶部导航栏融为一体；全面替换残余简陋图标为 Apple 原生 SF Symbols。

## 二、架构设计与核心实现要求

### 1. 机器唯一硬件特征码与商用授权分级管理 (`LicenseManager.swift`)
- **机器唯一特征码生成**：
  - 基于 macOS 原生 `IOPlatformUUID` 与网卡 MAC 地址，生成独一无二格式化机器码：`MAC-XXXX-XXXX-XXXX`；
- **签名校验与后台生成机制**：
  - 设计后台生成工具 `tools/generate_license.py`，使用专属私钥对输入的机器码进行防伪加密签名，生成商用许可证代码（如 `FCPX-LIC-XXXX-XXXX-XXXX`）；
  - `LicenseManager.swift` 包含公钥/校验算法，端侧对用户输入的 License Key 执行数学签名验证，验证通过存入本地持久化存储；
- **分级权限控制（Feature Gate）**：
  - `LicenseManager.shared.isProLicensed: Bool`
  - 基础体验版：
    - 素材管理浏览、预览：✅ 允许；
    - 模板物理移入废纸篓：❌ 拦截并提示“未激活商业授权，删除功能已锁定”；
    - 一键批量导出全套模板：❌ 禁用；
    - 外置一键搬家与软链接迁移：❌ 禁用；
    - 多工作区情境隔离快速切换：❌ 禁用；
    - 局域网 P2P 团队克隆与分发：❌ 禁用；
  - 商业旗舰版：全量功能 100% 解锁。
- **左上角品牌授权卡片 UI**：
  - 机器码标签 + 「📋 复制」小按钮；
  - 授权状态徽章：`🟡 试用体验版` / `🟢 永久商用授权`；
  - 「🔑 激活授权」按钮：点击就地展开/弹出内嵌激活码输入框，输入后立即生效。

### 2. 中栏 TableView 自定义整行高亮 (`GroupTableRowView`)
- 新建 `GroupTableRowView: NSTableRowView`：
  - 重写 `drawSelection(in dirtyRect: NSRect)`，绘制微光圆角背景矩形（深邃高透蓝光晕 `NSColor(calibratedRed: 0.18, green: 0.48, blue: 0.95, alpha: 0.32)` + `0.5pt` 描边）；
  - `drawBackground(in dirtyRect: NSRect)` 保持透明，不遮挡底层磨砂穿透；
- `tableView(_:viewFor:row:)` 联动：
  - 当 `row == selectedGroupIndex` 时，整行文本全部同步切换为高亮色：
    - `groupName`：加粗纯白；
    - `groupCount`：高光天青蓝胶囊徽章；
    - `groupSize`：高亮银白；
    - `groupTier`：微光徽章 + 醒目「▶」指示箭头；
  - 在 `tableViewSelectionDidChange` 中触发整行重绘。

### 3. 右栏自适应弹性卡片流与无滚动条平滑滚动 (`InvisibleScroller`)
- **自适应卡片流（Adaptive Fluid Grid）**：
  - 重构 `reloadCardGrid`：不再使用生硬写死的卡片宽度与列数；
  - 根据 `cardGridScrollView.contentView.bounds.width` 动态计算：
    - 计算列数 `cols`（最小 2 列，最大 4 列）；
    - 动态计算每列卡片宽度 `cardW = (availableW - margin * 2 - CGFloat(cols - 1) * spacing) / CGFloat(cols)`；
    - 保证右侧预留 16pt 呼吸边距，彻底消除右侧第 3 列被窗口边缘截断的问题！
- **零滚动条平滑滚动（No Visible Scrollbars）**：
  - 实现 `InvisibleScroller: NSScroller`：重写 `draw(_:)`、`drawKnob()`、`drawKnobSlot(in:highlight:)` 均为空实现；
  - 将 `groupScrollView.verticalScroller = InvisibleScroller()` 与 `cardGridScrollView.verticalScroller = InvisibleScroller()`；
  - 界面上完全看不到任何原生滑轨和滑块，但触控板双指滑动与鼠标滚轮 100% 保持原生顺畅滚动！

### 4. 全局磨砂玻璃质感、椭圆胶囊与配色深度统一
- **左下角外置挂载指示**：
  - 重构为精致的**椭圆胶囊 Pill Shape**（`layer.cornerRadius = 22`，高度 44pt）；
  - 磨砂半透明背景（`NSColor(white: 0.12, alpha: 0.45)`）+ `0.8pt` 亚光微光融合边框；
  - 动态呼吸灯指示点 + Apple 原生 SF Symbol `externaldrive.fill` 图标；
- **中栏与右栏磨砂统一**：
  - 移除所有硬编码的纯黑不透明背景（`alpha 0.90` / `alpha 1.0`）；
  - 统一为半透明磨砂质感（`alpha 0.40 ~ 0.50` 结合底层 `NSVisualEffectView` 穿透）；
  - 分类胶囊栏、面包屑栏、工具栏统一圆角与亚光微光边框，与整个深色磨砂系统完全契合。
