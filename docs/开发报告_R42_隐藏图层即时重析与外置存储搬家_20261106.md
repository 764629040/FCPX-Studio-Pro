## 一、 A-72 修复细节：解耦早退与即时响应

### 1.1 `MainWindowController.swift` 早退解耦
在旧实现中，`parsePSD` 在路径不变且 `canvasView.layers` 非空时直接退出，导致用户在 UI 上点击复选框时虽然改变了 `includeHiddenLayers`，但被 `currentPsdPath == path` 拦截而无法重新发起解析。

在 R42 中重构为：
```swift
/// R33 / A-70 / R42 / A-72：切换「显示隐藏图层」→ 立即以 force=true 重新解析当前文件
public func setIncludeHiddenLayers(_ on: Bool) {
    guard includeHiddenLayers != on else { return }
    includeHiddenLayers = on
    parseCurrentFile(force: true)
}

/// R42 / A-72：核心解析入口，解耦早退逻辑。当 force=true 时强制发起重新解析
public func parseCurrentFile(force: Bool = false) {
    let path: String
    if let curr = currentPsdPath, !curr.isEmpty {
        path = curr
    } else {
        let row = psdTableView?.selectedRow ?? -1
        if row >= 0 && row < psdFiles.count {
            path = psdFiles[row]
        } else if let first = psdFiles.first {
            path = first
        } else {
            return
        }
    }

    if !force && currentPsdPath == path && !canvasView.layers.isEmpty {
        return
    }
    currentPsdPath = path
    let wantsHidden = includeHiddenLayers

    DispatchQueue.global(qos: .userInitiated).async { [weak self] in
        let parseResult = PSDParserSocket.shared.parsePSD(at: path, includeHidden: wantsHidden)
        DispatchQueue.main.async {
            guard let self = self,
                  self.currentPsdPath == path,
                  self.includeHiddenLayers == wantsHidden else {
                return
            }
            // 更新画布、属性栏并触发 onParseCompleted 回调...
        }
    }
}
```

### 1.2 `ResourceCardView.swift` 启停直连与 `.disabled` 徽章
- 将 `TemplateInstaller` 封装为单例 `TemplateInstaller.shared`，暴露 `toggleTemplate(item: TemplateItem) -> TemplateItem?` 接口。
- `ResourceCardView` 内部增加 `disabledBadgeLabel`：
  - 正常启用时隐藏；
  - 禁用时显示 `⚪️ 已停用`，卡片透明度降为 `0.55`。
- 点击卡片右下角 Toggle 按钮时直连底层安装器重命名磁盘文件夹，即时局部更新卡片 UI 与状态，避免大面积重新计算带来的界面闪烁。

## 二、 A-73 修复细节：守恒口径归正与消除假告警

### 2.1 Python `core/psd_parser.py` 统计归正
当 `include_hidden=True` 时：
1. 遍历隐藏图层并生成预览位图贴图后，将其图层信息存入 `layers_info`（在列表中真实呈现）；
2. 其处置口径标记为 `degraded`（位图降级输出）；
3. 统计指标调整：
   - `output_layer_count = len(layers_info)`（等于 `preserved + degraded`）；
   - `effective_hidden_ignored = 0`（隐藏层已被真实输出，不再视为被忽略）；
   - `ignored_count = background_ignored + effective_hidden_ignored + ...`（仅剩 1 个底板层）；
   - `ignored_summary` 生成精确描述：`"已忽略 1 层（1 个底板）。当前列表已展开 12 层（含 11 个隐藏预览层）。"`。
4. 校验公式严格闭合：
   - 守恒定律：$13 = 0 + 12 + 1 + 0$（`input == preserved + degraded + ignored + failed`，`conservation_holds = True`）；
   - 输出吻合：`output_layer_count == 12`。

### 2.2 `ParseDiagnostics.swift` 诊断文案适配
移除在勾选隐藏层后的多余引导文案：
```swift
if counts.hidden > 0 && counts.preview == 0 {
    warnings.append("本文件含 \(counts.hidden) 个隐藏图层，已按规范跳过；勾选「显示隐藏图层」可查看")
}
```
彻底消除了勾选状态下依然出现自相矛盾黄色告警的缺陷。

## 三、 对标嘉星 2.app：存储与搬家中心

### 3.1 架构设计
- **`TemplateMigrator.swift`**：
  - `listMountedVolumes()`：扫描系统已挂载的 `/Volumes` 外部驱动器，过滤只读与系统引导镜像；
  - `calculatePhysicalSizeBytes(atPath:)`：穿透软链接，精确计算本地磁盘的实际物理块占用与目标符号链接状态；
  - `scanStorage()`：扫描系统默认 `~/Movies/Motion Templates.localized` 及各个分类（Titles / Effects / Generators / Transitions），产出聚合概览对象 `StorageOverview`；
  - `migrateEntireLibrary(...)` & `restoreEntireLibraryToInternal(...)`：支持全量原子搬迁与原路无损还原；
  - `migrateCategory(...)` & `restoreCategory(...)`：支持细粒度分类级搬迁与还原。
- **`StorageMigrationDashboardView.swift`**：
  - 采用 Pro 级深色视觉设计，与 FCPX 主界面完全一致；
  - 包含 4 张指标卡片、外置卷下拉选择框、一键全量搬迁/还原主操作按钮、各分类明细 TableView（含分类名称、物理大小、当前存储位置状态、行内独立操作按钮）。

### 3.2 侧边栏与主窗口无缝联动
