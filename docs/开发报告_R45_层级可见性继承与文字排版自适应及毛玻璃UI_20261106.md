## 一、工程背景与攻坚目标

针对用户真机反馈与实际工程痛点，本次 R45 轮次完成了五大关键模块的深度攻坚与架构重塑：
1. **层级可见性继承（Root Cause 根治）**：解决在打开包含图层组的 PSD（如 `被托付的光.psd`）时，隐藏组内的所有子图层被全部作为可见层展开并相互堆叠在画布上的问题；
2. **文字排版边界自适应（根治文字截断与漏字）**：解决超大字号（如 429pt）以及多行文本中，CoreText 因机械采用位图包围盒导致首行被提前折行、“付”与“的光”字符被裁剪吞掉的问题；
3. **表头眼睛总控按钮（一键全选 / 全部隐藏）**：在检查器图层列表表头实现一键全显/全隐总控，并即时联动画布刷新；
4. **现代 macOS Pro 哑光半透明毛玻璃 UI 系统重塑**：启用 `.fullSizeContentView` 现代浸润式窗口架构与透明标题栏，顶栏、左侧列表栏、右侧检查器全面升级为 `NSVisualEffectView`（背向毛玻璃、暗黑外观、`.sidebar` 材质），全面以 Apple 原生 SF Symbols 替换 Emoji；
5. **新增【🪞 原稿直观对比】功能（总指挥追加指令）**：底层提取并导出 PSD 完整成图，画布支持三种对比模式（中轴卷帘对比 Split Curtain Divider、并排双画板对比 Side-by-Side、长按 ⌥ 键瞬时透视原图 Peek Hold）。

## 二、核心技术实现与源码变更

### 1. `core/psd_parser.py` & `core/cli_bridge.py`
- 引入递归层级可见性检测函数 `layer_is_effectively_visible(layer)`：优先调用 `psd-tools` 的 `layer.is_visible()`（内置递归向上检测 parent 的 visibility），在底层环境降级时自动沿 parent 链回溯；
- 在默认 `include_hidden=False` 下，任何父组被隐藏的图层均判定为隐藏层（归入 `hidden_layers_count`），不作为可见层加载；在 `include_hidden=True` 下作为带有 `visible=False` 的贴图预览层加载；
- 增加 PSD 完整成图导出支持：调用 `psd.composite()` 导出 `original_composite.png`，并在输出 JSON 中沉淀 `original_composite_path`。

### 2. `InfiniteCanvasView.swift`
- **文字排版边界自适应**：
  在 `layerVisualSize(for:)` 与 `drawTextLayer` 中，根据富文本属性字串调用 `astr.boundingRect(with: CGSize(width: max(bw * 2.0, 4000), height: 10000), options: [.usesLineFragmentOrigin, .usesFontLeading])` 动态测算自然排版空间：
  ```swift
  let drawW = max(bw, ceil(neededSize.width) + 24)
  let drawH = max(bh, ceil(neededSize.height) + 24)
  let textRect = CGRect(x: -drawW / 2, y: -drawH / 2, width: drawW, height: drawH)
  ```
  彻底杜绝大字号多行文本（“被托付的光”全 5 个字）在首行因宽度不足折行被 CoreText 截断的缺陷。
- **直观对比模式**：
  支持 `ComparisonMode` 枚举（`.off`, `.splitCurtain`, `.sideBySide`, `.peekHold`）；
  实现可拖拽的 3D LUT 风格中轴卷帘分割线（neon cyan 高光与双向控制手柄）；
  支持并排双画板联动，与 ⌥ 键瞬时透视。

### 3. `InspectorView.swift`
- 面板升级为 `NSVisualEffectView`（`.sidebar` 材质，`.behindWindow` 混合模式，暗黑 Pro 外观）；
- 可见性表头列 `colVis` 配置 SF Symbol `eye` 矢量图标与 ToolTip；
- 实现 `toggleAllVisibility()`：若列表中有任何可见层则一键全隐，若全为隐藏则一键全显，联动 `onAllVisibilityToggled` 与画布即时刷新；
- 表头添加 `NSClickGestureRecognizer` 与 `tableView(_:didClick:)` 双重响应；
- 全面以 SF Symbols 替换 Emoji：`eye`/`eye.slash`、`lock.fill`/`lock.open`、`text.aligncenter`/`arrow.up.and.down.text.horizontal`、`square.and.arrow.down`、`arrow.up.forward.app`。

### 4. `MainWindowController.swift`
- 窗口增加 `.fullSizeContentView` 样式，`titlebarAppearsTransparent = true`；
- TopBar 升级为 `NSVisualEffectView`；
- 顶部工具栏集成对比模式分段控制器（`comparisonSegmentedControl`），一键切换画板/卷帘/并排/透视；
- 引擎切换分段控制器配备 SF Symbols（`slider.horizontal.3`, `square.stack.3d.up`）。
