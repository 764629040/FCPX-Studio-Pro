## 2. 根因

同一控件组被**三条路径各自更新**，从无任何路径反向同步预设下拉框：

| 路径 | 旧行为 | 缺陷 |
|---|---|---|
| `_on_preset_changed` | 写输入框、写按钮（带后缀）、设画板 | 正确，但不反向同步（本身即权威源） |
| `_on_custom_size_changed` | 写按钮（**无后缀**）、设画板 | **A-17** 文案缺后缀 |
| `_on_toggle_orientation` | 仅交换 W/H 两个数值 | **A-12** 下拉与按钮均未更新，标签与画板脱节 |

`_on_toggle_orientation` 交换数值时会触发 `valueChanged` → `_on_custom_size_changed`，
但该函数只改按钮文案、不改下拉框，因此下拉框永远停留在旧标签。

**架构层面根因**：缺少单一尺寸入口，状态更新逻辑分散在三个函数中，必然产生不一致。

## 3. 修复（`gui/canvas_view.py`）

### 3.1 新增唯一尺寸入口

```python
def _apply_resolution(self, w: int, h: int, sync_preset: bool = True):
    """唯一尺寸入口：输入框、方向按钮、预设下拉、左右画板同步更新"""
    # 1. 输入框（阻断信号，避免递归）
    for spin, val in ((self.spin_w, w), (self.spin_h, h)):
        spin.blockSignals(True); spin.setValue(val); spin.blockSignals(False)
    # 2. 方向按钮（统一带画幅后缀）
    self.orient_btn.setText(self._orientation_button_text(w, h))
    # 3. 预设下拉反向同步
    if sync_preset:
        self._sync_preset_combo(w, h)
    # 4. 两侧画板
    self.left_canvas.set_artboard_resolution(w, h)
    self.right_canvas.set_artboard_resolution(w, h)
```

### 3.2 新增下拉反向同步（A-12）

```python
def _sync_preset_combo(self, w: int, h: int):
    """按真实宽高对齐下拉项；无精确匹配则落到"自定义分辨率..." """
```

### 3.3 新增按钮文案统一（A-17）

```python
@staticmethod
def _aspect_suffix(w, h) -> str:
    """由真实宽高约分推导，如 (1920,1080) -> (16:9)，(1080,1920) -> (9:16)"""

def _orientation_button_text(self, w, h) -> str:
    """方向 + 真实比例后缀；方形为「方形 (1:1)」"""
```

### 3.4 三条路径与外部调用全部收口

| 入口 | 修改后 |
|---|---|
| `_on_preset_changed` | `_apply_resolution(w, h, sync_preset=False)`（预设即权威源） |
| `_on_custom_size_changed` | `_apply_resolution(w, h, sync_preset=True)` |
| `_on_toggle_orientation` | `_apply_resolution(h, w, sync_preset=True)` |
| `set_artboard_resolution`（外部） | `_apply_resolution(width, height, sync_preset=True)` |
