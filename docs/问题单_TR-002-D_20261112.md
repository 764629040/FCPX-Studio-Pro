## 2. 逐条详情

### BUG-4D-1｜严重｜英文参数链模板 X/Y 假 0.0 且不可写

**现象**

打开 564 层第三方模板（`~/Movies/Motion Templates.localized/Titles.localized/-PVFX便签字幕/10 字母/10 字母.moti`，`11464903 B` / 3840×2160）进入编辑态：

- 右栏 X / Y 显示 `0.0` / `0.0`，但该层真实位置不是 0（参数实际存在于 `Properties / Transform / Position / X|Y`）。
- 改 X 后点保存，被 `verifyReadback` 判为不一致并**安全回填**（文件 sha 回到写前），用户只看到「写后读回不一致，已回填」，没有任何解释。

**根因（复核已定位）**：`MotiDocumentParser` 只按中文链 `属性(1)/变换(100)/位置(101)` 取值；字节扫描侧已支持双语，但 parser 侧不读英文链 → 读回恒 `0.0`，与写入值不可能一致 → 必然回填。

**复现步骤**

1. `cp` 上述模板到 `/tmp/x.moti`，记 `shasum -a 256`。
2. 起交付包：`FCPXStudio --edit-moti /tmp/x.moti --edit-moti-auto-save --edit-moti-auto-confirm --edit-moti-layer 0 --edit-moti-x 100`
3. 观察右栏 X/Y 显示值，以及 stdout 是否出现「写后读回不一致，已回填」。

**期望结果（可判定）**

- 检测到该层参数链**不是**中文链时：X / Y 输入框置灰只读，属性区出现一行明确提示，文案固定为
  `该模板参数链非本工具格式（Properties/Transform/Position），X/Y 不可写`
- **不得**把 `0.0` 当作真实值显示（显示 `—` 或置灰空值均可，二者择一，不许显示 0.0）。
- 保存按钮在只有 X/Y 改动时禁用；若同时改了文本/可见/锁定，只允许写这三项，X/Y 不进 ops。

**判定标准**

- 打开该模板并截图：X/Y 灰、提示文案逐字存在、无 `0.0`。
- 用本单第 4 节的复现命令跑一遍：stdout **无** `SAVE_OK`、副本 sha 与写前相同（若仅 X/Y 改动）。
- 8 层中文链样本回归：X/Y 仍可写，读回 5 值全 OK。

### BUG-4D-3｜一般｜交付包内含 7 个无人值守写盘开关

**现象**

交付包二进制中可通过命令行参数直接触发**跳过确认弹窗 + 自动写盘**：

`--edit-moti-auto-save`、`--edit-moti-auto-confirm`、`--edit-moti-layer`、`--edit-moti-x`、`--edit-moti-y`、`--edit-moti-text`、`--edit-moti-enabled`、`--edit-moti-locked`

复核已确认：**只在命令行显式传参生效、UI 无任何入口**，风险有限；但与 TR-022「验证开关留生产二进制」同一类问题，且这批开关会**无确认地覆盖用户模板**。

**期望结果（二选一，推荐 A）**

- A（编译期隔离）：用条件编译把自动化参数整段包起来；交付包正常启动时，任何参数组合都无法触发自动写盘。取证改用 `tools/` 下的 debug 构建产物。
- B（双重门）：参数 + 环境变量双门（例如必须同时存在 `TR002C_AUTOMATION=1`），缺一即忽略；并在 `安装说明.txt` 之外的项目文档标注「仅内部取证用」。

**判定标准（行为判定，不靠 strings）**

用交付包（重签后的最终包）跑：

```
FCPXStudio --edit-moti /tmp/y.moti --edit-moti-auto-save --edit-moti-auto-confirm \
  --edit-moti-layer 0 --edit-moti-x 100 --edit-moti-text "越权测试"
```

`/tmp/y.moti` 的 sha256 **必须与写前相同**，stdout **无** `SAVE_OK`，且不产生新的 `moti_backups/*.bak`。
若选 B，则上述命令同样必须不写盘，只有额外加 `TR002C_AUTOMATION=1` 才允许。

**现象**

**判定标准**

- 报告文本含两个数字，且明确「以交付包为准」。
- 交付包实测仍满足：8 层 ≤ 3000ms、564 层 ≤ 10000ms。
