## 二、详细任务分解与代码规范

### 1. 修复 A-72：UI 隐藏图层开关即时重析 (`MainWindowController.swift`)
- 抽出 `parseCurrentFile(force: Bool)`：
  - 当 `force == true` 时，无视 `currentPsdPath == path && !canvasView.layers.isEmpty` 早退守卫；
  - `setIncludeHiddenLayers(_ on: Bool)` 翻转时直接调用 `parseCurrentFile(force: true)`；
  - 卡片网格视图 `ResourceCardView` 的卡片启用/禁用开关直连 `TemplateInstaller.shared.toggleTemplate`，且翻转后即时更新卡片状态与徽章，无需整页卡顿重刷。

### 2. 修复 A-73：`include_hidden=True` 统计口径收紧 (`core/psd_parser.py`)
- 当 `include_hidden=True` 时：
  - `output_layer_count` 必须等于实际输出的图层数（如 `镇雄.psd` 为 12）；
  - `ignored_count` 仅统计真正被过滤的非有效层/底层底板；
  - 严格保持 `total == visible_rendered + hidden_rendered + dropped_background` 守恒；
  - 同步更新 Python 测试用例与 Swift 解析模型，消除假告警。

### 3. 外置盘存储空间与一键搬家管理 (`StorageMigrationDashboardView.swift` & `TemplateMigrator.swift`)
- 整合 `TemplateMigrator.swift` 与 `SymlinkSocket.swift`：
  - 分析 `~/Movies/Motion Templates.localized` 物理占用；
  - 列出当前已挂载的外置磁盘卷（如 `/Volumes/...`）；
  - 提供【一键搬家至外置卷】功能：物理搬移并自动建立符号链接；
  - 提供【一键还原至内置系统盘】功能：安全回迁；
  - 侧边栏常驻显示存储空间占用与搬家管理。

### 4. 修复 A-74 / A-75：文档与台账合规
- 修正 `FCPX_Studio_Pro/docs/03_项目进度总清单_指针.md`，精确同步行数与 SHA256；
- 登记 R40、R41，措辞客观中立。
