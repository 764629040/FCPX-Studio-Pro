## 一、 核心功能实现细节

### 1.1 原生画布智能对齐吸附系统（D-73）

- **对齐目标采集**：
  在 `InfiniteCanvasView.swift` 中实现 `calculateSnap` 核心吸附引擎，动态采集 4 类对齐目标：
  1. **画板几何中心**：$X = 0, Y = 0$；
  2. **广播安全区**：90% 动作安全框（$X = \pm 0.45 \times W, Y = \pm 0.45 \times H$）与 80% 标题安全框（$X = \pm 0.40 \times W, Y = \pm 0.40 \times H$）；
  3. **其他可见图层**：所有 `layer.visible == true` 且非当前拖动图层的左右边界、上下边界与中心点（基于真实 `layerVisualSize`）；
- **磁吸判定与优先级仲裁**：
  - 吸附判定公式：屏幕物理阈值 $6.0$ 像素对应画布空间阈值 $\text{threshold} = 6.0 / \text{zoomScale}$；
  - 当前图层 3 点（左、中、右 / 顶、中、底）探测所有参考点，选取 $|\Delta| \le \text{threshold}$ 且距离最小的吸附偏移量；
  - 当图层间距离与画板中心距离出现相同微小偏差时，优先吸附画板几何中心与安全区；
  - 按住 ⌘ (Command) 键时，`disableSnapping` 触发，完全跳过吸附并清空参考线。
- **高光对齐参考线视觉渲染**：
  - 定义结构体 `AlignmentGuide`（包含方向、固定坐标、起点跨度、终点跨度与颜色）；
  - 画板中心与安全区采用高光金色（`NSColor(calibratedRed: 1.0, green: 0.8, blue: 0.0, alpha: 0.95)`）；
  - 图层边界与中心对齐采用高光青色（`NSColor(calibratedRed: 0.0, green: 0.85, blue: 1.0, alpha: 0.95)`）；
  - 线条样式采用高清虚线，跨度覆盖对齐图层两端最小/最大外延（+24px 安全边距）；
  - 鼠标松开（`mouseUp`）立即清空 `activeGuides` 并触发 `needsDisplay = true`。

### 1.2 历史台账闭环治理

- **A-62（⌘O 单文件打开）**：

  - 原生壳在接收 `--open <path>` 参数时，直接进入主界面并解析该文件，真机实测输出包含 8 个图层树的完整规格。
