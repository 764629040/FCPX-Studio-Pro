# 开发任务单 R34 —— 文字图层位置不精确与重叠挤压根治（P1 / A-71）

- 出具方：项目总指挥 / 架构设计
- 日期：2026-11-05
- 交付对象：**开发 AI（海鸥）**
- 优先级：**P1 阻断级缺陷**（直接影响模板版式美观度与商用交付质量）

---

## 一、 缺陷背景与现象（A-71）

用户在桌面端真机点验 R33 交付成果时明确反馈：
> “PSD 里面的文字图层（不管是竖版还是横版），在通过程序转出来的时候，位置还不是很精确。
> 有些本来是有间距的图层，导入进来以后，就会随机出现挤压、叠在一起的情况。反正就是说，他转这个 PSD 转 Motion 文件的字幕的位置，文字的位置不精确。”

---

## 二、 根因深度剖析（三段链路）

经总指挥针对真实婚礼纪实字幕样稿（`01.psd`）与底层代码比对，确认以下三段硬伤：

### 2.1 链路①：`psd_parser.py` 丢失段落对齐与真实行距
- `psd_parser.py:1200-1215` 仅提取了 `font_size` 与 `tracking`，**完全未读取** `layer.engine_dict["ParagraphRun"]` 中的段落对齐属性 `Justification`（0=左对齐, 1=右对齐, 2=居中对齐）；
- 丢失了 `layer.engine_dict["StyleRun"]` 中的真实行距 `Leading`（`01.psd` 实测中文为 46.5，英文为 20.833），代码硬编码 `line_spacing = 1.0`。

### 2.2 链路②：`motion_builder.py` 写入对齐缺失与坐标未补偿
- 在 Apple Motion 中，参数 id="401" 决定了对齐模式（1=Left, 2=Center, 3=Right）；
- 原型模板 `reference_base.moti` 中不同图层的初始对齐各异（`Text 01` 为居中, `Text 04` 为左对齐）；
- `motion_builder.py:417` 将所有图层的包围盒中心坐标 `motion_pos` 统一填入 `parameter 101`。对于左对齐图层，Motion 会将中心坐标误作为行首基线，导致图层向右平移半个身位，直接撞入右侧图层造成挤压。

### 2.3 链路③：`InfiniteCanvasView.swift` 伪假宽度公式导致边界严重膨胀
- `InfiniteCanvasView.swift:255-265` 采用极其粗暴的估算公式：
  ```swift
  let totalH = lineCount * lineHeight
  let maxLineLen = lines.map { $0.count }.max() ?? 1
  let totalW = CGFloat(maxLineLen) * fontSize * 1.1
  let textRect = CGRect(x: -totalW / 2, y: -totalH / 2, width: totalW, height: totalH)
  ```
- 以 `THE BRIDE` 为例，真实 PSD 物理包围盒为 14×115，但伪公式计算出宽度为 165，旋转 90° 后高度变为 165，白白向外膨胀了整整 50 像素，强制覆盖并挤压相邻图层；
- 绘制时强制采用 `.center`，忽略了 PSD 原生左对齐或右对齐。

---

## 三、 修复要求

### 3.1 `core/psd_parser.py`
1. 从 `layer.engine_dict` 提取段落对齐：
   - 读取 `ParagraphRun` 中的 `Justification`：
     - `0` -> `"left"`
     - `1` -> `"right"`
     - `2` -> `"center"`
     - 其它 -> `"left"`
   - 记录进 `PSDLayerInfo.alignment`；
2. 提取真实行距 `Leading`（若存在且非 AutoLeading，存为浮点数，否则默认 `fontSize * 1.2`），存入 `PSDLayerInfo.line_spacing`；
3. 将 `alignment` 与 `line_spacing` 完整序列化到桥接 JSON。

### 3.2 `core/motion_builder.py`
1. 同步更新 `parameter id="401"`（段落对齐）：
   - `"left"` -> 写入 value=`"1"`
   - `"center"` -> 写入 value=`"2"`
   - `"right"` -> 写入 value=`"3"`
2. **锚点坐标补偿**：
   - 保持中心坐标注入规范，若为非居中对齐，确保 Motion 中的段落和基线锚点与 PSD 一致，消除图层相互侵入。
3. 现有的 305 项单元测试保持 100% 通过。

### 3.3 `InfiniteCanvasView.swift` & `LayerModel.swift`
1. `LayerModel.swift` 增加 `alignment: String`（默认 "center"）与 `lineSpacing: Double` 字段，并在 `PSDParserSocket.swift` 解析中完成反序列化；
2. `InfiniteCanvasView.swift`：
   - 彻底废除 `maxLineLen * fontSize * 1.1` 伪假公式；
   - 文本图层按真实 `psdBBox`（`W = max(1, b[2]-b[0])`, `H = max(1, b[3]-b[1])`）建立绘制矩形；
   - 设置对应的 `style.alignment`（`.left` / `.center` / `.right`）；
   - 旋转与居中变换统一基于包围盒几何中心，消除重叠。
3. 重新编译原生应用并更新签名：`FCPX Studio Pro.app`。
