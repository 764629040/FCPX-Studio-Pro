## 一、 核心系统实现细节

### 1.1 `LibraryCleaner.swift` 资源库深度穿透与安全瘦身引擎

- **多层级包结构穿透算法**：
  - Final Cut Pro 的资源库包表面为单一 `.fcpbundle` 文件夹包，内部实际组织为：
    ```
    LibraryName.fcpbundle/
    ├── CurrentVersion.flexolibrary      (数据库，必须严格保护)
    ├── Settings.plist                   (配置，必须严格保护)
    ├── __Temp / __AsyncCopying          (临时缓存，可安全瘦身)
    └── [EventName]/                     (事件目录)
        ├── CurrentVersion.fcpevent      (事件数据库，必须严格保护)
        ├── Original Media/              (拍摄原片，绝对红线！严禁触碰！)
        ├── Transcoded Media/
        │   ├── Proxy Media/             (代理素材，可安全瘦身)
        │   └── High Quality Media/      (优化素材，可安全瘦身)
        ├── Render Files/
        │   ├── High Quality Media/      (高画质渲染缓存，可安全瘦身)
        │   ├── Peaks Data/              (波形数据，可安全瘦身)
        │   └── Thumbnail Media/         (缩略图，可安全瘦身)
        ├── Analysis Files/              (防抖与光流，可安全瘦身)
        └── Shared Items/                (历史导出残留，可安全瘦身)
    ```
  - `LibraryCleaner.analyzeBundle(at:)` 穿透以上两级目录结构，使用 `FileManager.enumerator` 精确统计各分类字节体积与文件计数。

- **三层严密安全防御机制**：
  - **防线 1（扫描候选隔离）**：在分类扫描时，`Original Media` 目录仅累加其体积至 `originalMediaSizeBytes`，绝对不放入任何待清理路径数组中；
  - **防线 2（清理入口拦截）**：在 `safeClean` 执行函数中加入硬编码防御网：
    ```swift
    guard !dirPath.contains("Original Media") else {
        errors.append("【安全拦截】检测到原始素材路径 \(dirPath)，触发最高防线中止！")
        continue
    }
    guard !dirPath.hasSuffix(".fcpevent") && !dirPath.hasSuffix(".flexolibrary") else {
        errors.append("【安全拦截】检测到项目数据库，触发最高防线中止！")
        continue
    }
    ```
  - **防线 3（macOS Trash 移入保护）**：严禁调用任何 `removeItem` 或 `unlink`。一律通过 `try FileManager.default.trashItem(at: dirURL, resultingItemURL: &resultingURL)` 将缓存目录整块安全推入 macOS 废纸篓。剪辑师若有需要，可在访达废纸篓中随时右键“放回原处”。

### 1.2 `CleanerDashboardView.swift` 瘦身医生控制台

- **左右双栏交互设计**：
  - **左栏（资源库列表）**：采用 `NSTableView`，呈现资源库图标、名称、总占用体积、可瘦身体积以及醒目的 `🛡️ 原始素材安全` 状态；
  - **右栏（详情与交互）**：
    - 呈现资源库物理绝对路径；
    - **`LibraryStorageBarView` 动态比例条**：以绿色区块呈现原始素材占比，橙黄色呈现可瘦身缓存占比；
    - **细项勾选列表**：每个缓存分类配备独立复选框、彩色徽标与安全说明（如“非破坏性。FCPX 在播放或导出时可随时按需重新渲染”）；
    - **操作栏**：提供【⚡ 一键安全瘦身 (Safe Clean All)】、【🧹 清理所选缓存】与【🔍 在访达中定位】。
- **拖拽即刻体检**：
  - 视图注册 `.fileURL` 拖拽协议，剪辑师从访达拖入任何 `.fcpbundle` 资源库即可触发瞬间解析与列表插入。

### 1.3 `TemplateRenameManager.swift` 模板本地化中文重命名引擎

- **Final Cut Pro 国际化标准协议**：
  - FCPX 使用 Apple 规范的 `.localized/<language>.strings` 机制将目录名映射为 UI 显示名；
  - 针对简体中文环境，同时维护 `.localized/zh_CN.strings` 与 `.localized/zh-Hans.strings`；
  - 字典格式严格按 Apple Property List 标准序列化：
    ```strings
    /* FCPX Studio Pro 本地化字典 (自动对标 FCPX / Motion 规范) */
    "Modern_Title_01" = "中式婚礼优雅字幕";
    ```
- **增量更新与现有键值保护（`TemplateStringsMutationWriter`）**：
  - 写入前先通过 `parseStringsFile` 提取已存在的字典，保留同分类下其他模板的别名映射；
  - 仅对目标模板键值进行 Upsert（新增或覆写）；
  - 支持调用 `removeLocalizedName` 干净清除别名，无缝回退至默认物理名称；
- **防断链核心机制**：
  - 模板内部的 `.moti`、`.motn`、`.mota` 工程文件物理名称与 XML 引用 ID 保持不变；
  - 用户在 Final Cut Pro 时间线上剪辑时，引用的依然是稳定的底层资源，彻底杜绝 FCPX 红色问号与感叹号断链！

### 1.4 `AssetHubView.swift` 四大超级业务中心整合

- 顶层 Tab 控制器全面由 3 项扩容至 4 项：
  - `labels: ["🎨 模板插件管理", "🎞️ 3D LUT 调色与分屏", "🎵 影视级音效库", "🧹 工程瘦身清理"]`

- 触发时弹出 `NSAlert` 交互输入框，预填当前中文别名，支持一键保存或一键还原；
- 模板名称列以高亮青色呈现 `中文别名 (OriginalName)` 复合格式，让剪辑师一目了然。
