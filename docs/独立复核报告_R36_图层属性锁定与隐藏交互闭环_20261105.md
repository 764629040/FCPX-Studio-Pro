## 五、用户真机验收与交互体验清单

请用户在 macOS 图形桌面环境下双击启动 [`FCPX Studio Pro.app`](file:///Volumes/摄影师工具箱128GB/未命名文件夹/FCPX_Studio_Pro/FCPX%20Studio%20Pro.app)，执行以下真机点验动作：

1. **画布锁定与穿透点验**：
   - 打开包含多个重叠图层的工程（例如镇雄 PSD 或包含底板与文字的模板）；
   - 在图层列表中将上层文字或装饰图层加锁（点击 `lock` 列出现 🔒）；
   - 在画布上直接单击该图层所在位置，观察鼠标是否穿透该层并成功选中其下方的图层；
   - 尝试按住鼠标左键拖动，确认锁定的图层绝对无法被拖移（手感稳固、零位移）。

2. **锁定高光与 🔒 徽标视觉肉眼确认**：
   - 在图层列表中主动单选已锁定的图层；
   - 观察画布上该图层的高亮边框是否变为科技灰细点虚线；
   - 检查右上角是否清晰渲染 `🔒 LOCKED` 圆角深色胶囊徽标，缩放画布（滚轮或缩放滑块）观察徽标是否平滑自适应。

3. **检查器只读置灰与横幅点验**：
   - 选中锁定图层，观察右侧检查器：
     - 顶部是否浮现琥珀黄色锁定提示横幅：“🔒 图层已锁定，解锁后可修改属性”；
     - 文本编辑框是否置灰且无法输入光标；
     - 旋转、缩放滑块、XY 坐标框是否全部变灰且无法拖动；
   - 再次点击列表中的 🔒 图标解锁，观察横幅是否即刻隐去，所有属性控件是否瞬时恢复可编辑状态。

4. **快捷键体验（⌘L 与 ⌘H）**：
   - 单选任一图层，按下键盘快捷键 `⌘L`，确认图层锁定状态即时翻转；
   - 按下快捷键 `⌘H`，确认图层在画布上瞬时隐藏/再现，列表眼睛图标同步在 👁 与 🚫 间切换；
   - 检查顶部系统菜单栏中的「图层」菜单项，确认快捷键标签显示正确且点击菜单项与按键效果完全一致。
