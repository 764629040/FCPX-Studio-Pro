## 一、工程背景与攻坚使命

作为工程第五十四轮（商业终结交付），本轮次的核心使命是兑现产品白皮书《D 域第 82/83 项：打包交付与便携化环境探测》的最终闭环：
1. **脱离开发宿主环境依赖**：过去原生壳依赖宿主机上的 Homebrew Python 或已激活虚拟环境，若在未安装 Python 的纯净裸机 Mac 上运行，将出现 Python 缺失或依赖找不到的问题；
2. **零依赖内置运行时（Zero-Dependency Standalone Bundle）**：将核心 Python 运行时、纯净标准库、Mach-O 动态依赖、`psd-tools` 核心解析引擎以及 `core/` 桥接模块完整封装进 `FCPX Studio Pro.app/Contents/Resources/python_bundle`，并通过 `@loader_path` 相对路径动态重定向与递归深度签名，确保即使在完全未装 Homebrew 的纯净 Mac 上双击即用；
3. **商用级分发镜像压制**：采用 macOS 原生 `hdiutil` 自动化压制只读压缩镜像 `FCPX_Studio_Pro_v1.0.dmg`，内嵌经过递归签名的 App Bundle、`/Applications` 软链接快捷替身与《使用说明与快速上手.txt》；
4. **设置面板自检升级**：偏好设置与体检窗口（⌘,）新增实时硬件加速状态（Metal GPU 设备名称探测）、便携包健康状态与商业版本标识回显。

## 二、核心技术实现与源码变更

### 1. `tools/bundle_standalone_runtime.sh`（新模块）
- **动态解析宿主环境**：自动化提取当前 macOS 主机 Python 3.14 架构与 Framework 根路径；
- **自包含解释器与动态库**：
  - 提取 `Python.app/Contents/MacOS/Python` 至 `python_bundle/bin/python3`，并软链 `python` 与 `python3.14`；
  - 提取 `Python.framework/Versions/3.14/Python` 动态库至 `python_bundle/Python`；
  - 使用 `install_name_tool` 将二进制依赖绝对路径替换为 `@loader_path/../Python`，并将动态库 ID 配置为 `@loader_path/Python`；
- **标准库精简裁剪**：
  - 使用 `rsync` 提取标准库，主动排除了 `test`、`idlelib`、`tkinter`、`turtledemo`、`ensurepip` 等与解析无关的组件；
- **C-扩展库与外部依赖闭环**：
  - 自动识别并提取 `lib-dynload` 依赖的 6 款三方库（`libmpdec`、`libcrypto`、`libssl`、`libsqlite3`、`liblzma`、`libzstd`）至 `python_bundle/lib/dylibs`；
  - 遍历所有 `.so` 与 `.dylib`，使用 `install_name_tool -change` 重定向为 `@loader_path/../../dylibs/...`，彻底切断对 `/opt/homebrew` 的外部绝对路径引用；
- **精炼 site-packages**：
  - 封装 `psd_tools`、`PIL` (Pillow)、`numpy`、`attrs`、`attr`、`scipy`、`objc`、`Cocoa`、`AppKit` 与 `typing_extensions`；
  - 深度清洗 `__pycache__`、`*.pyc`、测试用例与符号表；
  - 最终便携包体积控制在 140MB 左右（UDZO 压制进 DMG 后仅 64MB）；
- **内嵌 core 套件与隔离验证**：
  - 将 `core/` 脚本套件打包至 `Contents/Resources/core`；
  - 对全部 Mach-O 二进制执行 `codesign --force --sign -`；
  - 使用 `env -i PATH=/usr/bin:/bin HOME=$HOME` 执行纯净隔离子进程自检，验证 `STANDALONE_READY` 与真实复杂 PSD 解析。

### 2. `FCPXStudioNative/Sources/FCPXStudio/Models/AppConfig.swift`
- **重构级联探测链最高优先级**：
  - 探测链第一优先级检查 `Contents/Resources/python_bundle/bin/python3` 与 `Contents/Resources/python_bundle/bin/python`；
  - 支持向上向前级联检索工程 App Bundle，保证在测试 Harness、命令行及 App 真实运行环境中均稳定命中内嵌便携包；
- **内置 bridge 探测升级**：
  - 优先检测 `Contents/Resources/core/cli_bridge.py`；
- **新增硬件加速与版本规格**：
  - 引入 `import Metal`，新增 `hardwareAccelerationSummary`，自动读取系统 `MTLCreateSystemDefaultDevice()?.name`（如 `🟢 Metal 硬件加速就绪 (Apple M3)`）；
  - 新增 `appVersionString` 规范回显：`v1.0.0 (Build 20261106.R47 - Commercial)`；
  - 新增 `isStandalonePortableReady` 综合就绪状态判定。

### 3. `FCPXStudioNative/Sources/FCPXStudio/Views/SettingsWindow.swift`
- **设置与环境自检面板完善**：
  - 窗口标题升级为 `FCPX Studio Pro 设置与环境体检`，优化视窗纵向高度与布局比例；

    4. 核心解析依赖健康度（`🟢 psd-tools 核心引擎已就绪`）；
    5. Python 解释器实体命中路径；
    6. CLI Bridge 桥接脚本路径。

### 4. `tools/package_dmg.sh`（新模块）
- **商用分发镜像自动化打包器**：
  - 自动校验 App Bundle 完整性与 `python_bundle` 就绪状态；
  - 预先执行 `codesign --deep --force --verify --verbose --sign - "FCPX Studio Pro.app"` 确保签名完备；
  - 组织标准分发暂存区：内嵌 App、建立 `/Applications` 软链接快捷替身、生成商业版《使用说明与快速上手.txt》；
  - 调用 `hdiutil create -volname "FCPX Studio Pro" -srcfolder ... -ov -format UDZO` 压制只读压缩镜像；
  - 自动执行 `hdiutil verify` 与挂载测试（`hdiutil attach`），严密校验镜像内部应用、软链接与说明文件的可读性；
  - 自动卸载并计算最终镜像文件大小与 SHA-256 指纹。

### 5. `tools/r47_harness.swift` 与 `tools/run_r47_harness.sh`（新模块）
- **五大维度自动化直证套件**：
  1. 便携环境四级级联探测与健康自检（D-82 / D-83）；
  2. 零依赖离线真实 PSD 解析（含纯净隔离子进程调用）；
  3. 商用级 DMG 分发镜像挂载、完整性校验与文件核验；
  4. 递归深度代码签名与 Apple Silicon arm64 架构合规性断言；
  5. 偏好设置与自检面板数据模型回显核验。
