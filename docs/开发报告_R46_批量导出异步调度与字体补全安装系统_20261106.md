## 一、工程背景与攻坚目标

针对用户批量处理海量婚礼字幕模板时出现的主线程冻结、未插入外置移动硬盘时弹窗报错阻断工作流，以及缺字警告无法便捷修复等痛点，本次 R46 轮次完成了三大核心系统的深度攻坚与原生重构：

1. **批量导出异步并发调度器与磨砂质感进度面板 (`BatchExportProgressSheet.swift`)**：
   - 彻底解决批量转换数十款 PSD 模板时主线程死锁卡死与彩球旋转问题；
   - 采用 macOS Pro 磨砂毛玻璃 Sheet 窗口（基于 `NSVisualEffectView` HUD 材质）；
   - 平滑进度条（`40% (8/20)`）、当前实时转换文件状态与流水明细列表（🟢 成功、🟡 警告、🔴 失败）；
   - 底部动作智能翻转：转换中支持中途安全【取消批处理】，全部完成后切换为【在 Finder 中查看】与【完成】。
2. **多目标导出路径智能降级与无阻断自适应 (`AppConfig.swift` & `MainWindowController.swift`)**：
   - 优先探测首选外置存储目录（`defaultExternalAssetsDir` / `preferredExternalDir`）；
   - 若外置存储未挂载或不可写，**严禁弹出模态错误弹窗阻断用户**；
   - 自动无缝降级到本地标准路径：`~/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕`（必要时自动创建目录与清理历史死软链）；
   - 若外置盘挂载可用则写入外置盘并建立系统软链接，彻底消除未插盘时的报错。
3. **字体拖拽一键补齐与系统安装助手 (`FontInstaller.swift`)**：
   - 原生支持 `.ttf` / `.otf` / `.ttc` / `.dfont` 格式智能识别；
   - 基于 macOS 原生 `CTFontManagerRegisterFontsForURL(url, .user, &error)` 瞬间静默注册字体为用户级系统可用字体；
   - 注册成功后自动通知并触发当前 PSD 强制重新校验，使原本缺字橙色警告即刻恢复正常绿色（`detection_status: "detected"`，字形覆盖率 100%）；
   - 检查器诊断区与主窗口全面支持拖拽接收字体文件。

## 二、核心技术实现与源码变更

### 1. `FCPXStudioNative/Sources/FCPXStudio/Views/BatchExportProgressSheet.swift`（新模块）
- **窗口与视觉架构**：
  采用 `NSVisualEffectView`（`.hudWindow` 材质，`.behindWindow` 混合模式），提供圆角磨砂深色视觉；
- **组件结构**：
  - 顶部标题与动态副标题：展示调度状态与目标目录；
  - 进度指示区：`NSProgressIndicator` 与 `percentageLabel` 平滑联动（支持百分比与计数）；
  - 实时状态行：展示当前正在转换的 PSD 文件名（如 `正在生成: 婚礼序幕_镇雄.psd...`）；
  - 实时日志流水列表：基于 `NSTableView`，按时间戳呈现 🟢 成功、🟡 警告、🔴 失败流水明细；
  - 底部操作栏：支持 `cancelButton`（中途取消）、`revealButton`（完成后 Finder 定位）和 `doneButton`（关闭面板）；
- **线程安全与状态封装**：
  提供 `updateProgress(...)`、`appendLog(...)`、`finishExport(...)` 和 `markCancelled()`，内置主线程调度保护，供后台工作队列无锁调用。

### 2. `FCPXStudioNative/Sources/FCPXStudio/Models/AppConfig.swift`
- 新增 `ExportDestinationMode` 枚举：
  - `.smartAuto`：智能自适应（优先外置存储，未插盘自动降级至系统本地盘）；
  - `.externalSSD`：强制外置存储；
  - `.localSystem`：直接保存到系统本地盘；
  - `.custom`：自定义保存目录；
- 新增 `resolveExportDestination(category:groupName:) -> ResolvedExportDestination`：
  - 动态探测 `/Volumes/` 下外置存储挂载状态与写入权限；
  - 外置盘未插入或不可写时，自动切换至 `~/Movies/Motion Templates.localized/Titles.localized/PSD婚礼字幕`，并标明 `fallbackUsed = true`；
  - 自动检测并安全清理目标路径可能残留的死软链（指向拔出硬盘的 dangling symlink），杜绝 I/O 报错。

### 3. `FCPXStudioNative/Sources/FCPXStudio/Models/FontInstaller.swift`（新模块）
- 封装 CoreText 原生字体管理 API：
  - `isFontFile(at:)`：检测 `.ttf` / `.otf` / `.ttc` / `.dfont` 有效字体扩展名与实体文件；
  - `extractFontMetadata(at:)`：使用 `CTFontManagerCreateFontDescriptorsFromURL` 提取 PostScript 名称与 Family 家族名；
  - `registerFont(at:scope:)`：调用 `CTFontManagerRegisterFontsForURL` 静默注册字体为系统可用，广播 `FCPXStudioDidRegisterFontNotification`；
  - `registerFonts(at:scope:)`：支持批量并发/队列安装并生成 `FontBatchInstallReport`；
  - `unregisterFont(at:scope:)`：支持字体卸载闭环，便于测试与资源清理。

### 4. `DropAcceptingView.swift` & `InspectorView.swift`
- `PSDImportPlanner.swift`：增加 `isFont(...)` 判定，使 `acceptsDrop(paths:)` 同时接纳 PSD 与字体文件；
- `DropAcceptingView.swift`：区分拖拽落盘文件类型，非 PSD 字体文件自动路由至 `onFontsDropped` 回调；
- `InspectorView.swift`：
  - 注册 `.fileURL` 拖拽类型，增加 `fontDropPromptBox` 提示框（`🔤 缺失字体？拖拽 .ttf / .otf 字体文件至此处一键补齐安装`）；
  - 支持将字体文件直接拖拽至检查器，高亮响应并触发 `onFontsDropped`。

### 5. `MainWindowController.swift`
- `handleDroppedFonts(_ paths:)`：接收拖拽字体，通过 `FontInstaller.shared.registerFonts` 即刻注册，并立即调用 `parseCurrentFile(force: true)` 重新解析当前 PSD；
- `saveCurrentTemplate()`：采用 `AppConfig.shared.resolveExportDestination()` 智能路径解析，消除外置盘未插时的阻断弹窗；
- `batchExportAllTemplates()`：
  - 弹出 `BatchExportProgressSheet` 磨砂进度 Sheet；
  - 核心处理完全放入 `DispatchQueue.global(qos: .userInitiated)` 后台队列异步执行，每处理完成一项通过 `DispatchQueue.main.async` 刷新进度条与日志；
  - 任务循环中实时检测 `sheet.isCancelled`，支持用户随时中途安全取消批处理。
