## 一、 核心痛点根因分析

### 1.1 严重卡顿的致命根因（主线程高频阻塞 I/O）
1. **主线程递归遍历磁盘**：`TemplateTierScanner.scan` 在主线程对几十套模板递归遍历所有子文件读取 `attributesOfItem` 计算体积，单次切换触发上万次主线程同步 I/O；
2. **音效与 LUT 同步扫描**：6,096 项音效与 103 套 LUT 在点击 Tab 时全部在主线程同步加载，导致窗口瞬间卡死数秒并出现彩虹圈；
3. **零缓存机制**：每次点击分类或刷新，所有数据全部重盘重扫，无内存缓存层。

### 1.2 界面视觉与嘉星脱节问题
1. 当前界面为单薄的简单表格与单一顶栏，缺乏专业影视后期 Pro App 的沉浸质感；
2. 嘉星的经典形态是：**左侧深色专业侧边栏 (Sidebar) + 顶层现代工具栏 (Toolbar 带搜索与外置状态) + 右侧现代化卡片网格流 / 列表 (Resource Card Grid)**。

## 二、 详细设计与重构要求

### 2.1 彻底根除卡顿：异步后台扫描、缓存与懒加载（性能重构）

1. **全面异步化（GCD Background Work）**：
   - `TemplateTierScanner`、`LUTManager`、`AudioManager`、`LibraryCleaner` 统一提供异步接口：
     `scanAsync(category:completion:)`，强制切入 `DispatchQueue.global(qos: .userInitiated)`；
   - 主线程点击分类或 Tab 时**耗时严格为 0ms**，立即返回并展示骨架/指示器，扫描完毕后主线程安全更新数据；
2. **多级内存缓存中心（`AssetCacheManager.swift`）**：
   - 建立扫描结果内存缓存，在有效会话周期内秒级命中，避免重复扫描；
   - 切换分类瞬间加载（0ms 响应，零等待，彻底消除彩虹圈）；
3. **体积计算后台懒加载（Lazy Size Calculation）**：
   - 优先秒级输出模板名称、分类与图标（10ms 内呈现卡片）；
   - 磁盘体积计算转入后台次级线程，计算完成后局部异步刷新对应卡片标签。

### 2.2 深度复刻嘉星 2.app 视觉布局（UI 视觉重塑）

1. **左侧深色专业侧边栏（Sidebar）**：
   - 采用 macOS Pro App 暗色石墨黑质感（`#161719` 底色，细边框 `#2a2b2e`）；
   - 分组一：**【视觉模板】**
     - 💬 标题字幕 (Titles)
     - ✨ 视频特效 (Effects)
     - 🔄 视频转场 (Transitions)
     - ⚡ 视频发生器 (Generators)
   - 分组二：**【专业媒体】**
     - 🎨 3D LUT 调色
     - 🎵 影视音效库
   - 分组三：**【系统工具】**
     - 🧹 资源库瘦身医生
     - ⚙️ 偏好设置
   - 底部常驻：外置移动硬盘挂载指示灯与容量统计。
2. **顶层现代化工具栏（Toolbar）**：
   - 当前分类大标题与健康统计计数；
   - 实时过滤搜索框（Search Field，支持中文别名与英文原名即输即搜）；
   - 三级归属快捷过滤（全部 / 🟡 内置 / 🟢 用户 / 🟣 系统）；
   - 视图切换按钮：卡片网格流 (Grid) ⊞ / 专业列表 (List) ☰；
3. **卡片网格流（Resource Card View，对标嘉星 `FxXuResourceCardView`）**：
   - 高质感圆角深色卡片（悬停微亮边缘动效）；
   - 16:9 高清缩略图视口（若有预览图优先展示，支持悬停预览动图）；
   - 标题区：中文友好别名（主标题）+ 英文原始标识（副标题）+ 占用容量徽章；
   - 交互区：右下角精致的 `🟢 开启 / ⚪️ 禁用` 胶囊 Toggle 开关，以及 `⋯` 更多菜单（重命名、外置迁移、在访达中显示）；
4. **拖拽安装遮罩（Drop Overlay）**：
   - 继承嘉星的高质感全窗口半透明深蓝毛玻璃安装引导（`📦 释放以自动安装至当前分类`）。
