## 一、 任务背景与目标

用户明确指示：**“程序里的引擎 2，功能应该完完全全对标我们的这个程序 '/Applications/嘉星插件管理 2.app'”**。

1. **拖拽与 Zip 一键安装引擎**（`FxXuZipInstall` / `TemplateInstallDropOverlayView`）；
2. **模板生命周期管理与一键启停隔离**（Toggle 开启/禁用，避免模板过多拖慢 FCPX 启动）；

## 二、 详细设计与实现要求

### 2.1 智能拖拽与 Zip 自动识别安装引擎（`TemplateInstaller.swift`）

1. **拖拽汇入拦截**：
   - 在 `AssetHubView` 中支持接收拖拽的文件（支持 `.zip` 压缩包、标准模板文件夹、或任意包含 Motion 文件的目录）；
   - 拖拽悬停时展示类似嘉星的半透明安装引导遮罩（`Drop to Install Templates`）；
2. **分类智能感知算法**：
   - 解压或扫描包内文件，深度递归检查文件扩展名：
     - 含 `.moti` -> 判定为 `Titles.localized`（字幕）
     - 含 `.moef` -> 判定为 `Effects.localized`（特效）
     - 含 `.motr` -> 判定为 `Transitions.localized`（转场）
     - 含 `.motn` -> 判定为 `Generators.localized`（发生器）
   - 若包内包含多个分类，自动拆解并按类别分流安装；
3. **安全原子安装与冲突检查**：
   - 解压至安全临时沙箱；
   - 提取规范的主模板文件夹名与内部分类名；
   - 若目标目录已存在重名模板，自动生成带时间戳的安全隔离备份，严禁静默覆盖；
   - 安装至用户目标库（默认 `~/Movies/Motion Templates.localized/<Category>/<Subcategory>/<TemplateName>`，或当前外置盘配置路径）；
4. **安装完成通知与自动刷新**：
   - 安装完成后自动触发 `AssetHubView` 重新扫描刷新，并在状态栏显示安装成功通知（如：“成功安装 3 套字幕模板至 Titles”）。

### 2.2 模板一键启停（Enable / Disable Toggle 开关）系统

1. **模型层扩展**：
   - `TemplateItem` 增加属性：`public var isEnabled: Bool`（若文件夹名以 `.disabled` 结尾或软链接指向隔离区，则为 `false`，否则为 `true`）；
2. **UI 层交互呈现**：
   - 在 `AssetHubView` 列表中增加「状态/启停」列，提供直观的开关控件（Toggle Switch / 状态圆点）；
   - 激活状态呈现绿色启用标记，禁用状态呈现置灰禁用标记；
3. **底层安全隔离机制**：
   - **禁用（Disable）操作**：
     - 将目标文件夹重命名为 `<OriginalName>.disabled`；
     - 或在软链接层面切断指向，保留配置元数据；
     - Final Cut Pro 在扫描 `Motion Templates.localized` 时会自动忽略 `.disabled` 目录，从而大幅提升 FCPX 启动速度与内存释放；
   - **启用（Enable）操作**：
     - 去除 `.disabled` 后缀，毫秒级复原，不改变内部任何资源与 XML 结构；
   - **权限防护**：
     - 对内置级（Builtin 🔒）只读模板，若用户尝试切换，弹窗提示：“系统内置模板受保护，需先复制到用户库后再调整”；
     - 对外置盘与用户库模板，支持秒级自由开关。

### 2.3 四大分类全景导航器与统计条升级

1. **分类切换支持**：
   - 导航栏完整支持切换四大类：
     - `Titles.localized`（字幕）
     - `Effects.localized`（视频效果）
     - `Transitions.localized`（转场）
     - `Generators.localized`（发生器）
2. **分类资产健康统计**：
   - 顶栏不仅展示三级归属分布，实时展示当前分类下的健康状态（如：“字幕：共 42 套 · 已启用 40 · 已休眠 2”）。
