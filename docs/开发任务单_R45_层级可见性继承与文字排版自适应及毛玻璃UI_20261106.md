## 一、核心攻坚目标与技术路线

### 1. 层级可见性继承（Root Cause 根治）
- **问题机理**：`core/psd_parser.py` 原代码仅判断 `layer.visible`，而未判断父组的显隐状态。在 Photoshop 中，若父组（如 `组 1`、`组 2`、`轻轻`）被隐藏，其内部所有子图层在画布上对用户均不可见。
- **重构要求**：
  - 在 `psd_parser.py` 中引入 `layer_is_effectively_visible(layer)`：递归检查 `layer` 及其所有祖先节点的 `visible` 状态（在 `psd-tools` 中等价于 `layer.is_visible()`）；
  - 默认状态（`include_hidden=False`）下，仅当图层本身及其父级组均可见时才判定为可见层；
  - 属于隐藏父组的图层归入隐藏层分类，按 A-70/A-72 规范在勾选「显示隐藏图层」时才展开预览；
  - 从而彻底解决打开 PSD 时多套方案图层全部堆叠在画布上的问题。

### 2. 表头眼睛总控按钮（一键全选/全部隐藏）
- **重构要求**：
  - 在 `InspectorView.swift` 中，为 `layerTableView` 的 `colVis`（可见性列）表头配置点击事件或自定义表头按钮；
  - 支持点击表头眼睛图标实现**一键全选/全部隐藏（Toggle All Visibility）**：
    - 若当前列表中有任何图层处于可见状态 $\to$ 一键将所有图层置为隐藏（`visible = false`）；
    - 若所有图层均处于隐藏状态 $\to$ 一键恢复所有图层为可见（`visible = true`）；
  - 联动 `canvasView` 即时重绘，消除用户逐行点击的繁重交互负担。

### 3. 文字排版边界自适应（根治文字截断与漏字）
- **问题机理**：`InfiniteCanvasView.swift` 在 `layerVisualSize` 中机械采用 `psdBBox` 宽度作为 `textRect`。在 `被托付的光.psd` 中，文本 `'被托付\n  的光'` 字号为 429pt，首行文字自然宽度为 1287.5pt，而位图 bbox 仅 1232pt；AppKit 的 `astr.draw(in: textRect)` 在宽度不足时自动将“付”折行到第二行，而两行高度超过了 892pt 的 bbox 高度，导致“付”与“的光”被 CoreText 自动裁剪！
- **重构要求**：
  - 在 `InfiniteCanvasView.swift` 中，对于文本图层，结合文本的实际属性字串计算真实的排版所需空间：
    ```swift
    let neededSize = astr.boundingRect(
        with: CGSize(width: max(bw * 2.0, 4000), height: 10000),
        options: [.usesLineFragmentOrigin, .usesFontLeading]
    ).size
    let drawW = max(bw, ceil(neededSize.width) + 24)
    let drawH = max(bh, ceil(neededSize.height) + 24)
    ```
  - `textRect` 采用 `drawW` 与 `drawH`，确保任何换行、空格及大字号标题完整排版渲染，绝不漏掉一个字。

### 4. 现代 macOS Pro 哑光半透明毛玻璃 UI 系统（UI 视觉质感飞跃）
- **重构要求**：
  - **毛玻璃材质（NSVisualEffectView）**：
    - 窗口样式加入 `.fullSizeContentView`，透明标题栏（`titlebarAppearsTransparent = true`）；
    - 顶栏 TopBar、左侧 PSD 列表 Panel、右侧属性 InspectorPanel 统一升级为 `NSVisualEffectView`（材质选用 `.sidebar` / `.underWindowBackground`，暗黑外观，`blendingMode: .behindWindow`）；
  - **原生 SF Symbols 矢量图标**：
    - 彻底替换掉粗糙的 Emoji 字符，采用 Apple 原生 SF Symbols（`NSImage(systemSymbolName:...)`）：
      - 引擎一切换：`slider.horizontal.3` / `sparkles`
      - 引擎二切换：`square.stack.3d.up` / `film.stack`
      - 可见性：`eye` / `eye.slash`
      - 锁定：`lock.fill` / `lock.open`
      - 保存与导出：`square.and.arrow.down` / `arrow.up.forward.app`
      - 竖排切换：`text.aligncenter` / `arrow.up.and.down.text.horizontal`
  - **现代深色调色板与质感边框**：
    - 采用 Pro Graphite（`#131519` 半透明基底），卡片采用精致细边框（`rgba(255,255,255,0.08)`）与平滑圆角（8~10pt）；
    - 按钮与选择器具备优雅的悬停高亮动效与微光外发光。
