## 一、任务背景与核心目标

在影视后期制作公司、MCN 机构或短视频团队中：
1. **传统分发效率极低**：视觉设计同事制作出最新片头或专属字幕包后，往往需要手动压缩成 ZIP，通过微信或企业网盘上传下载；剪辑师下载后解压，常常装错目录导致红屏。
2. **新机配置极其繁琐**：新入职剪辑师或换新 Mac 时，需要重新逐个安装上百个插件、导入数十款 3D LUT 和公司音效库。

本轮核心目标是研发**【团队资产免流量极速分发与环境一键克隆系统】（Team Asset P2P Fast Sync & Environment Cloner）**：
- **Bonjour 局域网设备自发现与 AirDrop 级内网直传**：
  - 基于 macOS 原生 `NetService` / `NetServiceBrowser` 协议，无须配置任何外网公网服务器；
  - 自动发现同一局域网（WiFi / 千兆内网）内运行 FCPX Studio Pro 的剪辑设备雷达；
  - 选定模板或资产包后，一键点对点直传（速度达 100MB/s+），目标机接收后自动识别分类（Titles / Effects / Transitions / Generators）并原子化安全安装；
- **生产环境与素材库一键打包克隆（`.fcpxpack`）**：
  - 支持将指定分类、模板、LUT 调色库与工作区情境（Profile）一键打包归档为标准的 `.fcpxpack` 单文件；
  - 新设备一键导入解包，实现全套生产环境秒级 100% 完美复刻。

## 二、详细任务分解与代码规范

### 1. 局域网自发现与 P2P 传输引擎 (`TeamP2PSyncManager.swift`)
- 存放路径：`FCPXStudioNative/Sources/FCPXStudio/Models/TeamP2PSyncManager.swift`；
- 协议规格：
  - Bonjour 服务类型：`_fcpxsync._tcp.`，广播本地剪辑主机名与端口；
  - 监听与发现：自动监听可用端口，使用 `NetServiceBrowser` 持续发现对端；
  - 数据包结构：包含包头魔数（`FCPXPK`）、版本号、清单 JSON（模板名、分类、SHA-256、文件大小）、归档 Payload；
  - 接收端校验与安装：接收完毕后计算 SHA-256 校验和，校验一致后直接调用 `TemplateInstaller.installTemplate` 无缝安装，并触发通知中心刷新列表。
- 支持 `FCPXSTUDIO_P2P_PORT` 与测试环境变量，保证单机测试时可启动两个隔离端点相互通信。

### 2. 生产环境一键克隆与打包器 (`EnvironmentCloner.swift`)
- 存放路径：`FCPXStudioNative/Sources/FCPXStudio/Models/EnvironmentCloner.swift`；
- 核心功能：
  - `exportPackage(categories: [String], includeLUTs: Bool, includeProfiles: Bool, outputPath: String) throws -> CloneManifest`；
  - 将模板目录、相关 LUT 预设与工作区配置文件打包成包含 `manifest.json` 的标准 `.fcpxpack`（本质为 ZIP 规范归档包）；
  - `importPackage(packagePath: String, conflictPolicy: ConflictPolicy) throws -> ImportSummary`：一键解包并无缝分发部署到本地各目标目录。

### 3. 前端交互看板与侧边栏挂载 (`TeamSyncDashboardView.swift` & `AssetHubView.swift`)
- 存放路径：`FCPXStudioNative/Sources/FCPXStudio/Views/TeamSyncDashboardView.swift`；
- 视觉风格：深色专业 Pro 风格（`#141518` 纯黑底色、`#1A1D24` 卡片面板、霓虹蓝/绿雷达扫描动效）；
- 布局结构：
  - **顶部雷达扫描卡片**：展示当前局域网在线剪辑设备列表（主机名、IP、状态 pill、一键【🚀 发送模板】）；
  - **环境克隆与打包面板**：
    - 【📦 导出当前环境为 .fcpxpack 包】（支持自定义勾选分类）；
    - 【📥 一键导入并恢复 .fcpxpack 包】（支持拖拽直接导入）；
  - **传输与同步历史日志列表**：实时展示近期局域网发送/接收记录。
- 侧边栏常驻接入【🚀 团队分发】（第 10 项），在主窗口支持快速切换。
