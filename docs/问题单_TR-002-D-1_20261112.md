## 2. 详情

### BUG-4D1-1｜严重｜不可写层被当成可写层

**现象（质控侧实测，原文照贴）**

用取证构建在 564 层第三方模板副本上改文本，两条都失败：

```
/tmp/qc_tr002d/wd/release/FCPXStudio --edit-moti /tmp/qc_tr002d/big_text.moti \
  --edit-moti-auto-save --edit-moti-auto-confirm \
  --edit-moti-layer 0 --edit-moti-text "质控改文本"

→ SAVE_FAIL error=XML 落点定位失败：L0 text 落点未找到
→ 文件 sha 不变、无 SAVE_OK、无新 .bak（安全失败，未毁件）
```

`--edit-moti-layer 3` 同一条结果（`L3 text 落点未找到`）。

**同一实例在编辑态给出的却是另一套说法**

| 位置 | 实际表现 | 代码落点 |
|---|---|---|
| 顶栏日志 | `[TR-002C] edit_moti_open ... writable=true reason=可写` | `MainWindowController.swift:619–621` |
| 文字内容框 | 可编辑（`isEditable = true` 无条件置真） | `InspectorView+MotiEdit.swift:73` |
| 可见 / 锁定 按钮 | 可点（判据只认 `motiReadOnlyMode` 与 `layer.isLocked`） | `InspectorView.swift:~1391` |
| 保存按钮 | 判据只认**文件级**写权限 `motiEditWritable` | `InspectorView+MotiEdit.swift:~120` |

**根因边界（只划界，不定实现）**

- 写回侧：文本落点只认中文链（`对象` / `文本`），X/Y 落点才有中英两套（`MotiWriteBack.swift:623–691`）。→ 英文链**文本必然失败**，这是既有局限，不是本轮回归。
- UI 侧：`positionChain` 目前只用于把 X/Y 置灰（4D-1），**没有扩散成「整块可写性」**。
- 结果：用户看到「可写」，改完点保存必失败，且失败文案是「落点定位失败」这种实现细节——用户既白干一场，也读不懂为什么。

**期望结果（可判定）**

1. **层级可写性**：`positionChain == "zh"` 才可写；`en` 与空值一律不可写。判据按**当前选中层**，不是整模板一刀切——混合链模板里可写层必须照旧能改能存。
2. 不可写层进入编辑态时：
   - 「文字内容」框不可编辑、字色转灰、toolTip 固定文案；
   - 可见 / 锁定 按钮置灰、不可点、带同一 toolTip；
   - X/Y 保持 4D-1 的 `—` 置灰；
   - 「保存回 .moti」禁用。
3. **横幅（不许回退 4D-1）**：
   - 第一行**逐字保留**「该模板参数链非本工具格式（Properties/Transform/Position），X/Y 不可写」；
   - 第二行追加「该图层仅支持只读预览：文本 / 可见 / 锁定 亦不可写回」；
   - 允许按两行调整横幅高度，但首行不许改字、不许被省略号截断。中文链形态与只读态形态一行不许变。
4. **保存前置拦截（核心判据，不许依赖写回报错）**：保存时若 `edits()` 中存在不可写层（index 对应 `positionChain != "zh"`）的改动，必须在进 `MotiWriteBack` **之前**拒绝：
   - 不备份、不写盘、不产生 `SAVE_OK`；
   - 文件 sha 不变、备份目录计数不变；
   - 输出 `SAVE_REJECT error=图层不可写：参数链非本工具格式 (L<n>)`（措辞可微调，但必须含「不可写」与层号，**不得**落到「落点未找到」）。
5. **日志诚实**：`edit_moti_open` 不能只打 `writable=true` 就完事。同一行必须补：
   - `editable_layers=<可写层数>`（564 层模板应为 `0`）；
   - 选中不可写层时 `selected_writable=false reason=参数链非本工具格式`。
   - `writable` 可保留为文件级写权限语义，但整行必须能看出「文件可写 ≠ 这一层可写」。
6. **不许用假状态凑数**：不许把不可写层的 `isLocked` 置真来借道置灰（表格会显示锁图标 + 「图层已锁定」横幅，那是另一种假话）；不许「先让按钮亮着，等写回失败再弹错」。
