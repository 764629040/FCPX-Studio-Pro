## 一、 核心系统实现细节

### 1.1 `LUTManager.swift` 3D LUT 调色库发现与着色引擎
- **智能探测与 HTML 拦截防御**：
  - 用户磁盘上部分通过网页直接下载的 `.cube` 可能会混入 HTML 404/页面文件。`peekDimension(at:)` 优先读取头部 4KB，拦截包含 `<!DOCTYPE` 或 `<html` 的伪文件，严防 CoreImage 因尺寸解析为 0 导致崩溃；
  - 正则/分词提取 `LUT_3D_SIZE\s+(\d+)`，验证尺寸合法性在 $2 \le \text{dim} \le 128$ 区间。
- **CoreImage CIColorCube 硬件加速着色**：
  - 标准 3D LUT 文件记录 $R \times G \times B$ 空间的三维浮点查找表。按 CoreImage 规范将每个网格节点展开为 4 个 32-bit Float（RGBA，其中 Alpha 恒为 1.0）；
  - 将总长度为 $\text{dim}^3 \times 4 \times 4$ 字节的数据打包为 `Data`，绑定至 `CIColorCube` 滤镜的 `inputCubeDimension` 与 `inputCubeData`；
  - 接入 `CIContext(options: [.useSoftwareRenderer: false])`，利用 GPU 进行实时的色彩矩阵映射，实测处理 $960 \times 540$ 画幅仅耗时数毫秒。
- **基准参考样张（`makeCinematicReferenceImage`）**：
  - 动态生成具备 35° 天空蓝到暖阳微反差对角渐变、Rec.709 电影色彩校准色块矩阵（18%中灰、黑白场、高饱和色、深浅肤色卡）的电影基准测试图，确保用户在未载入个人视频素材时即可直观体验调色风格。

### 1.2 `LUTCompareView.swift` 动态分屏对比视口
- **分屏剪裁绘制逻辑**：
  - 视口根据 `splitRatio`（默认 0.5，范围 0.02~0.98）划分左屏与右屏；
  - 左屏区域施加 `NSBezierPath(rect: leftClip).addClip()`，绘制原始画面；
  - 右屏区域施加 `NSBezierPath(rect: rightClip).addClip()`，绘制经当前 LUT 着色后的画面；
  - 垂直中轴绘制 2pt 高对比度分割线与柔和阴影。
- **对标嘉星 `FXLUTCompareOverlayView` 中轴指示胶囊**：
  - 在分屏线中点绘制半透明圆角胶囊手柄（`◀ 原始 ｜ LUT 效果 ▶`），文字大小 11pt，高质感悬浮感知；
  - 四角渲染当前视图状态徽标（“原片 (Log/Rec709)” 与 “LUT: <Name>”）。
- **鼠标无感悬停与拖拽**：
  - 配置 `NSTrackingArea` 监听 `mouseMoved` 与 `mouseDragged` 事件，鼠标 X 轴移动直接映射为 `splitRatio = loc.x / bounds.width`，刷新视口无需用户按住鼠标。

### 1.3 `AudioManager.swift` 影视级音效库与播放控制
- **全格式支持与多目录聚合扫描**：
  - 聚合扫描 Apple 官方内置音效库、外置 SD 音效库、系统音效库与用户音乐库；
  - 支持 `.caf`, `.wav`, `.m4a`, `.mp3`, `.aiff`, `.flac`, `.aac` 等主流格式；
  - 提取文件体积、时长（分秒格式化 `00:03.2`）、采样率（44.1kHz / 48kHz）与声道数。
- **声学波形图抽取算法（128 点归一化 Peak Downsampling）**：
  - 通过 `AVAudioFile` 读取 PCM 数据至 `AVAudioPCMBuffer`；
  - 将全曲音频采样帧平分为 128 个 Bucket，在每个 Bucket 内部提取左右双声道绝对振幅峰值；
  - 寻找 128 点最大峰值 `peak`，对全数组进行归一化映射至 $[0.0, 1.0]$ 区间；
  - 针对无声音或损坏文件生成带波浪起伏的合成波形降级保护。
- **AVAudioPlayer 低延迟试听控制**：
  - 实现 `play`, `pause`, `resume`, `stop`, `seek(to:)` 毫秒级响应；
  - 启动 30ms 间隔高频定时器，实时回传播放进度并在完成时自动复位。

### 1.4 `AudioWaveformView.swift` 真实声学波形图
- **上下对称镜像渲染**：
  - 以视口中线 `bounds.midY` 为基准线，向上下两侧对称绘制圆角柱状条；
  - 根据 `playbackProgress` 将波形划分为已播放区（天蓝 `#38BDF8` 高亮）与未播放区（暗石板灰 `#475569`）；
  - 播放指针线带高光与顶部倒三角指示标；
  - 鼠标悬停时动态显示虚线辅助线；支持点击或拖拽任意位置瞬间 Seek。

### 1.5 `AssetHubView.swift` 全景三大模块整合
- 顶层引入 `hubSegmentedControl`（【🎨 模板插件管理】/【🎞️ 3D LUT 调色与分屏】/【🎵 影视级音效库】）；
- 单一窗口控制器内无缝分流三大 NSTableView，各模块数据独立加载、互不干扰；
- 音效列表实现 `NSPasteboardWriting` 协议，支持直接拖拽音频项至访达或 FCPX 时间线；
- 保持 R37 一键安装与模板启停隔离逻辑（`.disabled`）100% 完好运行。
