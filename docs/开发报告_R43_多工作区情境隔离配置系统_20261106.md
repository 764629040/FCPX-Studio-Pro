## 一、 数据模型与毫秒级隔离引擎

### 1.1 数据结构定义 (`WorkspaceProfile.swift`)
```swift
public struct WorkspaceProfile: Codable, Identifiable, Equatable {
    public var id: UUID
    public var name: String
    public var icon: String
    public var category: String
    public var description: String
    public var includedTemplateIDs: [String]
    public var excludedTemplateIDs: [String]
    public var isDefault: Bool
    public var isBuiltin: Bool

    public func matches(templateName: String) -> Bool {
        if isDefault { return true }
        if excludedTemplateIDs.contains(templateName) { return false }
        if includedTemplateIDs.contains(templateName) { return true }
        if isBuiltin {
            for kw in includedTemplateIDs {
                let trimmed = kw.trimmingCharacters(in: .whitespaces)
                if !trimmed.isEmpty && templateName.localizedCaseInsensitiveContains(trimmed) {
                    return true
                }
            }
        }
        return false
    }
}
```

### 1.2 毫秒级批量启停调度逻辑
当剪辑师激活某一情境时，`WorkspaceProfileManager.activateProfileSync` 遍历各分类目录，根据白名单与排除规则计算目标状态：
- 若模板应激活但当前处于 `.disabled`，重命名恢复为正常名称；
- 若模板应休眠但当前处于激活态，重命名追加 `.disabled` 后缀；
- 批处理完成后自动执行 `AssetCacheManager.shared.invalidateAll()` 清理素材缓存，并广播通知更新 UI。
