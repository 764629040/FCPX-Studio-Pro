## 2. A-3 字号不一致

### 2.1 根因（审核方判定依据，代码算术）

| 位置 | 旧行为 |
|---|---|
| `canvas_view.py:92-96` | 建框用 `info.font_size` **原值**：`max_line_len * font_size * 0.8` |
| `canvas_view.py:199` | 绘制用 `info.font_size / 2.2` |

结果：字形相对框体被系统性压缩到 **1/2.2 = 0.4545**，且点选区域与可见文字错位。

实例（`Text01`，字号 45，文本 30 字符）：
- 旧框宽 = `max(40, 30 × 45 × 0.8)` = **1080 px**，而真实 bbox 宽仅 **31 px**
- 旧绘制字号 = `int(45 / 2.2)` = **20**

### 2.2 修复

新增唯一字号来源函数：

```python
def text_render_font_size(info) -> int:
    fsize = float(getattr(info, "font_size", 0.0) or 0.0)
    pt = fsize * 0.75          # PSD 像素 → Qt point（1pt ≈ 1.333px）
    return max(1, int(round(pt)))
```

- 建框改为直接采用 `psd_bbox`（与字形同源坐标），仅无 bbox 时用该函数兜底
- 绘制改为 `text_render_font_size(info)`
- `/2.2` 魔数删除

### 2.3 验证

| 图层 | font_size | 绘制 pt | 框宽 | 框高 | bbox 宽 | bbox 高 |
|---|---|---|---|---|---|---|
| `Text01` | 45.0 | 34 | **31** | **765** | 31 | 765 |
| `Title` | 90.0 | 68 | **188** | **798** | 188 | 798 |

框体与 bbox **完全一致**；字号比例恒为 0.75，不再是 0.4545。

截图：`docs/19_A3A4修复后并排对照.png`

## 3. A-4 字体不可用误报为缺字形

### 3.1 根因

`complex_layers.psd` 声明字体 `CormorantInfant-Regular`。该字体**系统未安装**（系统仅有 `CormorantGaramond-*` 变体）。

旧代码在字体不存在时执行：

```python
"missing_chars": list(dict.fromkeys(clean_chars))   # 把全部文本字符当作缺字
```

于是徽章显示「缺字: W, E, N」——但字母本身并不缺，缺的是整个字体。同时 `detection_status` 被设为 `missing_fallback`，使徽章走错分支。

### 3.2 修复

```python
if font is None:
    return {
        "status": "font_missing",
        "coverage_rate": 0.0,
        "missing_chars": [],          # 字体不存在时无法枚举字形，不得列出具体缺字
        "has_missing_risk": True,
        "warning": f"字体 '{font_name}' 在当前 macOS 系统中未安装，无法枚举其字形",
    }
```

`detection_status` 三态区分：

```python
if not is_font_available:            detection_status = "font_missing"
elif glyph_cov["status"] == "unverifiable": detection_status = "unverifiable"
else:                                detection_status = "missing_fallback"
```

### 3.3 验证

| 图层 | 字体 | status | missing | 徽章 |
|---|---|---|---|---|
| `Text01` | CormorantInfant-Regular | `font_missing` | `[]` | 🔴 原始字体未安装 (回退: Helvetica) |
| `Title` | CormorantInfant-Regular | `font_missing` | `[]` | 🔴 原始字体未安装 (回退: Helvetica) |

徽章不再出现 W/E/N。

**边界保留**：字体确已安装但缺字形时仍如实列出。`Helvetica` + "婚礼现场2026" → `partial_missing`，`missing_chars` 含"婚""礼"。

## 7. A-8 四态同屏截图 + A-9 左栏占位框定性

### 7.1 A-8 四色同屏

用 `four_state.psd` 真实夹具 + 1 个 `unverifiable` 构造层，同屏得到四种徽章：

| 状态 | 徽章 | 背景 / 前景 |
|---|---|---|
| detected | 🟢 字体 100% 支持 | `#14301c` / `#30d158` |
| missing_fallback | 🟠 缺字: 新, 娘, 朱... | `#3d2914` / `#ff9f0a` |
| font_missing | 🔴 原始字体未安装 (回退: …) | `#3d1418` / `#ff453a` |
| unverifiable | 🟡 无法验证字形 | `#3d3514` / `#ffd60a` |

截图：`docs/17_A8四态同屏_four_state夹具.png`

### 7.2 A-9 定性结论

审核观察：截图 15 左栏「PSD 原稿预览」只有 bbox 细框与图层标签、无文字，`canvas_view.py:280-289` 缺 `original_slice_bytes` 即走占位框。

**实测复核（当前代码）**：

| 检查项 | 实测 |
|---|---|
| `Text01` 切片字节 | 2124 bytes，尺寸 31×765 |
| `Title` 切片字节 | 741/12176 bytes，尺寸 188×798 |
| 切片非透明像素 | Text01 = 5230 / 23715；Title = 12176 / 150024 |
| 左栏图元 pixmap | **有**，`is_empty_or_group = False` |
| 左画布墨迹像素 | **2668** |
| 右画布墨迹像素 | 2875 |

结论：**当前代码左栏确实渲染了 PSD 原稿切片，非占位框**。两侧墨迹量同量级（2668 vs 2875）。

`canvas_view.py:280-289` 的占位分支仅在 `original_slice_bytes` 为空时触发。切片由 `parse_psd_file(..., extract_thumbnails=True)` 生成——**若截图时未开启 `extract_thumbnails`，或使用未含切片的解析结果，即会走占位框**。截图 15 应为该情形。

建议：第三方复现「并排对照」时须显式传 `extract_thumbnails=True`，否则左栏必然只剩占位框。该注意事项已记入本报告，建议同步写进任务单/使用说明。
