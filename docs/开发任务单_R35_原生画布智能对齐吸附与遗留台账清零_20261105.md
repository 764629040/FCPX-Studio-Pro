## 二、 详细设计与实现要求

### 2.1 原生画布智能对齐与磁吸系统（`InfiniteCanvasView.swift`）

1. **对齐目标探测**：
   - 拖动图层时（`isDraggingLayer == true`），计算当前图层的物理包围盒（左、中、右、顶、中、底）；
   - 对齐探测源包含：
     - ① **画板几何中心**：$X = 0, Y = 0$；
     - ② **广播安全区**：90% 动作安全框与 80% 标题安全框边界；
     - ③ **其他所有可见图层**的边界与中心线（基于 `other.psdBBox` / `posX, posY`）。
2. **磁吸吸附（Snapping）**：
   - 阈值设为 $\le 6.0$ 像素（考虑当前 `zoomScale` 换算）；
   - 当图层靠近参考线时，自动吸附至参考位置，消除微小抖动；按住 `Command` 键时临时禁用吸附。
3. **高光参考线绘制**：
   - 在图层上方绘制明亮的金色/青色虚线或细实线（例如 `NSColor.systemCyan` 或 `NSColor(calibratedRed: 1.0, green: 0.8, blue: 0.0, alpha: 0.8)`）；
   - 参考线两端延伸至涉及对齐的最小/最大跨度；
   - 鼠标松开（`mouseUp`）时立即清空辅助线状态并触发重绘。
4. **坐标更新闭环**：
   - 吸附后的最终坐标同步更新至 `LayerModel`，并通过 `onLayerMoved` 回调同步至检查器。

### 2.2 遗留台账自动化闭环（A-62 / A-66 / A-59 / A-60）

1. **A-62（⌘O 单文件打开）**：
   - 确认并在测试脚本中验证 `--open <psd_path>` 真实启动并在 2 秒内成功进入主界面解析图层；
2. **A-66（三级归属前置展示与菜单优化）**：
   - 验证操作列默认显示状态文本（内置 `🔒 只读` / 其它 `⋯`），归属列加宽至 300 且显示真实路径与彩色徽标，迁移功能收归右键菜单与 `⋯`；
3. **A-59 & A-60**：
   - 校验 `has_confirmed_missing_glyphs` 与 `has_glyph_risk` 语义解耦无自相矛盾，核对原生代码指纹完整性。
