### 2. 工作区情境隔离点击卡顿根治与响应优化 (`WorkspaceProfileDashboardView.swift`, `WorkspaceProfileManager.swift`)
- **根因分析**：
  - 用户点击卡片空白处仅触发了 `onSelect`（选择用于配置矩阵），而没有触发 `activateProfile`；
  - `TemplateTierScanner` 在遍历时未排除 `.framework`、`.app`、`.pluginkit` 等二进制包，导致扫描出 `en.lproj`、`_CodeSignature` 等非模板文件夹并尝试重命名加 `.disabled`，引发大量文件不存在警告并在 USB 外置卷上严重阻塞主线程，表现为“卡死没有任何反应”。
- **重构要求**：
  - **模板扫描精准过滤**：严格限定仅将以 `.moti`、`.moef`、`.motr`、`.motn` 为扩展名的目录或包含工程文件的真实模板目录纳入情境启停，**彻底排除 framework 与 app 内部资源**；
  - **整卡可点击**：点击卡片任意区域即可直接激活该情境，同时右上角显示即时 Loading Spinner；
  - **异步并发与状态回调**：在次级线程异步执行批量重命名（耗时由数秒降至 < 50ms），执行完成后在主线程平滑刷新卡片与顶部状态，彻底杜绝任何卡死！

### 3. macOS 系统级 Dock 图标强制生效 (`main.swift`, `MainWindowController.swift`, `Info.plist`)
- **根因分析**：
  - 尽管 `Contents/Resources/AppIcon.icns` 已存在，但由于 macOS LaunchServices 缓存了旧版本的空白图标，且 `Info.plist` 仅声明了 `CFBundleIconFile`，未在运行时主动向 `NSApplication` 注入图标，导致程序坞（Dock）和运行中 App 依然呈现默认白底网格。
- **重构要求**：
  - 在 `Info.plist` 中补齐 `<key>CFBundleIconName</key><string>AppIcon</string>`；
  - 在 `main.swift`（或 `applicationDidFinishLaunching`）启动的第一行显式执行：
    ```swift
    if let iconPath = Bundle.main.path(forResource: "AppIcon", ofType: "icns"),
       let iconImg = NSImage(contentsOfFile: iconPath) {
        NSApplication.shared.applicationIconImage = iconImg
    }
    ```
  - 打包流水线中增加 LaunchServices 强制刷新指令：
    `/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f "FCPX Studio Pro.app"`；
  - 确保桌面、访达、程序坞（Dock）与 DMG 安装盘 100% 呈现官方设计图标！
